## 6. 거시 환경 (Macro Backdrop)

> 이 회사의 투자 논리와 **실제로 연결되는** macro 문서만 고른다. 고르는 기준 예시:
> - 매출·매입원가가 특정 원자재·환율에 연동되는가 (예: 에너지 기업 → `macro/energy/`, 수출 비중이 큰 기업 → `macro/fx/`)
> - 4. 밸류에이션 결론의 할인율이 금리에 근거하는가 (거의 모든 회사 해당 → `macro/rates/treasury_10y.md` 등)
> - 동종업계·지수 대비 상대 성과를 봐야 하는가 (예: 반도체 기업 → `macro/equities/sox.md`)
>
> 관련 없는 카테고리(예: 소비재 기업에 `macro/crypto/`)는 빼고, 표 자체를 비워두지 말 것 — 최소 1개(대개 금리)는 대부분의 회사에 해당한다. (이 블록은 작성자 지침이므로 발행 전 삭제)

| 지표 (macro 문서) | 최신값 (기준일) | 이 회사와의 연관성 | 투자 논리에 주는 시사점 |
|---|---|---|---|
| [예: 미 국채 10년물](../../../meta/macro/rates/treasury_10y.md) |  | 위 4. 밸류에이션 결론의 할인율(Ke/WACC) 산정 근거 | 금리가 오르면 4. 밸류에이션 결론의 목표주가가 낮아지는 방향(민감도는 4. 밸류에이션 결론 참고) |
|  |  |  |  |

<표에서 다 담지 못하는 해석 — 예: 최근 이 지표의 추세가 4. 밸류에이션 결론 가정과 같은 방향인지 엇갈리는지 — 을 짧게 서술. 여기서 새로운 밸류에이션 재계산을 하지 말 것, 방향성 언급까지만>

## 9. 시나리오 요약

> 4. 밸류에이션 결론(가격)와 5. 투자 포인트 · 리스크(리스크)를 하나의 표로 합치는 이 보고서만의 종합 절이다 — 어디에도 없던 새 계산을 하지 말고, 이미 있는 하방/기본/상방 수치를 가져와 나란히 놓기만 한다. "근거" 열을 따로 두어 원본 파일명을 인용하지 않는다 — 근거는 위 4. 밸류에이션 결론·5. 투자 포인트 · 리스크 본문에 이미 있다.(이 블록은 작성자 지침이므로 발행 전 삭제)

| 시나리오 | 트리거 / 조건 | 가격 수준 |
|----------|----------------|-----------|
| Bear | 5. 투자 포인트 · 리스크 리스크의 트리거 | 5. 투자 포인트 · 리스크에 이미 계산된 하방 밸류에이션 |
| Base | 현재 가정 유지 | 4. 밸류에이션 결론 종합 적정주가 |
| Bull | (있다면) 5. 투자 포인트 · 리스크 강점의 확인 신호 | 상방 시나리오 가격 — 없으면 이 행 생략 |

**최종 결론**: <5. 투자 포인트 · 리스크의 결론을 그대로 인용하되, 위 시나리오 표를 근거로 한 문장 덧붙임. 이 문서가 새로운 매수/매도 트리거를 만들지 않는다 — 있다면 그것부터 `07_investment.md`(또는 해당 원 문서)에 반영한 뒤 여기서 인용할 것>
