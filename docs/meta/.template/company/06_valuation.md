# 밸류에이션 / 적정주가

> <적정주가 산정 결론 한 줄 요약 — 어떤 방법론(들)을 어떤 가중치로 병행했고, 현재 주가는 고평가/저평가/적정 수준인가>

> ⚠️ **4개 방법론을 기계적으로 전부 채우지 말 것.** 회사 특성에 맞지 않는 방법론은 아래 "적용 여부 판단 기준"에 따라 제외하거나 참고용으로 격하한다. 단순 평균은 이상치 하나에 쉽게 왜곡되므로 기본값은 "신뢰도 가중"이다.
>
> ⚠️ 2·3절의 EPS·BPS·DPS·FCF per share는 새로 계산하지 말고 핵심 지표 A.1·A.2·A.4를 그대로 인용한다. 미래 추정치(E)라 핵심 지표에 없는 값은 이 문서에만 존재하므로 근거와 신뢰도를 각주로 밝힌다.

!!! warning "읽기 전에"
    개인 리서치용 추정치이며 **투자 권유가 아니다.** 할인율·성장률·목표 배수 가정이 조금만 바뀌어도 결과는 크게 달라진다 — 아래 4. 민감도 분석에서 그 폭을 함께 본다.

    <이 회사 밸류에이션에만 해당하는 주의가 있으면 여기 덧붙인다. 없으면 이 줄만 삭제.
    예시: "GAAP EPS가 인수 관련 상각으로 왜곡돼 PER은 Non-GAAP 기준으로 통일했다"
    예시: "2026-08-19~21 사흘간 주가가 40% 급등해, 아래 괴리율은 그 직후 시점 기준이다">

??? note "이 문서의 수치를 읽는 기준 — 통화 · 기준 시점 · (E) 표기"
    - **통화**: <예: 1주당 수치는 모두 달러(USD), 총액은 백만 달러>
    - **기준 시점**: <예: 과거 3개년은 각 회계연도 말 종가, "현재"는 2026-08-21 종가 $397.87>
    - **(E) 표기**: <미래 3개년 추정치. 방법론별 근거가 가이던스인지 컨센서스인지 자체 추정인지 각주에 밝힌다>

## 1. 적용 방법론

**적용 여부 판단 기준** (해당 없으면 체크 해제하고 사유를 반드시 기록):

> ⚠️ 각 방법론의 정의·산식은 [용어집](../../../meta/glossary.md) "6. 밸류에이션 방법론" 참고. 아래는 적용 여부를 판단할 때 추가로 지킬 것만 적는다.

- [ ] PER 방식 — 적정주가 = EPS × 목표 PER
  - 적자 기업이나 이익 변동성이 극심한 기업엔 부적합.
- [ ] PBR 방식 — 적정주가 = BPS × 목표 PBR
  - **주의**: 최근 대형 M&A(주식교환 대가 지급 등)로 자기자본이 단절적으로 급변했다면, 과거 평균 배수와 최근 배수가 서로 다른 자본구조를 기준으로 계산돼 평균이 왜곡된다 — 적용하더라도 참고용으로 격하하고 이유를 명시.
- [ ] DCF (현금흐름할인법)
  - **① 할인율과 현금흐름의 짝을 먼저 선언할 것** — 핵심 지표 A.4의 FCF(`CFO − CapEx`)는 지급이자가 이미 차감된 **FCFE**이므로 **자기자본비용(Ke)**으로 할인하고 순부채를 따로 빼지 않는다. WACC를 쓰려면 현금흐름을 **FCFF**로 바꾸고 마지막에 **순부채를 차감**해야 한다. 외부 사이트의 "WACC 추정치"를 FCFE에 그대로 갖다 쓰는 건 오류이니 같은 사이트의 Cost of Equity를 쓸 것([용어집](../../../meta/glossary.md) "FCFE / FCFF — 할인율 정합성"). 부채가 거의 없어 WACC ≈ Ke로 근사했다면 근거를 아래 표에 명시.
  - **② SBC 처리를 명시할 것** — FCF에서 차감했는지 여부. 미차감이면 결과가 그만큼 낙관적이라는 점을 5. 결론에 적는다.
  - **③ 고성장 기업의 1단계 모델 한계** — 실제 성장률이 영구성장률보다 훨씬 높은 기업엔 **1단계(Gordon growth) 모델**이 구조적으로 지나치게 낮은 값을 낸다. 이런 회사는 **고성장기(3~5년) + 영구성장기 2단계 모델**이 기본이며, 그래도 1단계를 택했다면 왜 2단계를 쓰지 않았는지와 그 한계를 4. 민감도 분석·5. 결론에 명시하고 신뢰도를 Low로 낮춰 가중치에 반영할 것. **"한계를 적었으니 됐다"고 넘어가지 말 것** — 한계가 결론을 좌우할 정도면 종합값에서 빼는 게 맞다.
- [ ] DDM (배당할인모형)
  - **무배당 기업에는 적용 불가** — 체크하지 말고 "무배당으로 해당 없음" 한 줄만 남긴 뒤 아래 표에서 관련 행을 통째로 생략한다(N/A 반복 기입 금지).
  - 배당성장률 g가 요구수익률 r에 근접하면(`r − g` ≤ 2%p) 결과가 폭발해 종합값을 혼자 끌어올린다 — 신뢰도를 Low로 두고 5. 결론에서 그 영향을 분리해 보일 것.

**핵심 가정 및 신뢰도**

| 가정 항목 | 값 | 근거 | 신뢰도 |
|-----------|-----|------|--------|
| 목표 PER |  | <동종업계 평균 / 과거 N년 평균 등> | <High/Medium/Low> |
| 목표 PBR |  | <동종업계 평균 / 과거 N년 평균 등> | <High/Medium/Low> |
| **DCF 현금흐름 기준** | <FCFE (CFO−CapEx) / FCFF> | 위 ①에 따라 선택한 근거 | — |
| 할인율 (FCFE면 Ke, FCFF면 WACC) |  | <CAPM 구성요소(무위험이자율·베타·ERP) 또는 인용 출처. 출처 간 편차가 크면 범위로 기록> | <High/Medium/Low> |
| 순부채 차감 여부 (FCFF일 때만) | <차감액 / 해당 없음(FCFE)> | 핵심 지표 A.3 인용 | — |
| SBC 차감 여부 | <차감 / 미차감> | 미차감이면 결과가 낙관적임을 5. 결론에 명시 | — |
| 영구/장기 성장률 (DCF) |  |  | <High/Medium/Low> |
| 배당성장률 (DDM) |  |  | <High/Medium/Low> |
| 요구수익률 (DDM) |  |  | <High/Medium/Low> |
| **방법론별 가중치 (종합 시)** | <예: PER 50% / DCF 30% / PBR 20%> | 신뢰도가 Low면 가중치를 낮추거나 제외 — **균등가중을 기본값으로 쓰지 말고 왜 이 가중치인지 반드시 서술** | — |

> ⚠️ 신뢰도 Low인 방법론이 하나라도 있으면, 아래 2·3절의 "종합 적정주가"는 그 방법론을 제외했을 때 값도 괄호로 함께 적어 평균이 이상치에 얼마나 좌우되는지 드러낼 것.

## 4. 민감도 분석

> ⚠️ **종합 가중치가 가장 큰 방법론에는 반드시 민감도 분석을 붙인다.** 결론을 가장 많이 좌우하는 값인데 검증이 없으면 "왜 이 가정인가"가 서술 하나에만 의존하게 된다. DCF를 적용했다면 가중치와 무관하게 4-A를 항상 채우고(구조적으로 민감도가 크다), PER·PBR이 가중치 최대면 4-B도 채운다.
>
> ⚠️ **상단과 하단이 2배 이상 벌어지면 그 방법론은 "적정주가 한 점"이 아니라 범위로만 의미가 있다** — 5. 결론에서 단일 값처럼 인용하지 말 것. 4-A·4-B 모두에 같은 기준을 적용한다.
