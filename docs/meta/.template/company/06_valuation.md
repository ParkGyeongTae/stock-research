# <회사명> — 밸류에이션 / 적정주가

> <적정주가 산정 결론 한 줄 요약 — 어떤 방법론(들)을 어떤 가중치로 병행했고, 현재 주가는 고평가/저평가/적정 수준인가>

> ⚠️ 가정(할인율, 성장률, 목표 배수)이 바뀌면 결과도 크게 바뀜을 항상 염두에 둘 것.
>
> ⚠️ 통화 단위와 기준 시점(회계연도 말 / 특정일 종가 등)을 반드시 명시.
>
> ⚠️ 미래 3개년 추정치는 (E)로 표시하고, 근거(가이던스/컨센서스/자체 추정)를 밝힐 것.
>
> ⚠️ **4개 방법론을 기계적으로 전부 채우지 말 것.** 회사 특성에 맞지 않는 방법론은 억지로 적용하지 말고 아래 "적용 여부 판단 기준"에 따라 제외하거나 참고용으로만 표기. 단순 평균은 이상치 하나에 쉽게 왜곡되므로 기본값이 아니라 "신뢰도 가중"이 기본값.
>
> ⚠️ 아래 §2·§3의 EPS·BPS·DPS·FCF per share는 새로 계산하지 말고 `04_metrics.md` A.1(실적)·A.2(BPS·PBR)·A.4(FCF·DPS)의 값을 그대로 인용할 것. 미래 추정치(E)라서 `04_metrics.md`에 값이 없다면, 그 추정치는 `04_metrics.md`가 아니라 이 문서에만 있는 것이므로 근거(가이던스/컨센서스/자체 추정)와 신뢰도를 반드시 각주로 밝힐 것.

## 1. 적용 방법론

**적용 여부 판단 기준** (해당 없으면 체크 해제하고 사유를 반드시 기록):

> 각 방법론의 정의·산식은 [`glossary.md`](../../../meta/glossary.md) "1. 밸류에이션 방법론"을 참고. 아래는 이 문서에서 적용 여부를 판단할 때만 추가로 지킬 것.

- [ ] PER 방식 — 적정주가 = EPS × 목표 PER
  - 적자 기업이나 이익 변동성이 극심한 기업엔 부적합.
- [ ] PBR 방식 — 적정주가 = BPS × 목표 PBR
  - **주의**: 최근 대형 M&A(주식교환 방식 대가 지급 등)로 자기자본이 단절적으로 급변한 경우, 과거 평균 배수와 최근 배수가 서로 다른 자본구조를 기준으로 계산돼 평균이 왜곡됨 — 이런 경우 적용하더라도 참고용으로 격하하고 그 이유를 명시.
- [ ] DCF (현금흐름할인법)
  - **① 할인율과 현금흐름의 짝을 먼저 선언할 것** — `04_metrics.md` A.4의 FCF(`CFO − CapEx`)는 지급이자가 이미 차감된 **FCFE**이므로 **자기자본비용(Ke)**으로 할인하고 순부채를 따로 빼지 않는다. WACC를 쓰려면 현금흐름을 **FCFF**로 바꾸고 마지막에 **순부채를 차감**해야 한다. 외부 사이트의 "WACC 추정치"를 FCFE에 그대로 갖다 쓰는 것은 오류 — 같은 사이트의 Cost of Equity 값을 쓸 것([`glossary.md`](../../../meta/glossary.md) "FCFE / FCFF — 할인율 정합성"). 부채가 거의 없어 WACC ≈ Ke로 근사했다면 그 근거를 아래 표에 명시.
  - **② SBC 처리를 명시할 것** — FCF에서 SBC를 차감했는지 안 했는지. 차감하지 않았다면 결과가 그만큼 낙관적이라는 점을 §5에 적을 것.
  - **③ 고성장 기업의 1단계 모델 한계** — 실제 성장률이 영구성장률보다 훨씬 높은 기업엔 **1단계(Gordon growth) 모델**이 구조적으로 지나치게 낮은 값을 낸다. 이런 회사는 **고성장기(3~5년) + 영구성장기 2단계 모델**을 쓰는 것이 기본이며, 그래도 1단계를 택했다면 **왜 2단계를 쓰지 않았는지**와 그 한계를 §4·§5에 명시하고 §1 신뢰도를 Low로 낮춰 가중치에 반영할 것. "한계를 적었으니 됐다"고 넘어가지 말 것 — 한계가 결론을 좌우할 정도면 그 방법론은 종합값에서 빼는 게 맞다.
- [ ] DDM (배당할인모형)
  - **무배당 기업에는 적용 불가** — 이 경우 체크하지 말고 "무배당으로 해당 없음"이라고 한 줄만 남기고 아래 표에서 관련 행은 통째로 생략(N/A 반복 기입 금지).
  - 배당성장률 g가 요구수익률 r에 근접하면(`r − g`가 2%p 이하) 결과가 폭발적으로 커져 종합값을 혼자 끌어올린다 — 이 경우 신뢰도를 Low로 두고 §5에서 그 영향을 분리해 보일 것.

**핵심 가정 및 신뢰도**

| 가정 항목 | 값 | 근거 | 신뢰도 |
|-----------|-----|------|--------|
| 목표 PER |  | <동종업계 평균 / 과거 N년 평균 등> | <High/Medium/Low> |
| 목표 PBR |  | <동종업계 평균 / 과거 N년 평균 등> | <High/Medium/Low> |
| **DCF 현금흐름 기준** | <FCFE (CFO−CapEx) / FCFF> | 위 ①에 따라 선택한 근거 | — |
| 할인율 (FCFE면 Ke, FCFF면 WACC) |  | <CAPM 구성요소(무위험이자율·베타·ERP) 또는 인용 출처. 출처 간 편차가 크면 범위로 기록> | <High/Medium/Low> |
| 순부채 차감 여부 (FCFF일 때만) | <차감액 / 해당 없음(FCFE)> | `04_metrics.md` A.2·A.3 인용 | — |
| SBC 차감 여부 | <차감 / 미차감> | 미차감이면 결과가 낙관적임을 §5에 명시 | — |
| 영구/장기 성장률 (DCF) |  |  | <High/Medium/Low> |
| 배당성장률 (DDM) |  |  | <High/Medium/Low> |
| 요구수익률 (DDM) |  |  | <High/Medium/Low> |
| **방법론별 가중치 (종합 시)** | <예: PER 50% / DCF 30% / PBR 20%> | 신뢰도가 Low인 방법론은 가중치를 낮추거나 제외 — **균등가중을 기본값으로 쓰지 말고, 왜 이 가중치인지 반드시 서술** | — |

> 신뢰도가 Low인 방법론이 하나라도 있으면, 아래 §2·§3의 "종합 적정주가"는 그 방법론을 제외했을 때 값도 괄호로 함께 표기해 평균이 이상치에 얼마나 좌우되는지 드러낼 것.

## 4. 민감도 분석

> **§1 "방법론별 가중치" 표에서 종합 가중치가 가장 큰 방법론에는 반드시 민감도 분석을 붙일 것.** 최종 결론(§5·§6)을 가장 많이 좌우하는 값인데도 민감도 검증이 없으면, "왜 이 가정을 택했는가"가 서술 하나에만 의존하게 된다. DCF를 적용했다면 가중치와 무관하게 4-A를 항상 채운다(구조적으로 민감도가 크기 때문). **PER 또는 PBR이 종합 가중치 최대**라면(예: Coinbase처럼 PBR 100%) 4-B도 반드시 채운다 — DCF가 0%로 빠졌다는 이유로 민감도 검증 없이 넘어가지 말 것.

### 4-A. DCF 민감도 (DCF를 적용한 경우 항상 필수)

<할인율·영구성장률 가정이 조금만 바뀌어도 DCF 적정주가가 얼마나 흔들리는지 표로 제시. `(할인율 − g)`가 작을수록 민감도가 커지므로, 결론에서 DCF 비중을 어느 정도로 둘지 판단하는 근거로 사용. 표 안의 할인율은 §1에서 선언한 기준(FCFE면 Ke, FCFF면 WACC)과 일치시킬 것>

| 할인율 \ g | g−0.5%p | 기본 g | g+0.5%p |
|-----------|---------|--------|---------|
| 할인율 −1%p |  |  |  |
| 기본 할인율 |  |  |  |
| 할인율 +1%p |  |  |  |

> 민감도 범위의 상단과 하단이 2배 이상 벌어지면, DCF는 "적정주가 한 점"이 아니라 **범위**로만 의미가 있다 — §5에서 단일 값처럼 인용하지 말 것.

### 4-B. PER/PBR 민감도 (PER 또는 PBR이 종합 가중치 최대인 경우 필수)

<목표 배수 가정이 조금만 바뀌어도 적정주가가 얼마나 흔들리는지 표로 제시. 하단·상단 범위는 §1에서 목표 배수를 정할 때 쓴 근거와 일치시킬 것(예: 최근 N개년 최저~최고, 평균±1표준편차 등) — 임의로 새 범위를 만들지 말 것>

| | 하단 (근거: <예: 3개년 최저>) | 기본값 (§1 채택값) | 상단 (근거: <예: 3개년 최고>) |
|---|---|---|---|
| 목표 배수 (PER 또는 PBR) |  |  |  |
| 적정주가 |  |  |  |

> 상단·하단 적정주가가 2배 이상 벌어지면 이 방법론도 §5·§6에서 "한 점"이 아니라 **범위**로만 인용할 것 — DCF와 같은 기준을 적용한다.

## 5. 판단 메모

<현재 주가가 종합 적정주가 대비 어느 위치에 있는지, 최근 3년 추세와 향후 3년 전망을 종합했을 때의 결론. 방법론 간 괴리가 크다면 어떤 방법론에 더 무게를 둘지와 그 이유(§1 신뢰도·§4 민감도 근거로 서술). 밸류에이션 숫자만으로 도출되는 **가격 레벨**(예: "적정주가 대비 −20% 이하면 저평가 구간 진입")이 있으면 여기 기록 — 리스크·정성적 조건까지 합친 최종 매수/매도 트리거는 여기서 만들지 말고 `07_investment.md` §5에서 종합할 것>
