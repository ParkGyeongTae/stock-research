!!! note ""

## 2. 해석 참고 — 상승/하락이 의미하는 것

- **상승**: 건설·제조업·전력망 투자 등 글로벌 산업 수요 확장 기대, 즉 경기 확장 국면 신호로 흔히 해석된다("Dr. Copper"라 불리는 이유).
- **하락**: 산업 수요 위축, 경기 둔화·침체 우려 신호로 흔히 해석된다.
- 광산 파업·신규 프로젝트 가동 같은 공급 측 요인도 가격에 크게 작용하므로, 가격 변화를 수요 신호로만 단정하지 않는다.
