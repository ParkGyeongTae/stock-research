## 2. 해석 참고 — 상승/하락이 의미하는 것

- 시가총액 가중 지수라 상위 몇 개 대형주의 비중이 매우 크다 — 지수 움직임을 "시장 전체가 골고루 움직였다"로 곧장 해석하지 않는다.
