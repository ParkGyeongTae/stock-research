# 용어집

회사·섹터 문서 템플릿이 설명 없이 바로 쓰는 용어를 한 곳에 모은 참고 문서입니다. 특정 회사·섹터에 종속되지 않는 일반적인 정의만 다룹니다.

## 1. 재무제표 기초 { #financial-statements }

> 📖 예시로 풀어 쓴 설명: [재무제표 기초](./concepts/financial-statements.md)
>
> 재무제표를 처음 본다면 여기부터 시작하세요. 2. 재무 지표·6. 밸류에이션 방법론의 지표는 전부 이 세 표에서 나옵니다.

| 용어 | 뜻 |
|------|-----|
| **재무제표 3종** | **손익계산서**(일정 기간 얼마를 벌었나) · **재무상태표**(특정 시점에 무엇을 갖고 얼마를 빚졌나) · **현금흐름표**(그 기간 현금이 실제로 얼마나 드나들었나). 앞의 둘이 "회계상 성과"라면 현금흐름표는 "실제 현금"이라, 셋을 같이 봐야 그림이 맞는다. |
| **발생주의 vs 현금주의** | 발생주의는 현금이 오가는 시점과 무관하게 **거래가 발생한 시점**에 수익·비용을 기록하는 방식(손익계산서). 현금주의는 실제 현금 이동 시점에 기록(현금흐름표). 이익이 나는데 현금이 마르는 회사가 존재하는 이유가 이 차이다. |
| **회계등식** | 자산 = 부채 + 자본. 재무상태표가 항상 균형을 이루는 근본 원리. |
| **매출 / Top line** | 제품·서비스를 팔아 벌어들인 총액. |
| **매출원가 (COGS)** | 그 매출을 일으키는 데 직접 든 원가(재료비·직접 인건비·클라우드 비용 등). |
| **매출총이익** (Gross Profit) | 매출 − 매출원가. 판매·관리·연구개발 비용을 대기 전의 1차 이익. |
| **판매관리비 (SG&A)** | 영업·마케팅·일반관리 비용. 매출 성장 대비 SG&A 증가 속도를 보면 성장이 효율적인지 드러난다. |
| **연구개발비 (R&D)** | 미국 GAAP에서는 원칙적으로 발생 즉시 비용 처리한다(자산화하지 않음) — R&D가 큰 회사는 그만큼 당장의 이익이 낮게 나올 뿐, 미래 경쟁력을 만드는 투자일 수 있다. 예시는 [재무제표 기초](./concepts/financial-statements.md) 참고. |
| **영업이익 (EBIT)** | 매출 − 매출원가 − 판관비 − R&D. 본업에서 남긴 이익으로, 이자·세금의 영향을 받기 전 단계. |
| **EBITDA** | 영업이익 + 감가상각비·무형자산상각비(D&A). 설비 투자 방식과 감가상각 정책 차이를 걷어내고 비교하려는 지표. **CapEx가 큰 회사에서는 실제 현금창출력을 과대평가한다**(4. 수익성 · 효율성 · 안정성 심화 "EBITDA의 함정" 참고). |
| **D&A (감가상각 / 상각)** | 설비·건물처럼 여러 해 쓰는 자산의 취득원가를 사용 기간에 나눠 비용으로 인식하는 것(유형=감가상각, 무형=상각). 현금이 나가지 않는 비용이라 현금흐름표에서 다시 더해진다. |
| **영업외손익 / 이자비용 / 법인세** | 본업 밖에서 생긴 손익(이자·환차손익·투자평가손익 등)과 차입 이자, 그리고 세금. 영업이익에서 이것들을 거치면 순이익이 된다. |
| **순이익 / Bottom line** | 모든 비용·세금을 뺀 최종 이익. EPS의 분자. |
| **지배주주지분 / 비지배지분** | 자회사를 100% 갖고 있지 않을 때, 순이익 중 모회사 주주 몫과 나머지 주주 몫. **EPS 계산에는 지배주주지분 순이익을 쓴다.** |
| **자산 / 부채 / 자본** | 자산은 회사가 가진 것, 부채는 갚아야 할 것, 자본(자기자본)은 그 차액인 주주 몫. |
| **유동 vs 비유동** | 1년 안에 현금화되거나 갚아야 하면 유동, 그 이상이면 비유동. 유동비율 계산의 기준이다. |
| **매출채권 / 재고자산 / 매입채무** | 아직 못 받은 판매대금 / 아직 못 판 물건 / 아직 안 준 구매대금. 이 세 항목이 운전자본의 핵심이다. |
| **운전자본 (Working Capital)** | 유동자산 − 유동부채(협의로는 매출채권+재고−매입채무). **운전자본이 늘면 그만큼 현금이 묶인다** — FCFF 공식의 `−ΔWC`가 바로 이것. |
| **이익잉여금 / 자본잉여금 / 자기주식** | 벌어서 사내에 쌓아둔 이익 / 주식 발행 시 액면 초과분 / 회사가 되사들여 보유 중인 자기 주식(자본의 차감 항목). |
| **영업권 (Goodwill)** | 다른 회사를 순자산 가치보다 비싸게 인수했을 때 그 차액을 자산으로 올린 것. 상각하지 않는 대신 매년 손상 검사를 하며, **손상차손이 나면 과거 인수가 비쌌다는 뒤늦은 고백**에 가깝다. |
| **무형자산 / 손상차손** | 특허·고객관계·상표권 등 형체 없는 자산 / 자산의 회수가능액이 장부가에 못 미칠 때 인식하는 손실. |
| **이연법인세** | 회계상 이익과 세무상 이익의 시점 차이 때문에 생기는 자산·부채 항목. |
| **리스부채** | 리스 계약으로 미래에 지급할 의무를 부채로 계상한 것. 순부채·EV 계산 시 포함 여부를 명시해야 회사 간 비교가 어긋나지 않는다. |
| **CFO / CFI / CFF** | 현금흐름표의 3구분 — 영업활동(본업), 투자활동(설비·인수·금융자산), 재무활동(차입·상환·배당·자사주·증자). **어디서 현금이 들어오는가**가 회사의 단계를 말해준다(성숙기업은 CFO 플러스, 성장기업은 CFF 의존이 흔함). |
| **이연수익 (Deferred Revenue)** | 대금은 먼저 받았지만 아직 제공하지 않은 서비스에 대한 **부채**. 구독 사업에서 늘어나면 선수금이 쌓인다는 뜻이라 보통 긍정적 신호로 읽는다. |
| **주석 (Footnotes)** | 재무제표 뒤에 붙는 상세 설명. 세그먼트별 실적, 매출 인식 정책, 소송, 우발부채 등 본표에 안 보이는 핵심이 여기 있다. |
| **연결 vs 별도** | 자회사를 포함해 하나의 회사처럼 합친 재무제표(연결) vs 모회사만의 재무제표(별도). 투자 판단은 원칙적으로 연결 기준으로 본다. |
| **GAAP vs IFRS** | 미국 회계기준 vs 국제 회계기준. 이 레포는 미국 상장사 위주라 GAAP을 전제로 하며, 비-US 기업을 다룰 땐 용어를 치환하고 각주로 남긴다. |

## 2. 재무 지표 { #financial-metrics }

> 📖 예시로 풀어 쓴 설명: [재무 지표](./concepts/financial-metrics.md)

| 용어 | 뜻 |
|------|-----|
| **희석주식수** (Diluted Shares) | 스톡옵션·RSU 등이 모두 보통주로 전환됐다고 가정한 주식수. 기본주식수(basic)보다 크거나 같음 — 이 레포의 EPS·BPS·FCFPS는 모두 희석 기준을 기본으로 씀. |
| **EPS** (주당순이익, Earnings Per Share) | 순이익 ÷ 희석주식수. GAAP/Non-GAAP 두 기준으로 나눠 기록(아래 참고). |
| **BPS** (주당순자산, Book Value Per Share) | 자기자본 ÷ 희석주식수. PBR 계산의 기준값. |
| **DPS** (주당배당금, Dividend Per Share) | 1주당 지급한 배당금. 무배당 기업은 0으로 기록(행을 지우지 않음). |
| **GAAP vs Non-GAAP** | GAAP은 미국 회계기준에 따른 공식 수치, Non-GAAP은 회사가 특정 비용을 제외해 조정한 수치. 제외 항목엔 일회성뿐 아니라 **SBC·무형자산상각처럼 매년 반복되는 항목**도 흔히 포함되므로 무엇을 뺐는지 항목별로 확인하고, 어느 기준인지 행마다 구분해서 기록할 것 — 예시는 [재무 지표](./concepts/financial-metrics.md) 참고. |
| **SBC** (주식보상비용, Stock-Based Compensation) | 스톡옵션·RSU 지급을 비용으로 인식한 금액. 현금이 나가지 않아 CFO에 다시 더해지므로 **FCF와 Non-GAAP EPS 양쪽에서 동시에 사라지지만**, 실제로는 희석주식수 증가로 기존 주주 몫을 줄이는 실질 비용이다 — 매출 대비 SBC 비율과 희석주식수 추이를 함께 기록할 것. 자세한 예시는 [재무 지표](./concepts/financial-metrics.md) 참고. |
| **FCF** (잉여현금흐름, Free Cash Flow) | 영업활동현금흐름(CFO) − 자본적지출(CapEx). 배당·자사주매입·재투자에 실제 쓸 수 있는 현금. 미국 GAAP에서 CFO는 지급이자를 이미 차감한 뒤의 값이라 이 FCF는 **FCFE(주주 귀속) 성격**이며, SBC는 차감돼 있지 않다(위 SBC 항목 참고). |
| **FCFPS** (FCF per share) | FCF ÷ 희석주식수. DCF의 기준값이며, 위 정의상 FCFE 기준이므로 **자기자본비용(Ke)으로 할인**해야 정합적이다. |
| **CFO / CapEx** | CFO(영업활동현금흐름)는 본업에서 벌어들인 현금, CapEx(자본적지출)는 설비·시설 등에 재투자한 현금. |
| **영업이익률** | 영업이익 ÷ 매출. 본업의 수익성을 보는 지표. |
| **매출총이익률** (Gross Margin) | 매출총이익 ÷ 매출. 제품·서비스 자체의 근본 수익성으로, 규모가 커져도 잘 변하지 않아 **사업 모델의 체질**을 드러낸다. 소프트웨어는 70~90%, 하드웨어·유통은 20~40%대가 흔하다. |
| **순이익률** | 순이익 ÷ 매출. 이자·세금·일회성까지 모두 반영된 최종 수익성. |
| **ROE** (자기자본이익률, Return on Equity) | 순이익 ÷ 자기자본. 주주 자본을 얼마나 효율적으로 굴렸는지. **부채를 늘리면 자기자본이 줄어 ROE가 올라가므로**, 높은 ROE가 실력인지 레버리지인지 부채비율과 함께 확인할 것(4. 수익성 · 효율성 · 안정성 심화 "듀폰 분해" 참고). |
| **유동비율** | 유동자산 ÷ 유동부채. 단기 지급능력을 보는 지표. |
| **부채비율** | 총부채 ÷ 자기자본. 이 레포에서는 부채총계(총자산−자기자본) 기준을 기본으로 쓰되, 이자부 차입금만 집계하는 협의의 정의(Debt/Equity)와는 다르므로 비교 시 주의. |
| **순부채 (Net Debt)** | 이자부 차입금(단기+장기+리스부채) − 현금및현금성자산·단기투자자산. 양수면 순차입, 음수면 순현금. FCFF-DCF에서 EV를 주주가치로 환산할 때와 EV 계산에 쓴다. |
| **EV (기업가치, Enterprise Value)** | 시가총액 + 순부채. "회사를 통째로 사들일 때의 값". 순현금이 두꺼운 회사와 대형 인수로 순차입이 늘어난 회사를 PER만으로 비교하면 자본구조 차이가 배수에 섞여 들어오므로, **EV/EBITDA·EV/Sales**를 함께 본다. |
| **배당성향** | 배당금 ÷ 순이익. 이익 중 얼마를 배당으로 돌려주는지. |
| **배당수익률** | DPS ÷ 주가. 현재 주가 기준 배당의 연 수익률. |
| **자사주매입** | 회사가 자기 주식을 사들이는 것. 배당이 없는 기업의 주된 주주환원 수단인 경우가 많음. |
| **총주주환원율** | (배당금 + 자사주매입액) ÷ 순이익 또는 ÷ FCF. 배당만 보면 자사주매입 위주 기업의 환원 규모를 놓치므로 둘을 합쳐서 본다. |

## 3. 표기 규칙 { #notation }

> 📖 예시로 풀어 쓴 설명: [표기 규칙](./concepts/notation.md)

| 용어 | 뜻 |
|------|-----|
| **YoY / QoQ** | YoY(Year over Year)는 전년 동기 대비, QoQ(Quarter over Quarter)는 전분기 대비 증감. |
| **%p (퍼센트포인트)** | 비율 지표(영업이익률 등)의 증감을 표기할 때 씀. 예: 28% → 30%는 "+2%p"(단순 뺄셈)이지 "+7.1%"(상대 증감률)가 아님. |
| **bp (베이시스포인트)** | 0.01%p. 금리·수수료율처럼 작은 변화를 다룰 때 쓴다. 100bp = 1%p. |
| **(E)** | Estimate. 아직 확정되지 않은 값(회사 가이던스, 애널리스트 컨센서스, 또는 자체 추정)이라는 표시. 근거를 항상 함께 밝힘. |
| **가이던스 vs 컨센서스** | 가이던스는 회사가 직접 제시하는 향후 실적 전망치(자체 추정), 컨센서스는 여러 애널리스트 추정치의 평균/중앙값. 둘 다 (E)로 표시되지만 출처·신뢰도가 다르므로 어느 쪽인지 반드시 구분해서 표기. |
| **FY / Q 표기** | FY(Fiscal Year, 회계연도)는 회사마다 종료월이 다를 수 있어 헷갈리면 각주로 설명. FY-1·FY+1처럼 상대 표기는 실제 연도(FY2025 등)로 바꿔서 채움. |
| **TTM / LTM** | Trailing(Last) Twelve Months. 최근 4개 분기 합산치로, 회계연도 경계와 무관하게 "지금 시점의 연간 실적"을 보는 방법. 결산월이 다른 회사끼리 비교할 때 특히 유용. |
| **YTD** | Year to Date. 회계연도 시작부터 현재까지의 누적치. |
| **연환산 (Annualized)** | 분기 실적에 4를 곱하는 식으로 1년치로 환산한 값. 계절성이 큰 사업에 쓰면 심하게 왜곡되므로 주의. |
| **CAGR** (연평균성장률) | `(기말÷기초)^(1÷연수) − 1`. 중간의 등락을 무시하고 평균 성장 속도만 보는 값이라, **시작·끝 연도를 어디로 잡느냐에 따라 크게 달라진다** — 반드시 기간을 함께 표기할 것. |
| **상수통화 기준** (Constant Currency) | 환율 변동 효과를 제거하고 계산한 성장률. 해외 매출 비중이 큰 회사는 보고 기준 성장률과 크게 다를 수 있어 회사가 둘 다 공시하는 경우가 많다. |
| **유기적 성장** (Organic Growth) | 인수합병 효과를 뺀 자체 성장. 인수를 자주 하는 회사는 보고 매출 성장률이 실제 사업 성장을 과장하므로 구분해서 본다. |
| **스톡스플릿 소급조정** | 표 기간 내 주식분할·병합이 있었다면 과거 전 구간(주가·EPS·BPS·DPS·발행주식수)을 분할 후 기준으로 맞추는 것. 안 하면 분할 전/후 숫자가 섞여 평균·추이 전체가 왜곡됨. |
| **단위 표기** | 금액은 통화와 단위를 항상 명시(예: USD million). 미국 공시의 billion은 10억, trillion은 1조. |
| **계절성** (Seasonality) | 특정 분기에 실적이 몰리는 성질. 계절성이 있으면 QoQ 대신 YoY로 추세를 판단한다. |

## 4. 수익성 · 효율성 · 안정성 심화 { #advanced-metrics }

> 📖 예시로 풀어 쓴 설명: [수익성 · 효율성 · 안정성 심화](./concepts/advanced-metrics.md)
>
> 2. 재무 지표가 "자주 쓰는 지표"라면, 여기는 **자본을 얼마나 잘 굴리는가**와 **버틸 힘이 있는가**를 보는 지표들입니다.

| 용어 | 뜻 |
|------|-----|
| **ROA** (총자산이익률) | 순이익 ÷ 총자산. 자본구조와 무관하게 자산 전체의 효율을 본다. |
| **ROIC** (투하자본이익률) | NOPAT ÷ 투하자본. **가치 창출을 판별하는 가장 핵심적인 지표** — ROIC가 WACC보다 높아야 성장이 가치를 만들고, 낮으면 성장할수록 가치를 파괴한다. |
| **NOPAT** | 세후영업이익 = EBIT × (1 − 세율). 자본구조의 영향을 뺀 영업 성과. |
| **투하자본** (Invested Capital) | 사업에 실제로 묶여 있는 자본 = 이자부 차입금 + 자기자본 − 잉여현금(또는 순운전자본 + 순유형자산). 정의가 여러 개라 **어느 정의를 썼는지 반드시 밝힐 것**. |
| **ROIC − WACC 스프레드** | 초과수익률. 양수면 자본비용 이상을 벌고 있다는 뜻이며, 이 스프레드가 지속되는 기간이 곧 해자의 수명이다. |
| **ROCE** (사용자본이익률) | EBIT ÷ (총자산 − 유동부채). ROIC와 취지가 같고 정의만 다른 사촌 지표. |
| **듀폰 분해** (DuPont) | ROE = 순이익률 × 자산회전율 × 재무레버리지. ROE가 높은 이유가 **마진 때문인지, 효율 때문인지, 빚 때문인지** 갈라 보는 방법. |
| **자산회전율** | 매출 ÷ 총자산. 자산을 얼마나 자주 매출로 돌리는지. |
| **재고회전율 / DIO** | 매출원가 ÷ 평균재고 / 재고가 팔리기까지 걸리는 평균 일수. DIO가 길어지면 재고가 쌓이고 있다는 신호. |
| **DSO** (매출채권회수기간) | 판 뒤 대금을 받기까지 걸리는 평균 일수. 매출은 느는데 DSO가 급격히 길어지면 **밀어내기 매출이나 부실 고객**을 의심한다. |
| **DPO** (매입채무지급기간) | 사고 나서 대금을 지급하기까지의 평균 일수. |
| **CCC** (현금전환주기) | DIO + DSO − DPO. 현금이 재고·채권에 묶여 있다가 회수되기까지의 일수로, **음수면 고객 돈으로 사업을 돌리는 구조**(일부 유통·플랫폼)다. |
| **이자보상배율** | EBIT ÷ 이자비용. 영업이익으로 이자를 몇 배 감당하는지. 1 미만이면 본업으로 이자도 못 낸다는 뜻. |
| **순차입금 / EBITDA** | 순부채 ÷ EBITDA. 빚을 갚는 데 몇 년치 EBITDA가 필요한지. 인수 직후 이 값이 급등한 회사는 그 부담이 해소되는 속도를 추적한다. |
| **당좌비율** (Quick Ratio) | (유동자산 − 재고) ÷ 유동부채. 재고를 못 판다고 가정한 더 보수적인 단기 지급능력. |
| **영업레버리지** | 고정비 비중이 높아, 매출이 조금 늘 때 영업이익이 더 크게 늘어나는 구조. 반대로 매출이 꺾이면 이익은 더 크게 꺾인다. |
| **재무레버리지** | 부채를 써서 자기자본 수익률을 키우는 것. 이익이 날 땐 ROE를 밀어올리고, 나빠질 땐 손실도 증폭한다. |
| **손익분기점** (BEP) | 고정비를 덮는 데 필요한 매출 수준. 적자 성장기업을 볼 때 "언제 흑자 전환하는가"의 기준. |
| **FCF 전환율** | FCF ÷ 순이익(또는 ÷ EBITDA). 회계 이익이 실제 현금으로 얼마나 바뀌는지. 1에 못 미치는 상태가 이어지면 이익의 질을 의심한다. |
| **CapEx / 매출** | 매출 대비 설비투자 강도. 자본집약도를 보여주며, 유지 수준을 넘는 증가는 증설 사이클 진입 신호일 수 있다. |
| **유지 CapEx vs 성장 CapEx** | 현 상태를 유지하는 데 필요한 투자와 새 수익을 만들기 위한 투자. 회사가 구분 공시하지 않는 경우가 많아 D&A를 유지 CapEx의 근사치로 쓰기도 한다. |
| **EBITDA의 함정** | EBITDA는 D&A를 되돌려 놓기 때문에, 설비 재투자가 필수인 사업에서는 "쓸 수 있는 현금"을 과대평가한다. 자본집약 산업에서 EBITDA만 보면 부채 감당 능력을 낙관하게 되므로 FCF와 함께 볼 것. |

## 5. 사업 모델 · 성장 지표 { #business-metrics }

> 📖 예시로 풀어 쓴 설명: [사업 모델 · 성장 지표](./concepts/business-metrics.md)
>
> 회사가 속한 업종에 따라 "봐야 할 숫자"가 달라집니다. 구독 소프트웨어·수주 산업·플랫폼·금융은 각각 핵심 지표가 다릅니다.

| 용어 | 뜻 |
|------|-----|
| **리커링 매출** (Recurring Revenue) | 계약에 따라 반복적으로 발생하는 매출. 일회성 판매보다 예측 가능성이 높아 같은 매출이라도 더 높은 배수를 받는 근거가 된다. |
| **ARR / MRR** | 연간·월간 반복매출. 구독 사업의 사실상 표준 지표지만 **회사마다 정의가 다르다**(어떤 계약을 포함하는지) — 정의를 확인하지 않고 회사 간 비교하면 안 된다. |
| **이연수익 / 계약부채** | 미리 받은 대금 중 아직 서비스로 제공하지 않은 부분(부채). 증가 추세는 선주문이 쌓인다는 신호로 읽는다. |
| **RPO** (잔여 이행 의무, Remaining Performance Obligation) | 계약은 체결됐으나 아직 매출로 인식되지 않은 총액. ASC 606에 따라 공시되며, 단기(12개월 내 인식) 비중을 함께 보면 가시성이 드러난다. |
| **백로그 / 수주잔고** (Backlog) | 수주는 받았지만 아직 납품·인식하지 않은 물량. 방산·인프라처럼 계약 주기가 긴 산업의 핵심 선행지표. **자금이 확보된 수주(funded)와 옵션 포함 총액을 구분**해야 한다. |
| **Book-to-Bill** | 신규 수주 ÷ 당기 매출. 1을 넘으면 쌓이는 중, 1 미만이면 소진 중. 장비·반도체·방산 업종의 사이클 판단에 쓴다. |
| **NRR / GRR** (순·총 매출유지율) | 기존 고객 집단이 1년 뒤 만들어내는 매출 비율. GRR은 이탈만 반영(100% 이하), NRR은 업셀까지 반영해 **100%를 넘을 수 있다** — NRR 120%는 신규 고객 없이도 20% 성장한다는 뜻. |
| **처n / 이탈률** (Churn) | 일정 기간 이탈한 고객·매출 비율. 고객 수 기준과 금액 기준이 다르므로 어느 쪽인지 밝힐 것. |
| **CAC / LTV** | 고객 1명을 데려오는 비용 / 그 고객이 평생 남기는 이익. LTV/CAC 배수와 **CAC 회수기간**(몇 개월 만에 회수되나)을 함께 본다. |
| **유닛 이코노믹스** | 고객·거래 1단위 기준의 수익성. 전체가 적자여도 단위 경제성이 흑자면 규모 확대로 해결될 여지가 있고, 반대면 성장할수록 손실이 커진다. |
| **TAM / SAM / SOM** | 전체 시장 / 접근 가능한 시장 / 실제로 얻을 수 있는 시장. 회사 IR 자료의 TAM은 관대하게 잡히는 경향이 있어 정의와 출처를 확인할 것. |
| **테이크레이트** (Take Rate) | 플랫폼이 거래액 중 수수료로 가져가는 비율. 거래소·마켓플레이스의 핵심 수익 구조. |
| **GMV / 거래대금** | 플랫폼에서 오간 거래 총액. 매출이 아니라 **매출의 기반**이므로 둘을 혼동하지 말 것. |
| **ARPU** | 사용자당 평균 매출. 사용자 수 성장과 수익화 중 어디서 성장이 나오는지 분해할 때 쓴다. |
| **DAU / MAU** | 일간·월간 활성 사용자. DAU/MAU 비율은 사용 밀착도(engagement)의 근사치. |
| **코호트 분석** | 가입 시기별로 고객 집단을 나눠 시간에 따른 매출·잔존을 추적하는 방법. 전체 평균이 감추는 신규·기존 고객의 차이를 드러낸다. |
| **Rule of 40** | 매출성장률(%) + FCF마진(또는 영업이익률, %) ≥ 40을 건전성 기준으로 보는 소프트웨어 업계 경험칙. 어떤 마진을 썼는지에 따라 값이 달라지므로 기준을 밝힐 것. |
| **매출 인식 (ASC 606)** | 언제·얼마를 매출로 잡을지 정하는 미국 회계기준. 라이선스를 일시 인식하는지 기간에 걸쳐 인식하는지에 따라 같은 계약도 실적 그림이 달라진다(EDA·소프트웨어에서 특히 중요). |
| **세그먼트 (Segment)** | 회사가 공시하는 사업부문별 실적. 부문별 마진 차이가 크면 전사 평균 지표는 의미가 흐려지므로 SOTP 평가의 근거가 된다. |
| **AUM / AUC** | 운용자산 / 수탁자산(보관만 하는 자산). 금융·디지털자산 기업에서 수수료 매출의 기반이 되지만 소유권 성격이 다르다. |
| **순이자수익 (NII)** | 금융회사가 이자수익에서 이자비용을 뺀 값. 금리 국면에 따라 크게 움직인다. |
| **Float (예치금 운용수익)** | 고객이 맡긴 자금을 운용해 얻는 수익. 스테이블코인·보험·증권사 모델에서 금리 민감도의 핵심이며, 금리가 내리면 직격탄을 맞는다. |
| **생산량 / 판매량** (Production / Sales Volume) | 자원개발(E&P) 기업이 일정 기간 실제로 판매한 물량. 천연가스는 관례적으로 Bcfe(십억 입방피트 등가, 액체는 열량 기준으로 가스로 환산)로 표기 — 생산량(produced)과 판매량(sold)이 다를 수 있으므로(재고·자가소비 등) 회사가 공시한 쪽 정의를 그대로 따를 것. |
| **실현 가격** (Realized Price) | 회사가 실제로 판매해 받은 단위당 가격($/Mcfe 등). 헤지 효과를 포함하는지(realized incl. hedges) 제외하는지(unhedged), 운송·품질 차감(basis differential)을 반영했는지에 따라 같은 이름이라도 값이 크게 갈리므로 정의를 반드시 병기. 헨리허브 등 벤치마크 가격과의 차이가 이 회사의 지역별 가격 결정력(또는 파이프라인 병목)을 보여준다. |
| **증명매장량** (Proved Reserves) | 현재 가격·기술로 경제성 있게 채굴 가능하다고 합리적 확신을 가진 매장량. 통상 Tcfe(조 입방피트 등가)로 표기하며, 매년 SEC 기준(연평균 가격)으로 제3자 평가를 받아 갱신된다 — 유가·가스 가격 가정에 따라 값 자체가 바뀌므로 평가 시점의 가격 가정을 확인할 것. |
| **매장량 수명** (Reserve Life / R/P Ratio) | 증명매장량 ÷ 연간 생산량(년). 지금 속도로 생산을 지속한다면 몇 년치 매장량이 남았는지의 근사치이며, 실제로는 신규 시추·매장량 추가로 계속 갱신되므로 "고갈까지 남은 시간"으로 오독하지 말 것. |
| **매장량 대체율** (Reserve Replacement Ratio) | 그해 늘어난 매장량 ÷ 그해 생산량(%). 100%를 밑돌면 파낸 만큼 채우지 못했다는 뜻이다. **증가분을 무엇으로 잡느냐가 핵심** — 신규 시추 성과인 `extensions·discoveries`만 세는지, 가격 변동으로 경제성이 바뀌어 생긴 `revisions of previous estimates`와 기업 인수(`purchase of reserves-in-place`)까지 합치는지에 따라 값이 몇 배로 갈린다. 회사가 앞세우는 수치는 대개 후자이므로, **시추만으로 대체하고 있는지 보려면 10-K 매장량 증감표에서 `extensions·discoveries`만 따로 떼어 생산량과 비교**할 것. |
| **PV-10 / 표준화된 측정치** (Standardized Measure) | 증명매장량에서 나올 미래 순현금흐름을 연 10%로 할인한 값(PV-10)과, 거기서 미래 법인세까지 차감한 값(표준화된 측정치). SEC가 정한 방식이라 회사 간 비교가 가능하지만 **시장가치가 아니다** — ⚠️ ① 가격을 직전 12개월 매월 1일 가격의 단순평균으로 고정하므로 상품가격이 오르내리면 값이 크게 출렁이고, ② 할인율이 실제 자본비용과 무관한 10% 고정이며, ③ 본사 관리비·이자비용·미탐사 자산 가치가 빠져 있다. 그래서 EV와 곧바로 비교하면 안 되고, **EV ÷ PV-10 배수의 시계열과 동종 비교**로 쓰는 것이 일반적이다. 평가에 쓰인 가격 전제를 반드시 함께 인용할 것. |
| **손익분기 가격** (Breakeven Price) | 잉여현금흐름(FCF)이 0이 되는 벤치마크 가격 수준($/MMBtu 등). 유지(maintenance) 생산 기준인지 성장(growth) capex를 포함하는지, 레버드(이자비용 포함)인지 언레버드인지에 따라 값이 크게 달라지므로 회사가 공시한 전제 조건을 그대로 인용할 것. |
| **액화 능력** (Liquefaction Capacity) | LNG 액화 플랜트가 1년에 생산할 수 있는 LNG 물량. 통상 **mtpa**(million tonnes per annum, 연간 백만 톤)로 표기한다. "가동 중(in operation)"·"건설 중(under construction)"·"인허가 진행 중(in permitting)"을 반드시 구분할 것 — 회사 홍보 자료는 셋을 합친 숫자를 앞세우는 경우가 많다. 설비 개선으로 정격을 넘겨 뽑아내는 여유분(디보틀네킹, debottlenecking)을 포함했는지도 정의에 따라 갈린다. |
| **SPA** (LNG 판매·구매 계약, Sale and Purchase Agreement) | LNG 생산자와 구매자가 맺는 장기 인수 계약. 대개 **고정 액화수수료(fixed liquefaction fee)** + 원료가스 가격에 연동되는 변동수수료(주로 헨리허브 연동)로 구성되며, 구매자가 인수를 취소·중단해도 고정수수료는 지급해야 하는 take-or-pay 성격을 띤다. 이 구조가 LNG 사업자의 현금흐름을 스팟가격 변동에서 절연시키는 핵심 장치다. |
| **IPM 계약** (Integrated Production Marketing) | 가스 생산자가 LNG 사업자에게 천연가스를 **국제 LNG·가스 지수 가격에서 고정 액화수수료·운송비를 뺀 가격**으로 파는 장기 계약. 사업자 입장에서 마진이 계약으로 고정되지만, 회계상 **파생상품으로 분류**돼 국제 가격이 움직일 때마다 잔여 계약 전체의 공정가치 변동이 당기 손익에 잡힌다 — 현금흐름과 무관하게 GAAP 손익이 크게 출렁이는 원인이므로, 이런 회사는 GAAP 순이익·PER 대신 Adjusted EBITDA 계열 지표로 봐야 한다. |
| **장기계약 체결 비율 / 계약 잔존 가중평균 만기** | 예상 생산량 중 장기계약(SPA·IPM)으로 확보된 비중(%)과, 그 계약들의 남은 기간을 물량으로 가중평균한 값(년). LNG·인프라 사업의 현금흐름 가시성을 나타내는 핵심 지표다. **계약기간 10년 미만 물량이나 미착공 설비를 전제로 한 조건부 계약을 포함했는지**에 따라 값이 달라지므로 회사 정의를 그대로 병기할 것. |
| **Distributable Cash Flow** (DCF, 배분가능현금흐름) | EBITDA에서 이자비용·현금세금·**유지보수 capex**를 뺀, 배당·자사주매입·차입금 상환에 쓸 수 있는 현금. 성장(growth) capex는 차감하지 않는다는 점에서 `CFO − CapEx` 방식의 FCF와 다르며, 대규모 신규 건설 중인 인프라 기업의 배당 여력을 볼 때 쓴다. ⚠️ **밸류에이션 방법론의 DCF(Discounted Cash Flow, 현금흐름할인법)와 약자가 같지만 완전히 다른 개념**이다 — 문서에서 쓸 때는 어느 쪽인지 풀어 적을 것. |
| **Segment EBDA** (부문 EBDA, Earnings Before DD&A) | 미드스트림 기업이 부문 실적을 공시할 때 쓰는 지표로, 부문 매출·지분법이익에서 매출원가·운영유지비·재산세를 뺀 값(감가상각·본사비용·이자·법인세 차감 전). **GAAP이 규정한 지표가 아니라 회사가 정의하는 지표**이며, 여기서 다시 일회성 항목을 뺀 것을 Adjusted Segment EBDA라 부른다. 미드스트림은 상품 판매 통과 매출이 커서 부문 "매출" 비중이 실제 이익 기여를 왜곡하므로, 사업 구성은 매출이 아니라 이 지표의 비중으로 본다. |
| **AFFO** (Available Funds from Operations) | 영업현금흐름에서 **유지(maintenance) capex만** 차감한, 배당 지급 여력을 나타내는 비GAAP 지표. 성장(growth) capex를 차감하지 않는다는 점에서 `CFO − CapEx` 방식의 FCF와 다르며, 개념적으로 Distributable Cash Flow와 같은 계열이다. 회사마다 이름과 조정 항목이 다르므로(AFFO / DCF / Adjusted FCF 등) 정의를 병기할 것. **AFFO ÷ 배당지급액 = 배당커버리지비율**로 배당 안전마진을 본다. |
| **수송 물량 / 계약 수송용량** (Transport volumes / Contracted capacity) | 파이프라인 사업의 물량 지표. **수송 물량**은 실제로 흘러간 양(유량, BBtu/d·Bcf/d)이고 **계약 수송용량**은 고객이 장기계약으로 예약해 둔 용량(잔고)이다. 계약 용량은 실제 사용 여부와 무관하게 요금(take-or-pay)을 받으므로 매출 가시성을 나타내고, 수송 물량은 수요 강도를 나타낸다 — **회사마다 둘 중 하나만 공시하는 경우가 많아 회사 간 직접 비교가 안 되므로**, 어느 쪽인지 확인하고 각 회사 안에서의 추세로만 읽을 것. |
| **프로젝트 백로그** (Project backlog, 인프라형) | 미드스트림·인프라 기업이 쓰는 백로그는 위 "백로그 / 수주잔고"와 달리 **미래 매출이 아니라 이사회 승인을 받아 실행 중인 확장 프로젝트의 투자비(capex) 총액**을 가리키는 경우가 많다. 함께 공시되는 **Project EBITDA 배수**(투자비 ÷ 가동 첫해 예상 EBITDA)가 낮을수록 자본 효율이 좋다는 뜻 — 어떤 프로젝트를 배수 계산에서 제외했는지(회사가 임의로 고른다)를 반드시 확인할 것. |
| **OE / 애프터마켓** (Original Equipment / Aftermarket) | 항공우주 부품사의 매출을 나누는 기본 축. **OE**는 신규 기체·엔진에 처음 장착되는 초도장착 매출로 완제기 OEM의 생산율에 실적이 묶이고, **애프터마켓**은 이미 운항 중인 기체의 교체 부품·수리 매출로 비행시간에 걸린다. 통상 애프터마켓 마진이 훨씬 높아 **같은 매출이라도 구성비에 따라 이익 체력이 다르다** — 회사 간 비교 전에 반드시 구성비를 확인할 것. 회사에 따라 방산(Defense)을 제3의 축으로 따로 공시하기도 한다. |
| **MRO** (정비·수리·오버홀, Maintenance, Repair and Overhaul) | 운항 중인 항공기·엔진을 점검·수리·분해정비하는 서비스 전체. 부품사에게는 애프터마켓 수요의 통로이자 고객이다. 처리 소요 시간(**TAT**, Turnaround Time)과 엔진 shop visit 대기 물량이 업계 처리 능력의 병목 지표로 쓰인다. |
| **형식증명 / 감항인증** (Type Certificate, Airworthiness) | 항공당국(미 FAA·유럽 EASA 등)이 특정 기종의 설계가 안전 기준을 충족함을 인증하는 것. **부품 단위까지 인증에 묶여 있어**, 부품을 다른 회사 제품으로 바꾸려면 부품이 아니라 인증을 다시 받아야 한다 — 재인증 비용이 부품값을 크게 웃돌기 때문에 설계 단계에서 채택된(design-in) 공급사가 기종 퇴역까지 유지되는 구조가 만들어진다. 항공우주 부품사의 가격 결정력을 설명할 때 근거로 드는 것이 대개 이 장벽이다. |
| **PMA / USM** (승인 대체부품·중고 부품, Parts Manufacturer Approval / Used Serviceable Material) | 순정(OEM) 부품을 대체하는 두 경로. **PMA**는 FAA가 별도 제조사의 대체 부품에 내주는 승인이고, **USM**은 퇴역기에서 회수해 재인증한 중고 부품이다. 둘 다 위 형식증명 장벽을 우회하는 통로라, 확산 여부가 순정 부품사의 가격 결정력을 좌우한다 — 항공우주 부품사를 볼 때 **Bear Case의 핵심 축**으로 다뤄야 하는 변수다. |
| **Shipset content** (기체 1대당 탑재액) | 항공기 한 대에 그 회사 부품이 금액 기준으로 얼마나 들어가는지. 신기종 채택 여부를 매출로 환산해 보는 지표이며, 기종별로 크게 다르므로 **어느 기종 기준인지 반드시 병기**할 것. 회사가 제시하는 값은 옵션 장착분까지 포함한 최대치인 경우가 많다. |
| **비행시간 / 사이클** (Flight Hours / Flight Cycles, FH·FC) | 애프터마켓 수요의 물리적 동인. 부품은 누적 **비행시간**(마모형)이나 누적 **이착륙 사이클**(피로형) 기준으로 교체·정비 주기가 정해져 있어, 여객 수요(RPK)보다 이 둘이 부품 소모에 더 직접적으로 연결된다. 단거리 노선이 많으면 같은 비행시간이라도 사이클이 빠르게 쌓인다. |

## 6. 밸류에이션 방법론 { #valuation }

> 📖 예시로 풀어 쓴 설명: [밸류에이션 방법론](./concepts/valuation.md)

### 6.1 상대가치 (배수) 방식

| 용어 | 뜻 |
|------|-----|
| **PER** (주가수익비율, Price to Earnings Ratio) | 주가 ÷ EPS. 적정주가 = EPS × 목표 PER. 이익이 안정적인 기업에 가장 널리 쓰이는 상대가치 지표. 적자 기업엔 부적합. |
| **PBR** (주가순자산비율, Price to Book Ratio) | 주가 ÷ BPS. 적정주가 = BPS × 목표 PBR. 순자산(장부가치) 대비 주가 수준. 금융/자산주나 적자 기업 평가에 유용하나, 대형 M&A로 자기자본이 단절적으로 급변하면 과거 평균 배수가 왜곡될 수 있음. |
| **PSR** (주가매출비율, Price to Sales Ratio) | 시가총액 ÷ 매출. 적자라 PER을 못 쓰는 고성장 기업에 쓰지만 **이익률을 전혀 반영하지 않으므로** 반드시 매출총이익률과 함께 볼 것 — 예시는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **EV/Sales** | EV ÷ 매출. PSR과 취지는 같으나 분자에 순부채를 포함해 자본구조 차이를 걷어낸 버전. 순차입이 큰 회사를 PSR로 비교하면 저평가로 보이는 착시가 생기므로 이쪽이 더 정확하다. |
| **EV/EBITDA** | EV ÷ EBITDA. 감가상각 정책·자본구조·세율 차이를 걷어내고 비교할 수 있어 M&A와 자본집약 산업에서 표준처럼 쓰인다. 단 CapEx가 큰 회사일수록 EBITDA는 실제 현금창출력을 과대평가한다(4. 수익성 · 효율성 · 안정성 심화 "EBITDA의 함정" 참고). |
| **EV/EBIT** | EV ÷ 영업이익. EV/EBITDA와 달리 감가상각을 비용으로 인정하므로, 설비 재투자 부담이 큰 회사를 볼 땐 이쪽이 더 보수적이고 현실적이다. |
| **PEG** (Price/Earnings to Growth) | PER ÷ 이익성장률(%). 통상 1 미만이면 저렴하다고 해석하지만, 성장률을 몇 년 기준으로 잡느냐에 따라 값이 크게 갈리므로 **기준 기간을 반드시 함께 표기**할 것 — 예시는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **FCF 수익률** (FCF Yield) | FCF ÷ 시가총액(또는 FCFPS ÷ 주가). "이 회사를 통째로 사면 매년 시총 대비 몇 %의 현금이 나오는가". 국채수익률과 직접 비교할 수 있어 금리 환경 변화의 영향을 가늠하기 좋다. |
| **이익수익률** (Earnings Yield) | EPS ÷ 주가 = PER의 역수. PER 25배 = 이익수익률 4%. 국채수익률과 나란히 놓고 "주식이 채권 대비 얼마나 보상해주는가"를 볼 때 쓴다. |
| **배당수익률 기준 평가** | DPS ÷ 주가. 성숙한 배당주에서 과거 배당수익률 밴드의 상단(주가가 싼 구간)·하단을 비교 잣대로 삼는 방식. 배당 삭감 위험이 있으면 무의미해지므로 배당성향·FCF 커버리지와 함께 볼 것. |
| **목표 PER / 목표 PBR** | 적정주가 계산에 곱하는 배수 가정. 동종업계 평균이나 과거 N년 평균을 근거로 삼되, 근거와 신뢰도(High/Medium/Low)를 함께 기록. |
| **배수 확장 / 축소** (Multiple expansion/contraction) | 이익이 그대로여도 시장이 매기는 PER 자체가 오르내리며 주가가 변하는 현상. 주가 상승을 "이익 성장분"과 "배수 변화분"으로 분해해보면, 그 상승이 실적 때문인지 분위기 때문인지 구분된다. |
| **동종업계 비교** (Comparables, Comps) | 유사 기업의 배수와 나란히 놓고 상대적 위치를 보는 것. 사업 구조·성장률·마진이 실제로 비슷한지 먼저 따지지 않으면 "같은 섹터"라는 이유만으로 엉뚱한 회사와 비교하게 된다. |

### 6.2 절대가치 (현금흐름 할인) 방식

| 용어 | 뜻 |
|------|-----|
| **DCF** (현금흐름할인법, Discounted Cash Flow) | 미래 잉여현금흐름을 할인해 내재가치를 산정하는 절대가치 방식. **할인율과 현금흐름의 짝을 맞추는 것이 전제** — 아래 "FCFE / FCFF" 항목을 반드시 먼저 볼 것. |
| **FCFE / FCFF — 할인율 정합성** | **FCFE**(주주 귀속, 실무상 ≈ `CFO − CapEx`)는 **자기자본비용(Ke)**으로, **FCFF**(기업 전체 귀속)는 **WACC**로 할인해 EV를 구한 뒤 순부채를 차감한다 — 둘을 섞으면(예: FCFE를 WACC로 할인) 결과가 틀린다. 오차 크기를 숫자로 보려면 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **Gordon growth 모델 (1단계 DCF)** | DCF의 가장 단순한 형태: 주주가치/주 ≈ FCFEPS × (1+g) ÷ (Ke − g)(FCFF 기준이면 같은 식으로 EV를 구한 뒤 순부채 차감). 실제 성장률이 g보다 훨씬 높은 고성장 기업엔 구조적으로 낮은 값이 나오므로 **2단계 모델**을 쓰거나 한계를 명시할 것 — 민감도 예시는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **2단계 / 다단계 DCF** | 명시적 예측기간(보통 5~10년)의 현금흐름을 연도별로 할인하고, 그 이후는 터미널 밸류로 한 번에 처리하는 방식. 고성장 기업의 표준 접근. |
| **터미널 밸류** (TV, 잔존가치) | 명시적 예측기간 이후의 가치를 한 덩어리로 계산한 값. 영구성장 방식(`FCF×(1+g) ÷ (r−g)`)이나 출구배수 방식(`최종연도 EBITDA × 목표 EV/EBITDA`)을 쓰며, **DCF 총가치의 60~80%가 여기서 나오는 경우가 흔하므로** 비중을 반드시 밝힐 것. |
| **영구성장률 (g)** | DCF에서 예측 기간 이후 현금흐름이 영원히 성장한다고 가정하는 비율. 통상 장기 명목 GDP 성장률(2~3%) 근사치를 씀. **g가 장기 경제성장률을 넘으면 그 회사가 언젠가 경제 전체보다 커진다는 뜻**이 되므로 성립하지 않는다. |
| **DDM** (배당할인모형, Dividend Discount Model) | 미래 배당금을 요구수익률로 할인해 내재가치를 산정. 배당이 안정적인 성숙기업에 적합. 무배당 기업엔 적용 불가. |
| **NPV** (순현재가치) | 미래 현금흐름의 현재가치 합계 − 초기 투자액. 0보다 크면 그 투자는 요구수익률을 넘는다는 뜻. DCF의 기본 원리 자체다. |
| **IRR** (내부수익률) | NPV를 0으로 만드는 할인율. "이 투자가 연 몇 %의 수익률인가"로 읽는다. 현금흐름 부호가 여러 번 바뀌면 해가 여러 개 나올 수 있어 NPV와 함께 봐야 한다. |
| **현재가치 / 할인** | 미래의 1달러는 오늘의 1달러보다 가치가 낮다(그동안 굴릴 수 있었으므로). 이 차이를 되돌리는 계산이 할인이며, 할인율이 높을수록·시점이 멀수록 현재가치는 작아진다(성장주가 금리에 더 민감한 이유는 9. 거시경제 "금리가 주가에 닿는 두 경로" 참고). |
| **SOTP** (부문별 합산가치, Sum of the Parts) | 사업부별로 각각 다른 방법론·배수를 적용해 가치를 매기고 합산한 뒤, 순부채와 지주회사 할인을 조정하는 방식 — 성격이 다른 사업을 겸영하는 회사에 단일 배수보다 타당하다. 계산 예시는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **잔여이익모형** (RIM, Residual Income Model) | 가치 = 현재 자기자본 장부가 + 미래 초과이익(순이익 − 자기자본비용×자기자본)의 현재가치. 상당 부분이 이미 확정된 장부가에서 나와 터미널 밸류 의존도가 낮다(금융회사 평가에 자주 쓰임) — 수치 예시는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **청산가치** (Liquidation Value) | 자산을 모두 팔고 부채를 갚았을 때 남는 값. 계속기업 가정이 흔들리는 회사의 하방 기준선으로 쓴다. |
| **DCF 민감도 분석** | 할인율·g 가정을 조금씩 바꿔가며 DCF 적정주가가 얼마나 흔들리는지 보는 표. `(할인율−g)`가 작을수록 민감도가 커짐. |
| **시나리오 분석** | 낙관/기본/보수 세 가지 가정 묶음으로 각각 값을 내는 것. 민감도 분석이 "변수 하나씩"을 흔든다면, 시나리오는 "서로 연관된 변수들을 한꺼번에" 흔든다(예: 침체 시 매출↓·마진↓·배수↓가 동시에). |
| **역DCF** (Reverse DCF) | 현재 주가를 정당화하려면 어떤 성장률·마진이 필요한지 거꾸로 푸는 방법 — **"시장은 지금 무엇을 가정하고 있나"**를 묻는 유용한 교차검증이다. 계산 예시는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |

### 6.3 할인율 구성요소

| 용어 | 뜻 |
|------|-----|
| **WACC** (가중평균자본비용, Weighted Average Cost of Capital) | 자기자본비용과 타인자본비용을 자본구조 비중으로 가중평균한 값. 공식: `Ke × E/(D+E) + Kd × (1−t) × D/(D+E)` — 어느 현금흐름과 짝을 이루는지는 위 FCFE/FCFF 항목 참고. |
| **자기자본비용 (Ke)** | 주주가 이 주식에 요구하는 수익률. 보통 CAPM으로 추정한다: `Ke = 무위험이자율 + β × 시장위험프리미엄`. FCFE 기준 DCF의 할인율은 WACC가 아니라 이 값이다. |
| **CAPM** (자본자산가격결정모형) | 위험이 큰 자산일수록 더 높은 기대수익률을 요구한다는 모형. 실무에서 Ke를 구하는 가장 흔한 방법이지만, 베타 추정 기간·시장 지수 선택에 따라 결과가 꽤 달라진다는 한계를 안고 쓴다. |
| **무위험이자율 (Rf)** | 위험이 없다고 간주하는 수익률. 통상 미국 10년물 국채수익률을 쓴다. **DCF 대상 현금흐름의 기간과 만기를 맞추는 것**이 원칙(장기 현금흐름엔 10년물·30년물). |
| **베타 (β)** | 시장 전체가 1% 움직일 때 이 주식이 몇 % 움직이는지. 1보다 크면 시장보다 변동이 크다는 뜻. 추정 기간(2년/5년)과 비교 지수에 따라 값이 달라지므로 어느 기준인지 밝힐 것. |
| **시장위험프리미엄 (ERP)** | 주식시장 전체가 무위험이자율 대비 추가로 요구되는 수익률. 통상 4~6% 범위의 추정치가 쓰이며, 출처마다 편차가 크므로 **한 값으로 단정하지 말고 범위로 기록**한다. |
| **타인자본비용 (Kd)** | 회사가 부채로 자금을 조달할 때 부담하는 이자율. 이자비용 ÷ 평균 이자부 차입금으로 근사하거나 신용등급 기준 시장 금리를 쓰며, 세후(`Kd×(1−t)`) 기준으로 WACC에 넣는다 — 이유는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **규모 프리미엄 / 국가 위험 프리미엄** | 소형주나 신흥국 기업에 CAPM 결과 위로 추가하는 할인율 가산분. 자의성이 크므로 얼마를 왜 더했는지 반드시 밝힐 것. |
| **요구수익률 (r)** | 투자자가 이 자산에 최소한 기대하는 수익률. DDM의 할인율이며, 주식에서는 대개 Ke와 같은 뜻으로 쓴다. |
| **자본비용 vs 기대수익률** | 회사 입장에서는 "자본을 쓰는 대가(비용)", 투자자 입장에서는 "요구하는 수익률"로, 같은 숫자를 양쪽에서 부르는 이름이다. |

### 6.4 결과 해석

| 용어 | 뜻 |
|------|-----|
| **괴리율** | (실제주가 ÷ 종합 적정주가 − 1) × 100. 양수면 고평가, 음수면 저평가를 의미. |
| **목표주가 / 적정주가** | 방법론별로 산출한 값과, 그 값들을 신뢰도로 가중평균한 종합값. 단순 평균은 이상치 하나에 쉽게 왜곡되므로 신뢰도 가중이 기본값. |
| **안전마진** (Margin of Safety) | 내재가치 추정이 틀릴 가능성에 대비해, 적정주가보다 충분히 낮은 가격에서만 사는 완충폭. 추정이 정교해서가 아니라 **틀릴 것을 전제로** 두는 장치다. |
| **내재가치 vs 시장가격** | 내재가치는 현금흐름 기반으로 계산한 값, 시장가격은 실제 거래되는 값. 둘이 다르다는 관찰만으로는 아무것도 증명되지 않는다 — 시장이 틀렸을 수도, 내 가정이 틀렸을 수도 있다. |
| **가치 함정** (Value Trap) | 배수가 싸 보여서 샀는데 실적이 계속 나빠져 계속 싼 상태로 남는 경우. "싸다"는 것과 "좋다"는 것은 다른 판단이다. |

## 7. 투자 판단 / 거버넌스 용어 { #investment-terms }

> 📖 예시로 풀어 쓴 설명: [투자 판단 / 거버넌스 용어](./concepts/investment-terms.md)

| 용어 | 뜻 |
|------|-----|
| **Bull Case / Bear Case** | Bull Case는 투자를 지지하는 강점·논리, Bear Case는 반대로 우려되는 리스크·약점. |
| **Moat (경쟁 해자)** | 경쟁사가 쉽게 넘볼 수 없는 진입장벽. 브랜드, 전환비용, 네트워크 효과, 규모의 경제 등. |
| **전환비용** (Switching Cost) | 고객이 경쟁 제품으로 갈아탈 때 드는 비용·수고. 설계 도구나 기간 시스템처럼 업무 흐름에 깊이 박힌 제품일수록 높다. |
| **네트워크 효과** | 사용자가 늘수록 제품 가치가 커지는 성질. 거래소·플랫폼의 핵심 해자이며, 반대로 임계점 아래로 떨어지면 같은 속도로 무너진다. |
| **규모의 경제** | 생산량이 늘수록 단위당 원가가 낮아지는 효과. |
| **가격 결정력** (Pricing Power) | 수요를 크게 잃지 않고 가격을 올릴 수 있는 힘. 인플레이션 국면에서 마진을 지키는지 여부로 드러난다. |
| **트리거** | `06_valuation.md`의 트리거는 밸류에이션 숫자만으로 정하는 가격 레벨, `07_investment.md`의 트리거는 거기에 리스크·정성적 조건까지 합친 최종 매수/매도 기준 — 두 문서에서 뜻이 다르므로 섞어 쓰지 않음. |
| **투자 논거** (Thesis) | "이 회사에 투자하는 이유"를 한 문단으로 정리한 것. 논거가 깨지는 조건(thesis breaker)을 함께 적어둬야 나중에 판단을 복기할 수 있다. |
| **촉매** (Catalyst) | 가치가 주가에 반영되게 만들 만한 구체적 사건(신제품, 규제 승인, 수주, 분사 등). |
| **10-K / 10-Q / 8-K** | 미국 상장사의 연간보고서 / 분기보고서 / 수시보고서(중요 사건 발생 시). 이 레포에서 가장 신뢰도가 높은 1차 출처. |
| **S-1** | IPO를 위한 최초 등록신고서. 상장 전 재무·리스크가 처음 공개되는 문서다. |
| **위임장 (Proxy Statement, DEF 14A)** | 미국 상장사가 주주총회 전 공시하는 문서. 경영진 보상·지분 등 거버넌스 정보의 공식 출처. |
| **13F / Form 4** | 13F는 운용자산 1억 달러 이상 기관의 분기말 보유 종목 공시(45일 시차가 있어 과거 정보임), Form 4는 내부자의 매매 신고(2영업일 내). |
| **MD&A** | 10-K/10-Q 안에서 경영진이 실적 변동 이유를 직접 설명하는 절. 숫자만으로 안 보이는 맥락이 여기 있다. |
| **어닝콜 / 어닝서프라이즈** | 실적 발표 후 경영진이 진행하는 설명회 / 실제 실적이 컨센서스를 상회·하회한 정도. |
| **차등의결권 (Dual-class)** | 보통주와 의결권이 다른 주식 클래스를 함께 발행하는 구조. 창업자가 지분율보다 훨씬 큰 의결권을 갖는 경우가 많아 지배구조 리스크로 봄. |
| **기관/내부자 지분율** | 기관 투자자(펀드·연기금 등)와 내부자(임원·이사)가 각각 보유한 지분 비율. 내부자 지분이 높으면 이해관계 일치, 지나치게 높으면 소액주주 권리 약화 우려로 해석. |
| **자본 배분** (Capital Allocation) | 벌어들인 현금을 재투자·인수·배당·자사주매입·부채상환 중 어디에 쓰는가에 대한 경영진의 선택. 장기 수익률을 가르는 핵심 능력으로 본다. |
| **경영진 보상 구조** | 보상이 무엇에 연동되는지(매출 성장·EPS·TSR 등). 지표 선택이 경영진의 행동을 만들기 때문에 위임장에서 확인할 가치가 있다. |
| **행동주의 투자자** (Activist) | 지분을 확보해 이사회 교체·분사·환원 확대 등을 요구하는 투자자. |

## 8. 리스크 · 회계 품질 { #risk }

> 📖 예시로 풀어 쓴 설명: [리스크 · 회계 품질](./concepts/risk-and-quality.md)
>
> Bear Case(7. 투자 판단 / 거버넌스 용어)를 구체적으로 쓰려면, "무엇이 위험인가"를 종류별로 나눠 볼 수 있어야 합니다.

| 용어 | 뜻 |
|------|-----|
| **체계적 위험 vs 비체계적 위험** | 시장 전체에 작용해 분산으로 없앨 수 없는 위험(금리·경기·전쟁) vs 개별 기업 고유의 위험(리콜·소송·경영진). 분산투자로 줄일 수 있는 것은 후자뿐이다. |
| **분산투자** | 상관관계가 낮은 자산에 나눠 담아 전체 변동성을 줄이는 것. 같은 섹터 종목을 여러 개 담는 것은 분산 효과가 제한적이다. |
| **변동성 / 표준편차** | 수익률이 얼마나 출렁이는지. 위험의 대용치로 널리 쓰이지만 "손실 가능성"과 정확히 같은 개념은 아니다. |
| **최대낙폭 (MDD)** | 고점 대비 최대 하락폭. 실제로 견뎌야 하는 고통의 크기를 변동성보다 직관적으로 보여준다. |
| **샤프 비율 / 소르티노 비율** | 위험 1단위당 초과수익 / 하락 변동성만으로 계산한 버전. 상승 변동성까지 위험으로 세는 샤프의 한계를 보완한다. |
| **VaR (Value at Risk)** | 일정 확률 안에서 예상되는 최대 손실액. 꼬리 위험(극단 상황)을 과소평가한다는 비판이 있다. |
| **집중 위험** | 특정 고객·제품·지역에 매출이 쏠려 있는 상태. 10-K의 고객 집중도 공시(매출 10% 이상 고객)에서 확인한다. |
| **키맨 리스크** | 창업자·핵심 인물 의존도. 차등의결권과 겹치면 영향이 커진다. |
| **규제 / 정책 리스크** | 인허가·독점금지·수출통제·세제 변화 등 외부 규칙 변경 위험. 금융·디지털자산·방산에서 특히 크다. |
| **환위험 / 금리위험 / 신용위험** | 환율 변동 / 금리 변동 / 거래 상대의 채무불이행에서 오는 위험. |
| **유동성 위험** | 필요한 때 자산을 제값에 팔지 못할 위험. 소형주와 비상장 자산에서 크다. |
| **희석 위험** | 증자·전환사채·SBC로 주식수가 늘어 기존 주주 몫이 줄어들 위험. |
| **이익의 질 (Earnings Quality)** | 회계 이익이 실제 현금과 얼마나 일치하는지. **CFO가 순이익을 지속적으로 밑돌면** 이익이 현금으로 뒷받침되지 않는다는 뜻이라 우선 의심 대상이다. |
| **발생액 (Accruals)** | 순이익 − 영업현금흐름. 크고 지속적으로 양수면 이익이 회계적 추정에 많이 기대고 있다는 신호. |
| **매출채권·재고 급증** | 매출 증가율을 크게 웃도는 매출채권·재고 증가는 밀어내기 판매나 수요 둔화의 조기 신호일 수 있다(4. 수익성 · 효율성 · 안정성 심화의 DSO·DIO로 확인). |
| **채널 스터핑** | 유통망에 물건을 밀어넣어 매출을 앞당겨 인식하는 관행. 다음 분기 매출을 당겨쓴 것이라 반작용이 따른다. |
| **잦은 일회성 비용** | "일회성"이 매년 반복되면 그건 사실상 경상 비용이다. Non-GAAP 조정 항목의 3~5년 추이를 보면 드러난다. |
| **회계정책 변경 / 재작성 (Restatement)** | 추정·정책을 바꾸거나 과거 재무제표를 다시 발표하는 것. 재작성은 심각한 신호로 취급한다. |
| **감사의견** | 적정 / 한정 / 부적정 / 의견거절. 적정이 아니면 그 자체로 중대한 경고다. |
| **계속기업 불확실성 (Going Concern)** | 감사인이 1년 내 존속 능력에 의문을 표시한 것. |
| **내부통제 중요한 취약점 (Material Weakness)** | 재무보고 내부통제에 중대한 결함이 있다는 공시. 숫자 자체의 신뢰도를 떨어뜨린다. |
| **특수관계자 거래** | 경영진·대주주·관계사와의 거래. 조건이 공정한지 주석에서 확인할 필요가 있다. |
| **우발부채 / 소송** | 아직 확정되지 않았지만 현실화되면 부담이 되는 채무. 주석에 있다. |
| **Altman Z-Score** | 여러 재무비율을 결합해 부도 가능성을 점수화한 모형. 제조업 기반이라 금융·소프트웨어엔 잘 맞지 않는다. |
| **Piotroski F-Score** | 수익성·레버리지·효율성 9개 항목을 0/1로 채점해 재무 개선 여부를 보는 지표(0~9). |
| **Beneish M-Score** | 회계 조작 가능성을 추정하는 모형. 어디까지나 선별 도구이지 판정 도구가 아니다. |
| **공매도 리포트** | 공매도 투자자가 공개하는 부정적 분석. 이해관계가 있으므로 주장과 증거를 분리해서 검증한다. |
| **생존 편향** | 실패한 사례가 표본에서 빠져 과거 성과가 실제보다 좋아 보이는 착시. |
| **확증 편향** | 자기 논거를 지지하는 정보만 찾는 경향. Bull/Bear Case를 둘 다 쓰게 하는 규칙이 이 편향에 대한 장치다. |

## 9. 거시경제 { #macro }

> 📖 예시로 풀어 쓴 설명: [거시경제](./concepts/macroeconomics.md)
>
> ⚠️ 아래 지표들의 **현재 수준은 여기 적지 않는다.** 계속 바뀌므로 항상 원출처(FRED, BLS, 연준, 미 재무부)에서 확인할 것. 여기서는 "그 지표가 무엇이고 주가에 어떤 경로로 닿는가"만 다룬다.

| 용어 | 뜻 |
|------|-----|
| **GDP (국내총생산)** | 한 나라에서 일정 기간 생산된 최종 재화·서비스의 총가치. **명목**은 그해 가격 기준, **실질**은 물가 변동을 제거한 기준. 경제 규모와 성장 속도의 기본 척도. |
| **경기순환** | 확장 → 정점 → 수축 → 저점을 반복하는 흐름. 업종마다 이 국면에 대한 민감도(경기민감주 vs 경기방어주)가 다르다. |
| **경기침체 (Recession)** | 통상 "실질 GDP 2개 분기 연속 마이너스"를 기술적 침체라 부르지만, 미국의 공식 판정은 NBER이 고용·소득·생산 등을 종합해 사후에 내린다. |
| **인플레이션 / 디플레이션** | 물가가 지속적으로 오르는 것 / 내리는 것. **디스인플레이션**은 물가가 여전히 오르되 상승 속도가 둔화되는 것으로, 디플레이션과 전혀 다르다. |
| **CPI / 근원 CPI** | 소비자물가지수 / 변동성이 큰 식품·에너지를 뺀 지수. 근원 지표를 보는 이유는 추세를 더 안정적으로 보기 위해서다. |
| **PCE / 근원 PCE** | 개인소비지출 물가지수. **연준이 정책 판단에 주로 참고하는 물가 지표**로, 소비 대체 효과를 반영해 통상 CPI보다 낮게 나오는 경향이 있다. |
| **스태그플레이션** | 성장은 정체되는데 물가는 오르는 상태. 금리를 올리면 성장이 더 꺾이고 내리면 물가가 더 오르므로 정책 대응이 가장 까다롭다. |
| **기준금리 (연방기금금리)** | 미국 중앙은행이 목표 범위를 정하는 초단기 금리. 모든 자산 가격의 출발점이며, DCF의 무위험이자율을 통해 밸류에이션에 직접 닿는다. |
| **연준 / FOMC / 점도표** | 미국 중앙은행(Fed) / 통화정책을 결정하는 위원회 / 위원들의 향후 금리 전망 분포도. 실제 결정보다 **전망의 변화**가 시장을 더 크게 움직이는 경우가 많다. |
| **QE / QT (양적완화·긴축)** | 중앙은행이 채권을 사들여 유동성을 공급하는 것 / 보유 자산을 줄여 회수하는 것. 기준금리 외의 또 다른 정책 축. |
| **테이퍼링** | 자산 매입 규모를 점진적으로 줄이는 것. 완화의 축소이지 긴축 그 자체는 아니다. |
| **국채수익률 (Treasury Yield)** | 미 국채의 수익률. 2년물은 정책금리 기대를, 10년물은 장기 성장·물가 기대를 반영한다. **10년물은 DCF 무위험이자율의 표준 근거**다. |
| **수익률곡선 / 장단기 금리차** | 만기별 국채 수익률을 이은 곡선. 장기물이 단기물보다 낮아지는 **역전**은 역사적으로 침체의 선행 신호로 주목받아 왔지만, 시차가 길고 예외도 있어 단독 근거로 쓰긴 어렵다. |
| **실질금리** | 명목금리 − 기대인플레이션. 자산 가격에 실제로 작용하는 것은 명목이 아니라 실질금리다. |
| **신용스프레드** | 회사채 수익률 − 같은 만기 국채 수익률. 벌어지면 시장이 부도 위험을 더 크게 본다는 뜻으로, 위험선호의 온도계 역할을 한다. |
| **고용지표 (실업률 / 비농업고용 / JOLTS)** | 실업률, 매월 발표되는 비농업 부문 신규 고용, 구인·이직 통계. 연준의 두 가지 임무(물가 안정·최대 고용) 중 한 축이라 금리 경로 전망에 직접 영향을 준다. |
| **PMI / ISM** | 구매관리자지수. 50을 넘으면 확장, 밑돌면 위축으로 읽는 설문 기반 선행지표. |
| **소비자심리지수 / 소매판매** | 가계의 체감 경기와 실제 지출. 미국 GDP의 약 3분의 2가 소비라 중요도가 높다. |
| **환율 / 달러인덱스 (DXY)** | 통화 간 교환 비율 / 주요 통화 대비 달러 가치 지수. 달러 강세는 미국 기업의 해외 매출을 환산 시 줄이므로, 해외 비중이 큰 기업의 실적에 직접 작용한다(3. 표기 규칙 "상수통화 기준" 참고). |
| **무역수지 / 경상수지** | 상품·서비스 수출입 차액 / 여기에 소득·이전을 포함한 대외 거래 수지. |
| **관세 / 수출규제** | 수입품에 부과하는 세금 / 특정 기술·품목의 수출 제한. 공급망을 가진 기업엔 원가와 시장 접근성 양쪽에 작용하는 정책 리스크다. |
| **재정정책 vs 통화정책** | 정부의 지출·세금 조절 vs 중앙은행의 금리·유동성 조절. 방산·인프라처럼 정부 예산에 매출이 걸린 업종은 재정정책의 영향을 직접 받는다. |
| **원자재 가격 (유가 등)** | 에너지·금속 등의 가격. 원가 구조에 직접 들어가는 동시에 인플레이션 경로를 통해 금리에도 영향을 준다. |
| **M2 (통화량)** | 현금·예금 등 시중 통화의 총량. 유동성 환경을 보는 지표. |
| **소프트랜딩 / 하드랜딩** | 금리 인상으로 물가를 잡으면서 침체는 피하는 시나리오 / 침체를 동반하는 시나리오. |
| **필립스 곡선** | 실업률과 인플레이션의 역관계를 나타낸 경험적 관계. 최근에는 잘 들어맞지 않는 국면이 잦아 참고 틀 정도로 쓴다. |
| **금리가 주가에 닿는 두 경로** | ① **할인율**: 금리↑ → 요구수익률↑ → 현재가치↓(먼 미래 현금흐름이 큰 성장주가 더 크게 하락). ② **실적**: 금리↑ → 소비·투자 위축 → 매출·이익↓, 차입 많은 기업은 이자 부담↑. |

## 10. 시장 구조 · 거래 { #market }

> 📖 예시로 풀어 쓴 설명: [시장 구조 · 거래](./concepts/market-structure.md)

| 용어 | 뜻 |
|------|-----|
| **시가총액** | 주가 × 발행주식수. 통상 대형(100억 달러 이상)·중형·소형·마이크로로 나눠 부르며, 규모에 따라 유동성과 변동성이 크게 다르다. |
| **유통주식수 (Float)** | 실제 시장에서 거래 가능한 주식수(내부자·전략적 보유분 제외). Float이 작으면 적은 거래에도 주가가 크게 흔들린다. |
| **유동성 / 호가 스프레드** | 원하는 가격에 원하는 만큼 사고팔 수 있는 정도 / 매수·매도 호가 간 간격. 스프레드가 넓으면 드나드는 것만으로 비용이 발생한다. |
| **지수 (Index)** | S&P 500·나스닥 100·러셀 2000 등 시장을 대표하는 종목 묶음. 성과 비교 기준(벤치마크)이자 패시브 자금의 투자 대상이다. |
| **패시브 / ETF** | 지수를 그대로 따라가는 운용 방식 / 그런 펀드를 주식처럼 거래하게 만든 상품. **지수 편입·편출**은 패시브 자금의 기계적 매매를 유발해 실적과 무관한 주가 변동을 만든다. |
| **IPO / 직상장 / SPAC** | 신주를 발행해 자금을 조달하며 상장 / 신주 발행 없이 기존 주식만 상장 / 이미 상장된 껍데기 회사와 합병해 우회 상장. 조달 여부와 희석 규모가 서로 다르다. |
| **락업 (Lock-up)** | 상장 후 기존 주주의 매도를 일정 기간 제한하는 약정. **해제일 전후로 매물 부담**이 생기므로 상장 초기 기업은 해제 시점을 확인한다. |
| **유상증자 / ATM 발행** | 신주를 발행해 자금을 조달하는 것 / 시장가로 조금씩 나눠 발행하는 방식. 둘 다 기존 주주 지분을 희석하므로 조달 목적과 규모를 따진다. |
| **전환사채 (CB)** | 나중에 주식으로 바꿀 수 있는 채권. 부채이면서 잠재적 희석 요인이라 희석주식수 계산에 영향을 준다. |
| **자사주 소각** | 사들인 자기 주식을 없애 발행주식수를 실제로 줄이는 것. 소각하지 않고 보유만 하면 나중에 재사용될 수 있어 희석 방지 효과가 확정되지 않는다. |
| **배당락 / 배당기준일 / 지급일** | 배당 권리가 떨어져 이론상 그만큼 주가가 조정되는 날(미국 T+1 결제 기준 배당기준일 하루 전) / 배당 받을 주주를 확정하는 날 / 실제 지급일. |
| **주식분할 / 역분할** | 1주를 여러 주로 나누기 / 여러 주를 1주로 합치기. 기업 가치는 변하지 않으며, 과거 데이터는 소급조정이 필요하다(3. 표기 규칙 "스톡스플릿 소급조정" 참고). |
| **공매도 / 대차잔고 / 숏스퀴즈** | 빌려서 판 뒤 되사서 갚는 거래 / 빌려간 주식 잔량 / 주가 급등 시 공매도 세력이 손실을 줄이려 되사면서 상승이 증폭되는 현상. |
| **옵션 (콜 / 풋)** | 정해진 가격에 살 권리 / 팔 권리. 개별 종목 옵션 거래가 과열되면 기초 주식의 변동성이 함께 커지기도 한다. |
| **시간외 거래** | 정규장 밖 거래. 실적 발표가 대개 장 마감 후에 나오므로 주가 반응이 여기서 먼저 나타난다. |
| **서킷브레이커 / 거래정지** | 급격한 변동 시 거래를 일시 중단하는 제도. |
| **블록딜** | 대량 지분을 장외에서 한 번에 넘기는 거래. 통상 할인 가격에 이뤄져 단기 주가에 부담을 준다. |
| **실적 시즌 / 블랙아웃** | 분기 실적이 몰려 발표되는 기간 / 실적 발표 직전 회사가 소통을 자제하는 기간. |
| **벤치마크 / 초과수익 (알파)** | 성과를 재는 기준 지수 / 그 기준을 넘어선 수익률. |
| **베타 (시장민감도)** | 6.3 할인율 구성요소의 베타와 같은 개념으로, 거래 관점에서는 "시장이 흔들릴 때 이 종목이 얼마나 더 흔들리나"로 읽는다. |
