# Company Research — 용어집

`.template/company/`·`.template/sector/`의 문서들이 설명 없이 바로 쓰는 용어를 한 곳에 모은 참고 문서입니다. 특정 회사·섹터에 종속되지 않는 내용이라 `docs/meta/`에 `.template/`·`concepts/`와 함께 둡니다.

> ⚠️ 이 문서는 **일반적인 정의**만 다룬다. 특정 회사 문서(`06_valuation.md` 등)에 그 회사만의 가정·근거가 각주로 따로 적혀 있다면 그쪽이 우선한다 — 여기서 개념을 확인하고, 실제 계산 방식은 항상 해당 회사 문서에서 확인할 것.
>
> 여기 표는 **빠르게 찾아보는 용도**라 정의가 1~2문장으로 압축돼 있다. 공식이 왜 그렇게 생겼는지, 실제 숫자로 계산하면 어떻게 되는지 제대로 이해하고 싶다면 각 절 제목 아래 링크된 `concepts/` 학습용 문서(맨 아래 "관련 문서"에 전체 목록)를 참고할 것.

## 1. 밸류에이션 방법론 { #valuation }

> 📖 예시로 풀어 쓴 설명: [`concepts/valuation.md`](./concepts/valuation.md)

| 용어 | 뜻 |
|------|-----|
| **PER** (주가수익비율, Price to Earnings Ratio) | 주가 ÷ EPS. 적정주가 = EPS × 목표 PER. 이익이 안정적인 기업에 가장 널리 쓰이는 상대가치 지표. 적자 기업엔 부적합. |
| **PBR** (주가순자산비율, Price to Book Ratio) | 주가 ÷ BPS. 적정주가 = BPS × 목표 PBR. 순자산(장부가치) 대비 주가 수준. 금융/자산주나 적자 기업 평가에 유용하나, 대형 M&A로 자기자본이 단절적으로 급변하면 과거 평균 배수가 왜곡될 수 있음. |
| **DCF** (현금흐름할인법, Discounted Cash Flow) | 미래 잉여현금흐름을 할인해 내재가치를 산정하는 절대가치 방식. **할인율과 현금흐름의 짝을 맞추는 것이 전제** — 아래 "FCFE / FCFF" 항목을 반드시 먼저 볼 것. |
| **FCFE / FCFF — 할인율 정합성** | **FCFE**(주주 귀속 현금흐름, 실무상 ≈ `CFO − CapEx`. 미국 GAAP에서 지급이자가 이미 CFO에서 차감돼 있어 "레버드" 현금흐름임)는 **자기자본비용(Ke)**으로 할인해 곧바로 주주가치를 얻는다. **FCFF**(기업 전체 귀속, ≈ EBIT×(1−t) + D&A − CapEx − ΔWC)는 **WACC**로 할인해 **기업가치(EV)**를 얻고, 거기서 **순부채를 빼야** 주주가치가 된다. `CFO − CapEx`를 WACC로 할인한 뒤 순부채를 빼지 않는 조합은 두 방식을 섞은 것이라 결과가 틀린다 — 순차입이 큰 회사는 과대, 순현금이 큰 회사는 과소평가된다. |
| **Gordon growth 모델 (1단계 DCF)** | DCF의 가장 단순한 형태: 주주가치/주 ≈ FCFEPS × (1+g) ÷ (Ke − g) (FCFF를 쓰면 같은 식으로 EV를 구한 뒤 순부채를 차감). `(할인율 − g)`가 작을수록 g 변화에 결과가 크게 흔들리고, 실제 성장률이 g보다 훨씬 높은 고성장 기업엔 구조적으로 낮은 값이 나옴 — 이런 회사는 고성장기(3~5년)+영구성장기로 나누는 **2단계 모델**을 쓰거나, 1단계를 쓰더라도 한계를 명시. |
| **DDM** (배당할인모형, Dividend Discount Model) | 미래 배당금을 요구수익률로 할인해 내재가치를 산정. 배당이 안정적인 성숙기업에 적합. 무배당 기업엔 적용 불가. |
| **WACC** (가중평균자본비용, Weighted Average Cost of Capital) | 자기자본비용과 타인자본비용을 자본구조 비중으로 가중평균한 값. **FCFF와만 짝을 이룬다** — `CFO − CapEx`(FCFE) 기준 DCF의 할인율로 그대로 가져다 쓰지 말 것. |
| **순부채 (Net Debt)** | 이자부 차입금(단기+장기+리스부채) − 현금및현금성자산·단기투자자산. 양수면 순차입, 음수면 순현금. FCFF-DCF에서 EV를 주주가치로 환산할 때와 EV 계산에 쓴다. |
| **EV (기업가치, Enterprise Value)** | 시가총액 + 순부채. "회사를 통째로 사들일 때의 값". 순현금이 두꺼운 회사와 대형 인수로 순차입이 늘어난 회사를 PER만으로 비교하면 자본구조 차이가 배수에 섞여 들어오므로, **EV/EBITDA·EV/Sales**를 함께 본다. |
| **영구성장률 (g)** | DCF에서 예측 기간 이후 현금흐름이 영원히 성장한다고 가정하는 비율. 통상 장기 명목 GDP 성장률(2~3%) 근사치를 씀. |
| **목표 PER / 목표 PBR** | 적정주가 계산에 곱하는 배수 가정. 동종업계 평균이나 과거 N년 평균을 근거로 삼되, 근거와 신뢰도(High/Medium/Low)를 함께 기록. |
| **괴리율** | (실제주가 ÷ 종합 적정주가 − 1) × 100. 양수면 고평가, 음수면 저평가를 의미. |
| **목표주가 / 적정주가** | 방법론별로 산출한 값과, 그 값들을 신뢰도로 가중평균한 종합값. 단순 평균은 이상치 하나에 쉽게 왜곡되므로 신뢰도 가중이 기본값. |
| **DCF 민감도 분석** | 할인율·g 가정을 조금씩 바꿔가며 DCF 적정주가가 얼마나 흔들리는지 보는 표. `(할인율−g)`가 작을수록 민감도가 커짐. |

## 2. 재무 지표 { #financial-metrics }

> 📖 예시로 풀어 쓴 설명: [`concepts/financial-metrics.md`](./concepts/financial-metrics.md)

| 용어 | 뜻 |
|------|-----|
| **희석주식수** (Diluted Shares) | 스톡옵션·RSU 등이 모두 보통주로 전환됐다고 가정한 주식수. 기본주식수(basic)보다 크거나 같음 — 이 레포의 EPS·BPS·FCFPS는 모두 희석 기준을 기본으로 씀. |
| **EPS** (주당순이익, Earnings Per Share) | 순이익 ÷ 희석주식수. GAAP/Non-GAAP 두 기준으로 나눠 기록(아래 참고). |
| **BPS** (주당순자산, Book Value Per Share) | 자기자본 ÷ 희석주식수. PBR 계산의 기준값. |
| **DPS** (주당배당금, Dividend Per Share) | 1주당 지급한 배당금. 무배당 기업은 0으로 기록(행을 지우지 않음). |
| **GAAP vs Non-GAAP** | GAAP은 미국 회계기준 원칙에 따른 공식 수치, Non-GAAP은 회사가 특정 비용을 제외해 조정한 수치. 제외 항목은 일회성(소송 합의금, 구조조정비)뿐 아니라 **주식보상비용(SBC)·인수 관련 무형자산 상각처럼 매년 반복되는 항목**이 대부분을 차지하는 경우가 많음 — 소프트웨어·EDA 기업일수록 그렇다. 따라서 "Non-GAAP = 일회성만 제거한 정상화 이익"으로 읽지 말고, **무엇을 뺐는지 항목별로 확인**할 것. 어느 기준인지 행마다 구분해서 기록. |
| **SBC** (주식보상비용, Stock-Based Compensation) | 스톡옵션·RSU 지급을 비용으로 인식한 금액. 현금이 나가지 않아 **CFO에 다시 더해지므로 FCF에서는 차감되지 않고**, Non-GAAP EPS에서도 대개 제외된다 — 즉 FCF와 Non-GAAP EPS 양쪽에서 동시에 사라진다. 실제로는 희석주식수 증가라는 형태로 기존 주주 몫을 줄이는 실질 비용이므로, 매출 대비 SBC 비율과 희석주식수 추이를 함께 기록해 그 영향을 드러낼 것. |
| **FCF** (잉여현금흐름, Free Cash Flow) | 영업활동현금흐름(CFO) − 자본적지출(CapEx). 배당·자사주매입·재투자에 실제 쓸 수 있는 현금. 미국 GAAP에서 CFO는 지급이자를 이미 차감한 뒤의 값이라 이 FCF는 **FCFE(주주 귀속) 성격**이며, SBC는 차감돼 있지 않다(위 SBC 항목 참고). |
| **FCFPS** (FCF per share) | FCF ÷ 희석주식수. DCF의 기준값이며, 위 정의상 FCFE 기준이므로 **자기자본비용(Ke)으로 할인**해야 정합적이다. |
| **CFO / CapEx** | CFO(영업활동현금흐름)는 본업에서 벌어들인 현금, CapEx(자본적지출)는 설비·시설 등에 재투자한 현금. |
| **영업이익률** | 영업이익 ÷ 매출. 본업의 수익성을 보는 지표. |
| **ROE** (자기자본이익률, Return on Equity) | 순이익 ÷ 자기자본. 주주 자본을 얼마나 효율적으로 굴렸는지. |
| **유동비율** | 유동자산 ÷ 유동부채. 단기 지급능력을 보는 지표. |
| **부채비율** | 총부채 ÷ 자기자본. 이 레포에서는 부채총계(총자산−자기자본) 기준을 기본으로 쓰되, 이자부 차입금만 집계하는 협의의 정의(Debt/Equity)와는 다르므로 비교 시 주의. |
| **배당성향** | 배당금 ÷ 순이익. 이익 중 얼마를 배당으로 돌려주는지. |
| **배당수익률** | DPS ÷ 주가. 현재 주가 기준 배당의 연 수익률. |
| **자사주매입** | 회사가 자기 주식을 사들이는 것. 배당이 없는 기업의 주된 주주환원 수단인 경우가 많음. |

## 3. 표기 규칙 { #notation }

> 📖 예시로 풀어 쓴 설명: [`concepts/notation.md`](./concepts/notation.md)

| 용어 | 뜻 |
|------|-----|
| **YoY / QoQ** | YoY(Year over Year)는 전년 동기 대비, QoQ(Quarter over Quarter)는 전분기 대비 증감. |
| **%p (퍼센트포인트)** | 비율 지표(영업이익률 등)의 증감을 표기할 때 씀. 예: 28% → 30%는 "+2%p"(단순 뺄셈)이지 "+7.1%"(상대 증감률)가 아님. |
| **(E)** | Estimate. 아직 확정되지 않은 값(회사 가이던스, 애널리스트 컨센서스, 또는 자체 추정)이라는 표시. 근거를 항상 함께 밝힘. |
| **가이던스 vs 컨센서스** | 가이던스는 회사가 직접 제시하는 향후 실적 전망치(자체 추정), 컨센서스는 여러 애널리스트 추정치의 평균/중앙값. 둘 다 (E)로 표시되지만 출처·신뢰도가 다르므로 어느 쪽인지 반드시 구분해서 표기. |
| **FY / Q 표기** | FY(Fiscal Year, 회계연도)는 회사마다 종료월이 다를 수 있어 헷갈리면 각주로 설명. FY-1·FY+1처럼 상대 표기는 실제 연도(FY2025 등)로 바꿔서 채움. |
| **스톡스플릿 소급조정** | 표 기간 내 주식분할·병합이 있었다면 과거 전 구간(주가·EPS·BPS·DPS·발행주식수)을 분할 후 기준으로 맞추는 것. 안 하면 분할 전/후 숫자가 섞여 평균·추이 전체가 왜곡됨. |

## 4. 투자 판단 / 거버넌스 용어 { #investment-terms }

> 📖 예시로 풀어 쓴 설명: [`concepts/investment-terms.md`](./concepts/investment-terms.md)

| 용어 | 뜻 |
|------|-----|
| **Bull Case / Bear Case** | Bull Case는 투자를 지지하는 강점·논리, Bear Case는 반대로 우려되는 리스크·약점. |
| **Moat (경쟁 해자)** | 경쟁사가 쉽게 넘볼 수 없는 진입장벽. 브랜드, 전환비용, 네트워크 효과, 규모의 경제 등. |
| **트리거** | `06_valuation.md`의 트리거는 밸류에이션 숫자만으로 정하는 가격 레벨, `07_investment.md`의 트리거는 거기에 리스크·정성적 조건까지 합친 최종 매수/매도 기준 — 두 문서에서 뜻이 다르므로 섞어 쓰지 않음. |
| **위임장 (Proxy Statement)** | 미국 상장사가 주주총회 전 공시하는 문서. 경영진 보상·지분 등 거버넌스 정보의 공식 출처. |
| **차등의결권 (Dual-class)** | 보통주와 의결권이 다른 주식 클래스를 함께 발행하는 구조. 창업자가 지분율보다 훨씬 큰 의결권을 갖는 경우가 많아 지배구조 리스크로 봄. |
| **기관/내부자 지분율** | 기관 투자자(펀드·연기금 등)와 내부자(임원·이사)가 각각 보유한 지분 비율. 내부자 지분이 높으면 이해관계 일치, 지나치게 높으면 소액주주 권리 약화 우려로 해석. |
