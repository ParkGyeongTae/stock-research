## 1. 재무제표 기초 { #financial-statements }

> 📖 예시로 풀어 쓴 설명: [재무제표 기초](./concepts/financial-statements.md)

| 용어 | 뜻 |
|------|-----|
| **재무제표 3종** | 손익계산서·재무상태표·현금흐름표를 묶어 부르는 말입니다. 앞의 둘은 회계 규칙에 따라 계산한 "장부상 성과"이고, 현금흐름표는 통장에 실제로 드나든 돈입니다. **셋을 같이 봐야 그림이 맞습니다** — 이익은 늘어나는데 현금은 마르는 회사가 존재하기 때문입니다. |
| **손익계산서** (Income Statement) | 일정 기간(분기·1년) 동안 얼마를 벌고 얼마를 썼는지 보여주는 표입니다. 맨 위 매출에서 시작해 비용을 차례로 빼 내려가 맨 아래 순이익으로 끝납니다. **기간의 기록**이라 "2025년 1년 동안"처럼 구간이 붙습니다. |
| **재무상태표** (Balance Sheet) | 특정 날짜 하루를 찍어, 회사가 무엇을 갖고 있고(자산) 얼마를 빚졌으며(부채) 주주 몫이 얼마인지(자본) 보여주는 표입니다. **시점의 사진**이라 "2025년 12월 31일 현재"처럼 날짜 하나가 붙습니다. |
| **현금흐름표** (Cash Flow Statement) | 그 기간에 현금이 실제로 얼마나 들어오고 나갔는지 보여주는 표입니다. 회계적 추정이 거의 섞이지 않아 **세 표 중 가장 조작하기 어렵다**고 봅니다. 그래서 이익의 진위를 의심할 때 여기를 먼저 봅니다. |
| **발생주의 vs 현금주의** | 발생주의는 돈이 오간 시점과 무관하게 **거래가 일어난 시점**에 수익·비용을 기록하는 방식입니다(손익계산서). 현금주의는 실제로 현금이 움직인 시점에 기록합니다(현금흐름표). 예를 들어 12월에 물건을 팔고 대금을 3월에 받으면, 매출은 12월에 잡히고 현금은 3월에 잡힙니다. **이익이 나는데 현금이 마르는 회사가 존재하는 이유**가 이 차이입니다. |
| **회계등식** | `자산 = 부채 + 자본`. 회사가 가진 것(자산)은 결국 빌린 돈(부채) 아니면 주주 돈(자본)으로 산 것이라는 뜻입니다. 재무상태표가 항상 좌우 균형을 이루는 근본 원리입니다. |
| **매출** (Revenue, Top line) | 제품·서비스를 팔아 벌어들인 총액입니다. 손익계산서 맨 윗줄이라 "Top line"이라고도 부릅니다. **아직 아무 비용도 빼지 않은 금액**이라, 매출이 크다는 것과 돈을 번다는 것은 다른 이야기입니다. |
| **매출원가** (COGS, Cost of Goods Sold) | 그 매출을 일으키는 데 **직접** 들어간 원가입니다. 제조업이면 재료비·공장 인건비, 소프트웨어면 서버·클라우드 비용과 고객지원 인건비가 여기 들어갑니다. 매출이 늘면 대체로 같이 늘어나는 성격의 비용입니다. |
| **매출총이익** (Gross Profit) | `매출 − 매출원가`. 판매·관리·연구개발에 돈을 쓰기 전 단계의 1차 이익입니다. **제품 자체가 남기는 마진**이라, 회사의 사업 모델이 근본적으로 어떤 체질인지를 가장 먼저 드러냅니다. |
| **판매관리비** (SG&A) | 영업·마케팅·일반관리에 쓴 비용입니다. 매출과 직접 연결되지 않아 매출이 늘어도 그만큼 늘지는 않습니다. **매출 성장 속도보다 SG&A 증가 속도가 느리면** 성장이 효율적으로 일어나고 있다는 신호입니다. |
| **연구개발비** (R&D) | 신제품·신기술 개발에 쓴 비용입니다. 미국 GAAP은 원칙적으로 R&D를 **쓴 즉시 비용으로 처리**하고 자산으로 올리지 않습니다. 그래서 R&D를 많이 쓰는 회사는 당장의 이익이 낮게 나오는데, **수익성이 나쁜 것이 아니라 미래에 투자하는 중**일 수 있어 구분해서 읽어야 합니다. |
| **영업이익** (EBIT, Operating Income) | `매출 − 매출원가 − 판관비 − R&D`. 본업에서 남긴 이익입니다. 이자와 세금을 거치기 전 단계라, **자본구조(빚이 많은지)나 세율과 무관하게 본업의 실력만** 비교할 수 있습니다. |
| **EBITDA** | `영업이익 + 감가상각비·무형자산상각비(D&A)`. 설비 투자 방식과 감가상각 정책의 차이를 걷어내고 회사끼리 비교하려고 만든 지표입니다. 다만 **설비 재투자가 필수인 사업에서는 실제로 쓸 수 있는 현금을 과대평가**합니다(4. 수익성 · 효율성 · 안정성 심화의 "EBITDA의 함정" 참고). |
| **D&A** (감가상각 · 무형자산상각) | 설비·건물처럼 여러 해 쓰는 자산의 취득 가격을 사용 기간에 나눠 매년 조금씩 비용으로 인식하는 것입니다(유형자산이면 감가상각, 무형자산이면 상각). 이미 옛날에 현금이 나갔고 **올해는 현금이 나가지 않는 비용**이라, 현금흐름표에서 다시 더해집니다. |
| **영업외손익** | 본업 밖에서 생긴 손익입니다. 보유 주식의 평가손익, 환차손익, 자산 매각 차익 등이 들어갑니다. **변동이 크고 반복되지 않는 경우가 많아**, 순이익이 갑자기 뛰거나 꺾였을 때 여기부터 확인합니다. |
| **이자비용** | 빌린 돈에 대해 무는 이자입니다. 영업이익에서 차감되며, 빚이 많은 회사일수록 본업이 같아도 순이익이 작아집니다. `영업이익 ÷ 이자비용`이 이자보상배율입니다(4. 수익성 · 효율성 · 안정성 심화 참고). |
| **법인세** | 회사가 이익에 대해 내는 세금입니다. 실제 부담률(유효세율)은 명목 세율과 다른 경우가 많은데, 해외 소득 비중·세액공제·일회성 세무 조정 때문입니다. 유효세율이 갑자기 낮아진 해는 순이익 증가가 실력이 아닐 수 있습니다. |
| **순이익** (Net Income, Bottom line) | 모든 비용과 세금을 뺀 최종 이익입니다. 손익계산서 맨 아랫줄이라 "Bottom line"이라 부르며, **EPS를 계산할 때 분자로 쓰는 값**입니다. |
| **지배주주지분 vs 비지배지분** | 자회사를 100% 갖고 있지 않을 때, 순이익 중 모회사 주주에게 귀속되는 몫(지배주주지분)과 자회사의 나머지 주주 몫(비지배지분)을 나눠 표시합니다. **EPS 계산에는 지배주주지분 순이익을 씁니다** — 전체 순이익을 그냥 쓰면 남의 몫까지 내 주식에 얹는 셈이 됩니다. |
| **자산** (Assets) | 회사가 가지고 있는 것 전부입니다. 현금·매출채권·재고 같은 것부터 공장·특허·영업권까지 포함합니다. |
| **부채** (Liabilities) | 회사가 갚아야 할 것 전부입니다. 은행 차입금처럼 이자가 붙는 것도 있고, 매입채무·이연수익처럼 **이자가 붙지 않는 것**도 있습니다. 이 구분이 부채비율과 순부채를 갈라놓습니다(2. 재무 지표 참고). |
| **자본** (자기자본, Equity) | `자산 − 부채`. 빚을 다 갚고 남는 주주의 몫입니다. BPS와 ROE·PBR 계산의 기준값이 됩니다. |
| **유동 vs 비유동** | 1년 안에 현금이 되거나 갚아야 하면 유동, 그보다 오래 걸리면 비유동으로 나눕니다. 유동자산과 유동부채를 비교하면 **당장 1년을 버틸 수 있는지**가 보이는데, 그게 유동비율입니다. |
| **매출채권** (Accounts Receivable) | 물건은 넘겼는데 **아직 못 받은 판매대금**입니다. 매출로는 이미 잡혔지만 현금은 아직 안 들어온 상태라, 매출채권이 매출보다 빨리 늘면 돈을 못 받고 있다는 신호일 수 있습니다. |
| **재고자산** (Inventory) | **아직 못 판 물건**입니다. 팔리기 전까지는 현금이 묶여 있는 상태이며, 오래 남으면 헐값에 처분하거나 폐기해야 할 수 있습니다. |
| **매입채무** (Accounts Payable) | 물건은 받았는데 **아직 안 준 구매대금**입니다. 사실상 거래처가 무이자로 빌려준 돈이라, 협상력이 강한 회사일수록 이 기간이 깁니다. |
| **운전자본** (Working Capital) | 사업을 굴리는 데 묶여 있는 돈으로, 넓게는 `유동자산 − 유동부채`, 좁게는 `매출채권 + 재고 − 매입채무`로 계산합니다. **운전자본이 늘면 그만큼 현금이 잠깁니다** — FCFF 공식에 붙는 `− 운전자본 증가분`이 바로 이것입니다. |
| **이익잉여금** (Retained Earnings) | 지금까지 벌어서 배당으로 내보내지 않고 사내에 쌓아둔 이익의 누적액입니다. 오래 흑자를 낸 회사일수록 큽니다. |
| **자본잉여금** | 주식을 발행할 때 액면가를 넘겨 받은 금액입니다. 벌어서 쌓은 돈이 아니라 **주주가 넣어준 돈**이라는 점에서 이익잉여금과 성격이 다릅니다. |
| **자기주식** (Treasury Stock) | 회사가 시장에서 되사들여 보유 중인 자기 회사 주식입니다. 회계상 자본의 **차감 항목**으로 표시됩니다(자산이 아닙니다). |
| **영업권** (Goodwill) | 다른 회사를 순자산 가치보다 비싸게 인수했을 때, 그 차액을 자산으로 올린 것입니다. 매년 나눠 상각하지 않는 대신 **매년 손상 검사**를 받으며, 손상차손이 나면 사실상 "그때 인수가 비쌌다"는 뒤늦은 고백에 가깝습니다. |
| **무형자산** (Intangible Assets) | 특허·고객관계·상표권·개발 기술처럼 형체가 없는 자산입니다. 대부분 인수 과정에서 장부에 올라오며, 영업권과 달리 **정해진 기간에 걸쳐 상각**됩니다. Non-GAAP 조정에서 이 상각비를 빼는 회사가 많습니다. |
| **손상차손** (Impairment) | 자산에서 앞으로 회수할 수 있는 금액이 장부에 적힌 값보다 낮아졌을 때, 그 차액을 손실로 털어내는 것입니다. 현금이 나가지는 않지만 **과거 투자 판단이 틀렸다는 신호**로 읽습니다. |
| **이연법인세** | 회계장부상 이익과 세무상 이익이 인식 시점 차이로 어긋나면서 생기는 자산·부채 항목입니다. 지금 덜 낸 세금을 나중에 낼 의무(이연법인세부채), 지금 더 낸 세금을 나중에 덜 낼 권리(이연법인세자산)로 이해하면 됩니다. |
| **리스부채** | 리스(임차) 계약에 따라 앞으로 지급할 의무를 부채로 잡아둔 것입니다. 매장·물류창고를 빌려 쓰는 회사일수록 큽니다. **순부채와 EV를 계산할 때 포함할지 여부를 반드시 밝혀야** 회사 간 비교가 어긋나지 않습니다. |
| **CFO** (영업활동현금흐름) | 본업을 돌려서 실제로 만들어낸 현금입니다. 순이익에서 출발해 현금이 나가지 않은 비용(D&A·SBC)을 더하고 운전자본 변동을 조정해 계산합니다. 미국 GAAP에서 **CFO는 지급이자를 이미 뺀 값**이라는 점이 FCF의 성격을 정합니다(2. 재무 지표의 "FCF" 참고). |
| **CFI** (투자활동현금흐름) | 설비 투자, 기업 인수, 금융자산 매매에 쓰거나 회수한 현금입니다. 성장하는 회사는 대체로 마이너스입니다(투자에 돈을 쓰고 있으므로). |
| **CFF** (재무활동현금흐름) | 차입·상환·유상증자·배당·자사주매입으로 오간 현금입니다. **성숙한 회사는 CFO가 크고 CFF가 마이너스**(벌어서 주주에게 돌려주는 중), **성장 초기 회사는 CFF에 의존**(밖에서 돈을 끌어오는 중)하는 패턴이 흔합니다. |
| **이연수익** (Deferred Revenue) | 대금은 먼저 받았지만 **아직 제공하지 않은 서비스**에 대한 **부채**입니다. 구독 사업에서 이 금액이 늘어난다는 것은 선결제가 쌓이고 있다는 뜻이라 보통 긍정적 신호로 읽습니다. 이름은 "수익"이지만 부채 항목이라는 점을 헷갈리지 마세요. |
| **주석** (Footnotes) | 재무제표 본표 뒤에 붙는 상세 설명입니다. 사업부문별 실적, 매출 인식 정책, 진행 중인 소송, 우발부채 등 **본표 숫자만으로는 절대 안 보이는 핵심**이 여기 있습니다. |
| **연결 vs 별도** | 연결재무제표는 자회사까지 하나의 회사처럼 합쳐서 만든 것이고, 별도재무제표는 모회사만 떼어 만든 것입니다. **투자 판단은 원칙적으로 연결 기준**으로 봅니다 — 실제 사업은 자회사에서 일어나는 경우가 많기 때문입니다. |
| **GAAP vs IFRS** | 미국 회계기준(GAAP)과 국제 회계기준(IFRS)입니다. 이 저장소는 미국 상장사 위주라 GAAP을 전제로 하며, 미국 밖 기업을 다룰 때는 용어를 바꿔 쓰고 각주로 그 사실을 남깁니다. |

## 2. 재무 지표 { #financial-metrics }

> 📖 예시로 풀어 쓴 설명: [재무 지표](./concepts/financial-metrics.md)

| 용어 | 뜻 |
|------|-----|
| **희석주식수** (Diluted Shares) | 임직원에게 준 스톡옵션·RSU가 전부 보통주로 바뀌었다고 가정했을 때의 주식수입니다. 실제 발행된 주식수(기본주식수)보다 항상 크거나 같습니다. 나중에 주식이 늘어날 가능성까지 미리 반영한 **보수적인 기준**이며, **이 저장소의 EPS·BPS·FCFPS는 모두 희석 기준**을 씁니다. |
| **EPS** (주당순이익, Earnings Per Share) | `순이익 ÷ 희석주식수`. 주식 1주가 벌어들인 이익입니다. 회사 규모가 달라도 주당 기준으로 맞추면 비교가 되기 때문에 PER 계산의 기준이 됩니다. **GAAP 기준과 Non-GAAP 기준을 반드시 나눠 기록**합니다. |
| **BPS** (주당순자산, Book Value Per Share) | `자기자본 ÷ 희석주식수`. 주식 1주에 딸린 장부상 순자산입니다. PBR 계산의 기준값입니다. |
| **DPS** (주당배당금, Dividend Per Share) | 1주당 실제로 지급한 배당금입니다. 배당을 하지 않는 회사도 **행을 지우지 말고 0으로 기록**합니다 — 무배당이라는 사실 자체가 정보입니다. |
| **GAAP vs Non-GAAP** | GAAP은 미국 회계기준에 따라 계산한 공식 수치이고, Non-GAAP은 회사가 "이건 본질적인 비용이 아니다"라고 판단한 항목을 빼고 다시 계산한 수치입니다. 문제는 그 빼는 항목에 일회성뿐 아니라 **SBC나 무형자산상각처럼 매년 반복되는 것**이 흔히 섞인다는 점입니다. 무엇을 뺐는지 항목별로 확인하고, 표에는 행마다 어느 기준인지 적어야 합니다. |
| **SBC** (주식보상비용, Stock-Based Compensation) | 스톡옵션·RSU를 임직원에게 준 것을 비용으로 인식한 금액입니다. 현금이 나가지 않으므로 CFO 계산에서 다시 더해지고, Non-GAAP 이익에서도 빠지는 경우가 많습니다 — 즉 **FCF와 Non-GAAP EPS 양쪽에서 동시에 사라집니다.** 하지만 주식수를 늘려 기존 주주 몫을 실제로 줄이는 진짜 비용이므로, **매출 대비 SBC 비율과 희석주식수 추이를 함께** 기록합니다. |
| **FCF** (잉여현금흐름, Free Cash Flow) | `CFO − CapEx`. 본업으로 번 현금에서 설비 재투자에 쓴 돈을 빼고 남은, **배당·자사주매입·인수·부채상환에 실제로 쓸 수 있는 현금**입니다. 미국 GAAP에서 CFO는 지급이자를 이미 뺀 값이라, 이렇게 계산한 FCF는 **주주에게 귀속되는 성격(FCFE)**입니다. SBC는 차감되어 있지 않다는 점에 주의합니다. |
| **FCFPS** (주당 잉여현금흐름) | `FCF ÷ 희석주식수`. 이 저장소에서 DCF를 돌릴 때 기준값으로 쓰며, 위 정의상 FCFE 성격이므로 **자기자본비용(Ke)으로 할인**해야 앞뒤가 맞습니다(6. 밸류에이션 방법론의 "FCFE / FCFF — 할인율 정합성" 참고). |
| **CapEx** (자본적지출) | 공장·설비·서버·매장처럼 오래 쓸 자산을 사는 데 쓴 현금입니다. 현금흐름표의 투자활동에 들어 있으며, FCF를 계산할 때 CFO에서 빼는 항목입니다. |
| **매출총이익률** (Gross Margin) | `매출총이익 ÷ 매출`. 제품·서비스 자체의 근본 수익성입니다. 규모가 커져도 잘 변하지 않아 **사업 모델의 체질**을 드러냅니다. 소프트웨어는 70~90%, 하드웨어·유통은 20~40%대가 흔해서, 이 숫자 하나로 대략 어떤 종류의 사업인지 짐작할 수 있습니다. |
| **영업이익률** | `영업이익 ÷ 매출`. 본업에서 남기는 수익성입니다. 매출총이익률이 "제품의 체질"이라면 영업이익률은 "회사 운영까지 포함한 실력"입니다. |
| **순이익률** | `순이익 ÷ 매출`. 이자·세금·일회성 손익까지 전부 반영한 최종 수익성입니다. 영업이익률과 크게 벌어졌다면 그 차이가 어디서 왔는지(이자 부담인지, 일회성인지) 확인합니다. |
| **ROE** (자기자본이익률, Return on Equity) | `순이익 ÷ 자기자본`. 주주가 맡긴 돈을 얼마나 효율적으로 굴렸는지 보는 지표입니다. 함정이 하나 있는데, **빚을 늘리면 자기자본이 줄어들어 ROE가 저절로 올라갑니다.** 높은 ROE가 실력인지 레버리지인지는 부채비율과 함께 봐야 갈립니다(4. 수익성 · 효율성 · 안정성 심화의 "듀폰 분해" 참고). |
| **유동비율** | `유동자산 ÷ 유동부채`. 1년 안에 갚아야 할 돈을, 1년 안에 현금이 될 자산으로 몇 배 덮을 수 있는지 봅니다. 단기 지급능력의 가장 기본적인 척도입니다. |
| **부채비율** | 이 저장소에서는 `부채총계 ÷ 자기자본`(부채총계 = 총자산 − 자기자본) 기준을 기본으로 씁니다. **여기에는 이자가 붙지 않는 매입채무·이연수익까지 전부 들어갑니다.** 이자부 차입금만 세는 미국식 D/E(Debt/Equity)와는 전혀 다른 숫자이므로, 다른 자료와 비교할 때 어느 정의인지 반드시 확인해야 합니다. |
| **순부채** (Net Debt) | `이자부 차입금(단기 + 장기 + 리스부채) − 현금 및 현금성자산 · 단기투자자산`. 양수면 갚아야 할 빚이 현금보다 많은 순차입 상태, 음수면 현금이 더 많은 순현금 상태입니다. **부채비율과 달리 실제로 이자를 무는 빚만** 셉니다. EV 계산과 FCFF-DCF에서 기업가치를 주주가치로 바꿀 때 씁니다. |
| **EV** (기업가치, Enterprise Value) | `시가총액 + 순부채`. "이 회사를 통째로 사려면 얼마가 드는가"에 해당하는 값입니다. 빚까지 떠안아야 하고 회사 안의 현금은 되돌려 받는 셈이라 이렇게 계산합니다. 순현금이 두꺼운 회사와 대형 인수로 빚이 늘어난 회사를 PER만으로 비교하면 자본구조 차이가 섞여 들어오므로, **EV/EBITDA·EV/Sales를 함께** 봅니다. |
| **배당성향** | `배당금 총액 ÷ 순이익`. 번 돈 중 얼마를 배당으로 돌려주는지 보여줍니다. 너무 낮으면 환원에 인색한 것이고, 100%에 가깝거나 넘으면 **벌어들인 것보다 많이 주고 있다**는 뜻이라 지속 가능성을 의심합니다. |
| **배당수익률** | `DPS ÷ 주가`. 지금 주가로 샀을 때 1년에 받는 배당의 비율입니다. 주가가 떨어지면 자동으로 올라가므로, **배당수익률이 갑자기 높아진 종목은 배당이 늘어난 게 아니라 주가가 무너진 것**일 수 있습니다. |
| **자사주매입** (Buyback) | 회사가 시장에서 자기 주식을 사들이는 것입니다. 주식수가 줄어 남은 주주의 몫(EPS)이 늘어나는 효과가 있어, 배당하지 않는 회사의 주된 주주환원 수단인 경우가 많습니다. |
| **총주주환원율** | `(배당금 + 자사주매입액) ÷ 순이익` 또는 `÷ FCF`. 배당만 보면 자사주매입 위주 회사의 환원 규모를 통째로 놓치기 때문에 둘을 합쳐서 봅니다. 어느 쪽을 분모로 썼는지 밝혀야 합니다. |

## 3. 표기 규칙 { #notation }

> 📖 예시로 풀어 쓴 설명: [표기 규칙](./concepts/notation.md)

| 용어 | 뜻 |
|------|-----|
| **YoY** (Year over Year) | 전년 **같은 기간** 대비 증감입니다. 계절성이 있는 사업(4분기에 매출이 몰리는 소매업 등)에서도 왜곡 없이 추세를 볼 수 있어 기본으로 씁니다. |
| **QoQ** (Quarter over Quarter) | 직전 분기 대비 증감입니다. 변화를 빨리 잡아낼 수 있지만 **계절성이 있으면 심하게 왜곡**되므로, 그런 사업에서는 YoY를 씁니다. |
| **%p** (퍼센트포인트) | 비율로 표시되는 지표(영업이익률 등)가 얼마나 변했는지 나타낼 때 씁니다. 영업이익률이 28%에서 30%가 되면 **"+2%p"**(단순 뺄셈)이지 "+7.1%"(상대 증감률)가 아닙니다. 둘을 섞으면 마진 개선 폭이 크게 부풀거나 줄어 보입니다. |
| **bp** (베이시스포인트) | `1bp = 0.01%p`, `100bp = 1%p`. 금리나 수수료율처럼 작은 변화를 다룰 때 씁니다. |
| **(E)** | Estimate(추정치)의 약자로, 아직 확정되지 않은 값이라는 표시입니다. 회사 가이던스든 애널리스트 컨센서스든 자체 추정이든 **근거를 반드시 함께** 밝힙니다. 평균이나 중앙값을 낼 때 확정치와 (E)를 섞으면 안 됩니다. |
| **가이던스 vs 컨센서스** | 가이던스는 **회사가 직접** 제시하는 향후 실적 전망이고, 컨센서스는 **여러 애널리스트** 추정치의 평균·중앙값입니다. 둘 다 (E)로 표시되지만 만든 주체와 신뢰도가 다르므로 어느 쪽인지 반드시 구분해서 적습니다. |
| **회계연도** (FY, Fiscal Year) | 회사가 1년 실적을 끊는 기준 기간입니다. 12월에 끝나는 회사가 많지만 **1월·6월·9월에 끝나는 회사도 흔합니다**(예: 월마트 FY2026은 2026년 1월에 끝남). 헷갈릴 소지가 있으면 각주로 종료월을 밝히고, FY-1·FY+1 같은 상대 표기는 실제 연도로 바꿔 적습니다. |
| **분기 표기** (Q1~Q4) | 회계연도를 4등분한 구간입니다. **달력 분기가 아니라 회계연도 기준**이라, 6월 결산 회사의 Q1은 7~9월입니다. 회사 간 분기 실적을 나란히 놓을 때 이 어긋남을 확인해야 합니다. |
| **TTM / LTM** (Trailing / Last Twelve Months) | 최근 4개 분기를 합친 값으로, 회계연도 경계와 무관하게 "지금 시점 기준 1년치 실적"을 보는 방법입니다. 두 이름은 같은 뜻입니다. **결산월이 다른 회사끼리 비교할 때** 특히 유용합니다. |
| **YTD** (Year to Date) | 회계연도가 시작된 시점부터 지금까지의 누적치입니다. |
| **연환산** (Annualized) | 분기 실적에 4를 곱하는 식으로 1년치처럼 환산한 값입니다. **계절성이 큰 사업에 쓰면 심하게 왜곡**되므로(4분기 실적을 연환산하면 소매업은 터무니없이 커집니다) 사용 여부를 신중히 판단합니다. |
| **CAGR** (연평균성장률) | `(기말 ÷ 기초)^(1 ÷ 연수) − 1`. 중간의 등락을 무시하고 시작점과 끝점만으로 평균 성장 속도를 낸 값입니다. 그래서 **시작·끝 연도를 어디로 잡느냐에 따라 결과가 크게 달라집니다** — 코로나 직전을 시작점으로 잡느냐 직후로 잡느냐만으로 몇 %p씩 움직입니다. 반드시 기간을 함께 표기합니다. |
| **상수통화 기준** (Constant Currency) | 환율 변동 효과를 제거하고 계산한 성장률입니다. 해외 매출 비중이 큰 회사는 보고 기준 성장률과 몇 %p씩 차이가 나므로 회사가 둘 다 공시하는 경우가 많습니다. 사업이 나빠진 것인지 환율 탓인지 가르는 데 씁니다. |
| **유기적 성장** (Organic Growth) | 인수합병으로 더해진 매출을 뺀, 기존 사업 자체의 성장입니다. 인수를 자주 하는 회사는 보고 매출 성장률이 실제 사업 성장을 과장하므로 구분해서 봅니다. ⚠️ **소비재(CPG) 업계는 환율 효과까지 함께 제거한 것을 organic이라 부릅니다** — 섹터별 정의 차이는 해당 섹터 용어 문서를 확인하세요. |
| **주식분할 소급조정** | 대상 기간 안에 주식분할이나 병합이 있었다면, 과거 전 구간의 주가·EPS·BPS·DPS·주식수를 **분할 후 기준으로 모두 맞춰 다시 적는 것**입니다. 하지 않으면 분할 전후 숫자가 한 표에 섞여 평균과 추이 전체가 무너집니다. |
| **단위 표기** | 금액에는 통화와 단위를 항상 붙입니다(예: USD million). 미국 공시의 billion은 10억, trillion은 1조입니다. |
| **계절성** (Seasonality) | 특정 분기에 실적이 몰리는 성질입니다. 계절성이 있으면 QoQ가 무의미해지므로 YoY로 추세를 판단합니다. |

## 4. 수익성 · 효율성 · 안정성 심화 { #advanced-metrics }

> 📖 예시로 풀어 쓴 설명: [수익성 · 효율성 · 안정성 심화](./concepts/advanced-metrics.md)

| 용어 | 뜻 |
|------|-----|
| **ROA** (총자산이익률) | `순이익 ÷ 총자산`. 빚으로 샀든 주주 돈으로 샀든 상관없이, 회사가 가진 자산 전체를 얼마나 잘 굴렸는지 봅니다. ROE와 달리 레버리지 효과가 섞이지 않습니다. |
| **ROIC** (투하자본이익률) | `NOPAT ÷ 투하자본`. **가치를 만들고 있는지 판별하는 가장 핵심적인 지표**입니다. ROIC가 자본비용(WACC)보다 높으면 성장할수록 가치가 커지고, 낮으면 **성장할수록 가치를 파괴**합니다 — 조달 비용보다 낮은 수익률로 돈을 굴리고 있다는 뜻이기 때문입니다. |
| **NOPAT** (세후영업이익) | `영업이익(EBIT) × (1 − 세율)`. 빚을 얼마나 썼는지와 무관하게, 본업이 세금까지 낸 뒤 남긴 이익입니다. ROIC의 분자입니다. |
| **투하자본** (Invested Capital) | 사업에 실제로 묶여 있는 자본입니다. `이자부 차입금 + 자기자본 − 잉여현금`으로 구하거나 `순운전자본 + 순유형자산`으로 구합니다. **정의가 여러 개라 계산 결과가 꽤 달라지므로, 어느 정의를 썼는지 반드시 밝혀야** 합니다. |
| **ROIC − WACC 스프레드** | 투하자본이 벌어들이는 수익률에서 그 자본을 조달하는 비용을 뺀 초과수익률입니다. 양수면 자본비용 이상을 벌고 있다는 뜻이고, **이 스프레드가 몇 년이나 유지되느냐가 곧 해자의 수명**입니다. |
| **ROCE** (사용자본이익률) | `영업이익(EBIT) ÷ (총자산 − 유동부채)`. ROIC와 취지가 같고 계산 방식만 다른 사촌 지표입니다. 자료마다 어느 쪽을 쓰는지 다르므로 섞어 인용하지 않습니다. |
| **듀폰 분해** (DuPont Analysis) | `ROE = 순이익률 × 자산회전율 × 재무레버리지`로 쪼개 보는 방법입니다. ROE가 높은 이유가 **마진이 좋아서인지, 자산을 빨리 돌려서인지, 빚을 많이 써서인지** 갈라내는 데 씁니다. 세 번째 이유로 높은 ROE는 좋은 신호가 아닙니다. |
| **자산회전율** | `매출 ÷ 총자산`. 자산 1달러가 매출을 얼마나 만들어내는지 봅니다. 유통업처럼 자산을 빨리 돌리는 사업은 높고, 설비가 무거운 사업은 낮습니다. |
| **재고회전율** | `매출원가 ÷ 평균재고`. 1년에 재고를 몇 번 갈아치우는지 보여줍니다. 낮아지면 재고가 쌓이고 있다는 뜻입니다. |
| **DIO** (재고자산회전일수) | 재고가 팔리기까지 걸리는 평균 일수입니다. 재고회전율을 일수로 바꾼 것으로, **길어지면 물건이 안 팔리고 있다는 신호**입니다. |
| **DSO** (매출채권회수기간) | 물건을 팔고 나서 대금을 받기까지 걸리는 평균 일수입니다. 매출은 늘어나는데 DSO가 급격히 길어지면 **밀어내기 매출이거나 고객의 지급 능력이 나빠진 것**을 의심합니다. |
| **DPO** (매입채무지급기간) | 물건을 사고 나서 대금을 지급하기까지 걸리는 평균 일수입니다. 길수록 거래처 돈을 오래 무이자로 쓰는 셈이라 현금 사정에 유리합니다. |
| **CCC** (현금전환주기, Cash Conversion Cycle) | `DIO + DSO − DPO`. 재고를 사들인 시점부터 판매대금을 회수할 때까지 **현금이 묶여 있는 일수**입니다. **음수면 고객에게 먼저 받고 거래처에는 나중에 주는 구조**로, 사실상 남의 돈으로 사업을 돌리고 있다는 뜻입니다(일부 대형 유통·플랫폼). |
| **이자보상배율** | `영업이익(EBIT) ÷ 이자비용`. 본업에서 번 돈으로 이자를 몇 배나 감당할 수 있는지 봅니다. **1 미만이면 본업으로 이자조차 못 내고 있다**는 뜻이라 즉시 위험 신호입니다. |
| **순차입금 / EBITDA** | `순부채 ÷ EBITDA`. 지금 벌이로 빚을 다 갚으려면 몇 년치가 필요한지 보여줍니다. 대형 인수 직후 이 값이 급등한 회사는 **부담이 해소되는 속도**를 분기마다 추적합니다. |
| **당좌비율** (Quick Ratio) | `(유동자산 − 재고) ÷ 유동부채`. 재고는 급할 때 제값에 못 판다고 가정한, 유동비율보다 보수적인 단기 지급능력 지표입니다. |
| **영업레버리지** | 고정비 비중이 높아서, 매출이 조금만 늘어도 영업이익은 훨씬 크게 늘어나는 구조입니다. 좋을 때는 이익이 폭발적으로 늘지만 **매출이 꺾이면 이익은 더 크게 꺾입니다** — 양방향으로 작동합니다. |
| **재무레버리지** | 빚을 써서 자기자본 수익률을 키우는 것입니다. 잘 될 때는 ROE를 밀어올리지만 나빠지면 손실도 같이 증폭시킵니다. |
| **손익분기점** (BEP) | 고정비를 겨우 덮는 매출 수준입니다. 아직 적자인 성장 기업을 볼 때 **"언제 흑자로 돌아서는가"**를 판단하는 기준선이 됩니다. |
| **FCF 전환율** | `FCF ÷ 순이익` 또는 `FCF ÷ EBITDA`. 장부상 이익이 실제 현금으로 얼마나 바뀌는지 보여줍니다. **1에 한참 못 미치는 상태가 몇 년 이어지면 이익의 질을 의심**합니다. |
| **CapEx / 매출** | 매출 대비 설비투자 강도입니다. 그 사업이 얼마나 자본집약적인지 보여주며, 평소 수준을 크게 넘는 증가는 증설 사이클에 들어갔다는 신호일 수 있습니다. |
| **유지 CapEx vs 성장 CapEx** | 지금 상태를 유지하는 데 꼭 필요한 투자와, 새로운 수익을 만들기 위한 투자입니다. **회사가 구분해서 공시하지 않는 경우가 많아** D&A를 유지 CapEx의 근사치로 쓰기도 합니다. 성장 CapEx가 크다면 지금의 낮은 FCF가 반드시 나쁜 신호는 아닙니다. |
| **EBITDA의 함정** | EBITDA는 D&A를 도로 더해준 값이라, **설비를 계속 새로 사야 하는 사업에서는 "실제로 쓸 수 있는 현금"을 과대평가**합니다. 자본집약 산업에서 EBITDA만 보면 부채 감당 능력을 낙관하게 되므로 반드시 FCF와 함께 봅니다. |

## 5. 사업 모델 · 성장 지표 { #business-metrics }

> 📖 예시로 풀어 쓴 설명: [사업 모델 · 성장 지표](./concepts/business-metrics.md)
>
> 여기에는 **여러 섹터에 두루 쓰이는 지표만** 둡니다. 한 섹터 안에서만 쓰는 지표(E&P의 증명매장량, LNG의 액화 능력, 항공우주의 형식증명 등)는 그 섹터 폴더의 용어 문서에 둡니다 — [천연가스](../sectors/natural_gas/00_glossary.md) · [항공우주·방위산업](../sectors/aerospace_defense/00_glossary.md).

| 용어 | 뜻 |
|------|-----|
| **리커링 매출** (Recurring Revenue) | 계약에 따라 매달·매년 반복해서 들어오는 매출입니다. 한 번 팔고 끝나는 매출보다 다음 해 예측이 쉬워서, **같은 금액이라도 시장이 더 높은 배수를 매기는 근거**가 됩니다. |
| **ARR** (연간 반복매출) | 지금 시점의 구독 계약을 1년치로 환산한 금액입니다. 구독 사업의 사실상 표준 지표이지만 **회사마다 어떤 계약을 포함하는지 정의가 다르므로**, 정의를 확인하지 않고 회사끼리 비교하면 안 됩니다. |
| **MRR** (월간 반복매출) | ARR의 월 단위 버전입니다. 계약 기간이 짧고 변화가 빠른 사업에서 주로 씁니다. |
| **계약부채** (Contract Liability) | 대금을 먼저 받고 아직 서비스를 제공하지 않은 부분으로, **이연수익과 같은 것**입니다(1. 재무제표 기초 참고). 증가 추세는 선주문이 쌓이고 있다는 신호로 읽습니다. |
| **RPO** (잔여 이행 의무, Remaining Performance Obligation) | 계약은 이미 맺었지만 **아직 매출로 인식하지 않은 총액**입니다. ASC 606에 따라 공시되며, 앞으로의 매출 가시성을 보여줍니다. 이 중 12개월 안에 매출이 될 비중(단기 RPO)을 함께 보면 얼마나 빨리 실적이 되는지 드러납니다. |
| **백로그** (수주잔고, Backlog) | 수주는 받았지만 아직 납품하지 않은 물량입니다. 방산·인프라처럼 계약에서 납품까지 몇 년이 걸리는 산업의 핵심 선행지표입니다. ⚠️ **예산이 확정된 수주(funded)와 옵션까지 포함한 총액을 반드시 구분**해야 합니다 — 옵션은 발주처가 행사하지 않으면 매출이 되지 않습니다. |
| **Book-to-Bill** | `신규 수주 ÷ 당기 매출`. 1을 넘으면 수주가 매출보다 빨리 쌓이는 중(향후 성장), 1 미만이면 쌓아둔 것을 까먹는 중입니다. 장비·반도체·방산의 사이클 판단에 씁니다. |
| **NRR** (순매출유지율, Net Revenue Retention) | 1년 전 고객 집단이 지금 만들어내는 매출의 비율입니다. 이탈로 빠진 것과 기존 고객이 더 산 것(업셀)을 모두 반영하므로 **100%를 넘을 수 있습니다.** NRR 120%는 신규 고객을 한 명도 못 받아도 20% 성장한다는 뜻이라 매우 강한 신호입니다. |
| **GRR** (총매출유지율, Gross Revenue Retention) | NRR에서 업셀 효과를 뺀, **이탈만 반영한** 유지율입니다. 100%를 넘을 수 없습니다. NRR은 높은데 GRR이 낮다면 소수 대형 고객의 증액이 다수의 이탈을 가리고 있다는 뜻입니다. |
| **이탈률** (Churn) | 일정 기간 동안 빠져나간 고객·매출의 비율입니다. **고객 수 기준과 금액 기준이 전혀 다른 숫자**이므로(소액 고객이 많이 빠지면 건수 이탈률만 높음) 어느 쪽인지 밝힙니다. |
| **CAC** (고객획득비용) | 신규 고객 1명을 데려오는 데 든 마케팅·영업 비용입니다. 함께 보는 것이 **CAC 회수기간** — 그 고객이 남기는 이익으로 획득 비용을 되찾는 데 몇 개월이 걸리는지입니다. |
| **LTV** (고객생애가치) | 한 고객이 거래 관계를 유지하는 동안 남기는 총이익입니다. `LTV ÷ CAC` 배수가 사업의 지속 가능성을 가늠하는 기준이 되며, 통상 3배 이상을 건전하다고 봅니다. |
| **유닛 이코노믹스** | 고객 1명 또는 거래 1건 단위로 따진 수익성입니다. **회사 전체가 적자여도 단위 경제성이 흑자면** 규모를 키워 해결될 여지가 있고, 단위부터 적자면 성장할수록 손실이 커집니다. |
| **TAM** (전체 시장 규모) | 이론적으로 도달 가능한 시장 전체의 크기입니다. 회사 IR 자료의 TAM은 관대하게 잡히는 경향이 있어 **정의와 출처를 확인**해야 합니다. |
| **SAM** (유효 시장) | TAM 중 회사의 제품·지역·채널로 실제 접근할 수 있는 부분입니다. |
| **SOM** (수익 시장) | SAM 중 경쟁 상황을 감안해 현실적으로 가져올 수 있는 부분입니다. 셋 중 가장 작고 가장 현실적인 숫자입니다. |
| **테이크레이트** (Take Rate) | 플랫폼이 거래액 중 수수료로 가져가는 비율입니다. 거래소·마켓플레이스의 수익 구조를 결정하는 핵심 변수로, 경쟁이 심해지면 가장 먼저 깎이는 곳이기도 합니다. |
| **GMV** (거래대금, Gross Merchandise Value) | 플랫폼에서 오간 거래의 총액입니다. **이것은 매출이 아니라 매출의 기반**입니다 — 실제 매출은 `GMV × 테이크레이트`입니다. 둘을 혼동하면 회사 규모를 몇 배로 착각하게 됩니다. |
| **ARPU** (사용자당 평균 매출) | `매출 ÷ 사용자 수`. 성장이 사용자 수가 늘어서 나온 것인지, 1인당 수익화가 좋아져서 나온 것인지 분해할 때 씁니다. |
| **DAU** (일간 활성 사용자) | 하루에 서비스를 실제로 쓴 사용자 수입니다. |
| **MAU** (월간 활성 사용자) | 한 달에 한 번 이상 서비스를 쓴 사용자 수입니다. `DAU ÷ MAU` 비율은 **사용자가 얼마나 자주 돌아오는지(밀착도)**를 가늠하는 근사치로, 높을수록 습관적으로 쓰는 서비스입니다. |
| **코호트 분석** | 가입한 시기별로 고객을 묶어, 시간이 지나면서 그 집단의 매출·잔존이 어떻게 변하는지 추적하는 방법입니다. 전체 평균이 감추는 **신규 고객과 기존 고객의 차이**를 드러냅니다. |
| **Rule of 40** | `매출성장률(%) + FCF마진(%) ≥ 40`이면 건전하다고 보는 소프트웨어 업계의 경험칙입니다. 성장과 수익성 중 하나를 희생하더라도 합이 40을 넘으면 된다는 발상입니다. **영업이익률로 계산하면 값이 달라지므로** 어떤 마진을 썼는지 밝힙니다. |
| **매출 인식** (ASC 606) | 언제, 얼마를 매출로 잡을지 정하는 미국 회계기준입니다. 같은 계약이라도 라이선스를 계약 시점에 한꺼번에 인식하느냐 기간에 걸쳐 나눠 인식하느냐에 따라 **분기 실적 그림이 완전히 달라집니다**(EDA·소프트웨어에서 특히 중요합니다). |
| **세그먼트** (Segment) | 회사가 공시하는 사업부문별 실적입니다. 부문마다 마진 차이가 크면 전사 평균 지표는 의미가 흐려지므로, **부문별로 다른 배수를 적용하는 SOTP 평가**의 근거가 됩니다. |
| **AUM** (운용자산) | 고객을 대신해 **운용**하는 자산 총액입니다. 운용보수 매출의 기반이 됩니다. |
| **AUC** (수탁자산) | **보관만** 하는 자산 총액입니다. 운용하지 않으므로 수수료율이 AUM보다 훨씬 낮습니다. 둘을 합쳐 규모를 과시하는 회사가 있으므로 구분해서 봅니다. |
| **순이자수익** (NII, Net Interest Income) | 금융회사가 대출 등에서 받은 이자에서 예금 등에 지급한 이자를 뺀 값입니다. 금리 국면에 따라 크게 움직이는 것이 특징입니다. |
| **Float** (예치금 운용수익) | 고객이 맡겨둔 자금을 굴려서 얻는 수익입니다. 스테이블코인·보험·증권사 모델에서 금리 민감도의 핵심이며, **금리가 내려가면 직접적으로 타격**을 받습니다. |

## 6. 밸류에이션 방법론 { #valuation }

> 📖 예시로 풀어 쓴 설명: [밸류에이션 방법론](./concepts/valuation.md)

### 6.1 상대가치 (배수) 방식

| 용어 | 뜻 |
|------|-----|
| **PER** (주가수익비율, Price to Earnings Ratio) | `주가 ÷ EPS`. "지금 이익 수준이 계속된다면 투자금을 회수하는 데 몇 년이 걸리는가"로 읽으면 직관적입니다. 적정주가는 `EPS × 목표 PER`로 구합니다. 이익이 안정적인 회사에 가장 널리 쓰이며, **적자 기업에는 쓸 수 없습니다**(분모가 마이너스라 값이 무의미해집니다). |
| **PBR** (주가순자산비율, Price to Book Ratio) | `주가 ÷ BPS`. 장부상 순자산 대비 주가가 몇 배인지 봅니다. 적정주가는 `BPS × 목표 PBR`입니다. 자산이 곧 수익의 원천인 금융·자산주나 적자 기업에 유용합니다. 다만 **대형 인수로 자기자본이 단절적으로 급변하면** 과거 평균 배수와의 비교가 왜곡됩니다. |
| **PSR** (주가매출비율, Price to Sales Ratio) | `시가총액 ÷ 매출`. 적자라서 PER을 못 쓰는 고성장 기업에 씁니다. 문제는 **이익률을 전혀 반영하지 않는다**는 점입니다 — 매출총이익률 80%인 회사와 20%인 회사가 같은 PSR이면 전혀 다른 가치인데도 같아 보입니다. 반드시 매출총이익률과 함께 봅니다. |
| **EV/Sales** | `EV ÷ 매출`. PSR과 취지는 같지만 분자에 순부채를 포함해 자본구조 차이를 걷어낸 버전입니다. **빚이 많은 회사를 PSR로 보면 싸 보이는 착시**가 생기므로 이쪽이 더 정확합니다. |
| **EV/EBITDA** | `EV ÷ EBITDA`. 감가상각 정책·자본구조·세율 차이를 한꺼번에 걷어내고 비교할 수 있어 M&A와 자본집약 산업에서 표준처럼 쓰입니다. 단 **CapEx가 클수록 EBITDA는 실제 현금창출력을 과대평가**한다는 한계를 안고 씁니다(4. 수익성 · 효율성 · 안정성 심화의 "EBITDA의 함정" 참고). |
| **EV/EBIT** | `EV ÷ 영업이익`. EV/EBITDA와 달리 감가상각을 비용으로 인정하므로, **설비 재투자 부담이 큰 회사를 볼 때 더 보수적이고 현실적**입니다. |
| **PEG** (Price/Earnings to Growth) | `PER ÷ 이익성장률(%)`. 성장이 빠른 회사의 높은 PER이 정당한지 보정해 보는 지표로, 통상 1 미만이면 저렴하다고 해석합니다. 다만 **성장률을 몇 년 기준으로 잡느냐에 따라 값이 크게 갈리므로** 기준 기간을 반드시 함께 표기합니다. |
| **FCF 수익률** (FCF Yield) | `FCF ÷ 시가총액` 또는 `FCFPS ÷ 주가`. "이 회사를 통째로 사면 매년 투자금 대비 몇 %의 현금이 나오는가"입니다. **국채수익률과 직접 비교할 수 있어** 금리가 오르내릴 때 주식의 상대적 매력이 어떻게 변하는지 가늠하기 좋습니다. |
| **이익수익률** (Earnings Yield) | `EPS ÷ 주가`, 즉 PER의 역수입니다. PER 25배는 이익수익률 4%와 같은 말입니다. 국채수익률과 나란히 놓고 **"주식이 채권 대비 얼마나 더 보상해주는가"**를 볼 때 씁니다. |
| **배당수익률 기준 평가** | `DPS ÷ 주가`를 기준으로, 과거 배당수익률이 움직였던 밴드의 상단(주가가 싼 구간)과 하단을 비교 잣대로 삼는 방식입니다. 성숙한 배당주에 씁니다. **배당이 삭감될 위험이 있으면 이 방법 자체가 무의미**해지므로 배당성향·FCF 커버리지와 함께 봅니다. |
| **목표 배수** (목표 PER / 목표 PBR) | 적정주가를 계산할 때 곱하는 배수 가정입니다. 동종업계 평균이나 과거 N년 평균을 근거로 삼되, **근거와 신뢰도(High/Medium/Low)를 함께 기록**합니다. 이 값 하나가 결론을 좌우하므로 아무 숫자나 넣으면 안 됩니다. |
| **배수 확장 / 축소** (Multiple Expansion / Contraction) | 이익은 그대로인데 시장이 매기는 PER 자체가 오르내리면서 주가가 변하는 현상입니다. 주가 상승을 **"이익이 늘어난 몫"과 "배수가 오른 몫"으로 분해**해 보면, 그 상승이 실적 때문인지 분위기 때문인지 구분됩니다. |
| **동종업계 비교** (Comparables, Comps) | 비슷한 회사들의 배수와 나란히 놓고 상대적 위치를 보는 것입니다. **사업 구조·성장률·마진이 실제로 비슷한지 먼저 따지지 않으면**, "같은 섹터"라는 이유만으로 전혀 다른 회사와 비교하게 됩니다. |

### 6.2 절대가치 (현금흐름 할인) 방식

| 용어 | 뜻 |
|------|-----|
| **DCF** (현금흐름할인법, Discounted Cash Flow) | 회사가 앞으로 벌어들일 현금을 오늘 가치로 할인해 더한 값을 내재가치로 보는 방법입니다. 다른 회사와 비교하지 않고 그 회사 자체의 현금흐름만으로 값을 매기므로 절대가치 방식이라 부릅니다. **할인율과 현금흐름의 짝을 맞추는 것이 대전제**이므로 아래 "FCFE / FCFF — 할인율 정합성"을 반드시 먼저 확인합니다. |
| **FCFE** (주주 귀속 잉여현금흐름) | 이자와 원리금까지 다 치르고 **주주에게 남는 현금**입니다. 실무에서는 `CFO − CapEx`로 근사합니다. 이미 채권자 몫이 빠진 값이라 여기서 순부채를 또 빼면 안 됩니다. |
| **FCFF** (기업 전체 귀속 잉여현금흐름) | 채권자와 주주 **양쪽 모두에게 돌아갈 현금**입니다. 이자를 빼기 전 기준이라 할인하면 주주가치가 아니라 기업가치(EV)가 나오고, 여기서 순부채를 빼야 주주가치가 됩니다. |
| **FCFE / FCFF — 할인율 정합성** | **FCFE**(주주 귀속, 실무상 ≈ `CFO − CapEx`)는 **자기자본비용(Ke)**으로 할인해 곧바로 주주가치를 얻습니다. **FCFF**(기업 전체 귀속)는 **WACC**로 할인해 EV를 구한 뒤 순부채를 뺍니다. 둘을 섞으면(예: FCFE를 WACC로 할인) 결과가 틀립니다 — WACC는 Ke보다 낮으므로 가치가 부풀고, 거기서 순부채까지 빼면 이중 계산이 됩니다. 오차 크기는 [밸류에이션 방법론](./concepts/valuation.md) 참고. |
| **Gordon growth 모델** (1단계 DCF) | DCF의 가장 단순한 형태로, `주주가치/주 ≈ FCFEPS × (1 + g) ÷ (Ke − g)`로 구합니다(FCFF 기준이면 같은 식으로 EV를 구한 뒤 순부채를 뺍니다). 현금흐름이 **처음부터 끝까지 일정한 속도 g로만 자란다고 가정**하기 때문에, 실제 성장률이 g보다 훨씬 높은 고성장 기업에는 구조적으로 낮은 값이 나옵니다. 그런 경우 2단계 모델을 쓰거나 한계를 명시해야 합니다. |
| **2단계 / 다단계 DCF** | 앞으로 5~10년은 연도별로 현금흐름을 따로 예측해 할인하고, 그 이후는 터미널 밸류로 한 번에 처리하는 방식입니다. 고성장 구간과 성숙 구간의 성장률을 다르게 줄 수 있어 **고성장 기업의 표준 접근**입니다. |
| **터미널 밸류** (TV, 잔존가치) | 명시적으로 예측한 기간 이후의 가치를 한 덩어리로 계산한 값입니다. 영구성장 방식(`FCF × (1 + g) ÷ (r − g)`)이나 출구배수 방식(`최종연도 EBITDA × 목표 EV/EBITDA`)을 씁니다. ⚠️ **DCF 총가치의 60~80%가 여기서 나오는 경우가 흔하므로**, 전체에서 차지하는 비중을 반드시 밝혀야 합니다 — 사실상 가정 하나가 결론을 정하는 셈이기 때문입니다. |
| **영구성장률** (g) | 예측 기간 이후에도 현금흐름이 영원히 이 속도로 자란다고 가정하는 비율입니다. 통상 장기 명목 GDP 성장률에 가까운 2~3%를 씁니다. **g가 장기 경제성장률을 넘으면 그 회사가 언젠가 경제 전체보다 커진다는 뜻**이 되므로 성립하지 않습니다. |
| **DDM** (배당할인모형, Dividend Discount Model) | 앞으로 받을 배당금을 요구수익률로 할인해 내재가치를 구합니다. 주주가 실제로 손에 쥐는 현금만 세는 가장 보수적인 방법이라 **배당이 안정적인 성숙 기업에 적합**하고, **무배당 기업에는 적용할 수 없습니다.** |
| **NPV** (순현재가치) | `미래 현금흐름의 현재가치 합계 − 초기 투자액`. 0보다 크면 그 투자가 요구수익률을 넘어선다는 뜻입니다. DCF의 기본 원리 그 자체입니다. |
| **IRR** (내부수익률) | NPV를 0으로 만드는 할인율로, "이 투자가 연 몇 %짜리인가"로 읽습니다. 현금흐름의 부호가 여러 번 바뀌면 **답이 여러 개 나올 수 있어** NPV와 함께 봐야 합니다. |
| **현재가치와 할인** | 미래의 1달러는 오늘의 1달러보다 가치가 낮습니다 — 그 사이에 그 돈을 굴려 수익을 낼 수 있었기 때문입니다. 이 차이를 되돌려 오늘 가치로 환산하는 계산이 할인입니다. **할인율이 높을수록, 그리고 시점이 멀수록 현재가치는 작아집니다.** 성장주가 금리에 더 민감한 이유가 여기 있습니다(9. 거시경제의 "금리가 주가에 닿는 두 경로" 참고). |
| **SOTP** (부문별 합산가치, Sum of the Parts) | 사업부마다 성격에 맞는 방법론과 배수를 따로 적용해 값을 매긴 뒤 전부 더하고, 거기서 순부채와 지주회사 할인을 조정하는 방식입니다. **성격이 전혀 다른 사업을 겸영하는 회사**라면 하나의 배수를 씌우는 것보다 타당합니다. |
| **잔여이익모형** (RIM, Residual Income Model) | `가치 = 현재 자기자본 장부가 + 미래 초과이익의 현재가치`이며, 초과이익은 `순이익 − 자기자본비용 × 자기자본`입니다. 가치의 상당 부분이 **이미 확정된 장부가에서 나오므로 터미널 밸류 의존도가 낮고**, 그래서 자산이 곧 사업인 금융회사 평가에 자주 씁니다. |
| **청산가치** (Liquidation Value) | 자산을 전부 팔아 부채를 갚고 남는 값입니다. 회사가 계속 굴러간다는 가정 자체가 흔들릴 때 **하방의 바닥선**으로 씁니다. |
| **DCF 민감도 분석** | 할인율과 g를 조금씩 바꿔가며 적정주가가 얼마나 흔들리는지 표로 만드는 것입니다. `(할인율 − g)`가 작을수록 민감도가 급격히 커지므로, 이 표 없이 DCF 값 하나만 제시하면 정밀해 보이는 착각을 줍니다. |
| **시나리오 분석** | 낙관·기본·보수 세 가지 가정 묶음으로 각각 값을 내는 것입니다. 민감도 분석이 "변수 하나씩" 흔든다면, 시나리오는 **서로 연관된 변수들을 한꺼번에** 흔듭니다(침체가 오면 매출·마진·배수가 동시에 내려가는 식). |
| **역DCF** (Reverse DCF) | 순서를 뒤집어, **현재 주가를 정당화하려면 어떤 성장률과 마진이 필요한지** 거꾸로 푸는 방법입니다. "시장은 지금 무엇을 가정하고 있나"를 묻는 것이라, 내가 만든 가정이 상식적인지 교차검증하는 데 유용합니다. |

### 6.3 할인율 구성요소

| 용어 | 뜻 |
|------|-----|
| **WACC** (가중평균자본비용) | 주주 몫의 자본비용과 빚의 이자비용을, 각각이 차지하는 비중으로 가중평균한 값입니다. 공식은 `Ke × E/(D+E) + Kd × (1−t) × D/(D+E)`입니다. **FCFF와 짝을 이루는 할인율**이며, FCFE에 쓰면 안 됩니다(6.2의 "FCFE / FCFF — 할인율 정합성" 참고). |
| **자기자본비용** (Ke) | 주주가 이 주식에 최소한 요구하는 수익률입니다. 보통 CAPM으로 `Ke = 무위험이자율 + β × 시장위험프리미엄`으로 추정합니다. **FCFE 기준 DCF의 할인율은 WACC가 아니라 이 값**입니다. |
| **CAPM** (자본자산가격결정모형) | 위험이 큰 자산일수록 더 높은 기대수익률을 요구한다는 모형으로, 실무에서 Ke를 구하는 가장 흔한 방법입니다. 다만 **베타를 몇 년치로 추정하느냐, 어떤 시장 지수와 비교하느냐에 따라 결과가 꽤 달라진다**는 한계를 안고 씁니다. |
| **무위험이자율** (Rf) | 떼일 위험이 없다고 간주하는 수익률로, 통상 미국 10년물 국채수익률을 씁니다. 원칙은 **할인 대상 현금흐름의 기간과 국채 만기를 맞추는 것**이라, 장기 현금흐름을 다루면 10년물이나 30년물을 씁니다. |
| **베타** (β) | 시장 전체가 1% 움직일 때 이 주식이 몇 % 움직이는지 나타냅니다. 1보다 크면 시장보다 크게 출렁인다는 뜻입니다. **추정 기간(2년/5년)과 비교 지수에 따라 값이 달라지므로** 어느 기준인지 밝힙니다. |
| **시장위험프리미엄** (ERP) | 주식시장 전체가 무위험이자율보다 얼마나 더 보상해주기를 요구받는지에 대한 값입니다. 통상 4~6%대의 추정치가 쓰이는데, **출처마다 편차가 크므로 한 값으로 단정하지 말고 범위로 기록**하고 민감도 분석에서 다룹니다. |
| **타인자본비용** (Kd) | 회사가 빚을 낼 때 부담하는 이자율입니다. `이자비용 ÷ 평균 이자부 차입금`으로 근사하거나 그 회사 신용등급에 해당하는 시장 금리를 씁니다. 이자는 세금을 줄여주는 효과가 있으므로 **WACC에 넣을 때는 세후 기준(`Kd × (1−t)`)**을 씁니다. |
| **규모 프리미엄** (Size Premium) | 소형주는 유동성과 사업 안정성이 떨어진다는 이유로 CAPM 결과 위에 얹는 할인율 가산분입니다. 자의성이 크므로 **얼마를 왜 더했는지 반드시 밝힙니다.** |
| **국가 위험 프리미엄** (Country Risk Premium) | 신흥국 기업에 정치·제도·통화 위험을 반영해 얹는 가산분입니다. 규모 프리미엄과 마찬가지로 근거를 명시해야 합니다. |
| **요구수익률** (r) | 투자자가 이 자산에 최소한 기대하는 수익률입니다. DDM에서 쓰는 할인율이며, 주식에서는 대개 자기자본비용(Ke)과 같은 뜻으로 씁니다. |
| **자본비용 vs 기대수익률** | 같은 숫자를 양쪽에서 부르는 이름입니다. 회사 입장에서는 "자본을 쓰는 대가(비용)"이고, 투자자 입장에서는 "그래서 내가 요구하는 수익률"입니다. 자료마다 표현이 다를 뿐 가리키는 값은 같습니다. |

### 6.4 결과 해석

| 용어 | 뜻 |
|------|-----|
| **괴리율** | `(실제주가 ÷ 종합 적정주가 − 1) × 100`. 양수면 계산한 값보다 비싸게 거래되는 중(고평가), 음수면 싸게 거래되는 중(저평가)이라는 뜻입니다. |
| **목표주가 / 적정주가** | 방법론별로 각각 산출한 값과, 그것들을 신뢰도로 가중평균한 종합값입니다. **단순 평균은 이상치 하나에 쉽게 끌려가므로** 신뢰도 가중을 기본으로 씁니다. 특정 방법론의 한계가 결론을 좌우할 정도면 가중치를 낮추거나 아예 뺍니다. |
| **안전마진** (Margin of Safety) | 내재가치 추정이 틀릴 가능성에 대비해, 적정주가보다 충분히 낮은 가격에서만 매수하는 완충폭입니다. 계산이 정교해서 두는 것이 아니라 **틀릴 것을 전제로** 두는 장치입니다. |
| **내재가치 vs 시장가격** | 내재가치는 현금흐름을 근거로 계산한 값이고 시장가격은 지금 실제로 거래되는 값입니다. **둘이 다르다는 관찰만으로는 아무것도 증명되지 않습니다** — 시장이 틀렸을 수도, 내 가정이 틀렸을 수도 있습니다. |
| **가치 함정** (Value Trap) | 배수가 싸 보여서 샀는데 실적이 계속 나빠지면서 계속 싼 상태로 남아 있는 경우입니다. **"싸다"는 것과 "좋다"는 것은 전혀 다른 판단**이라는 점을 상기시키는 개념입니다. |

## 7. 투자 판단 / 거버넌스 용어 { #investment-terms }

> 📖 예시로 풀어 쓴 설명: [투자 판단 / 거버넌스 용어](./concepts/investment-terms.md)

| 용어 | 뜻 |
|------|-----|
| **Bull Case** | 투자를 지지하는 강점과 논리, 그리고 그것이 실현됐을 때 도달하는 상방 밸류에이션입니다. |
| **Bear Case** | 반대로 우려되는 리스크와 약점입니다. 이 저장소에서는 세 가지가 모두 있어야 제대로 쓴 것으로 봅니다 — **(a) 하방을 촉발하는 관찰 가능한 사건(트리거), (b) 그 시나리오에서 도달하는 배수·주가, (c) 이 논거가 강화되거나 무효화되는지 알려줄 확인·기각 신호.** 셋 중 하나라도 없으면 "리스크: 경쟁 심화" 같은 한 줄과 다를 바 없어집니다. |
| **Moat** (경쟁 해자) | 경쟁자가 쉽게 넘어오지 못하게 막는 구조적 진입장벽입니다. 브랜드, 전환비용, 네트워크 효과, 규모의 경제, 규제 라이선스 등이 원천이 됩니다. 해자가 실재하는지는 **ROIC가 자본비용을 계속 넘고 있는지**로 확인합니다. |
| **전환비용** (Switching Cost) | 고객이 경쟁 제품으로 갈아탈 때 드는 비용과 수고입니다. 설계 도구나 기간계 시스템처럼 **업무 흐름에 깊이 박힌 제품일수록 높고**, 그만큼 가격을 올려도 고객이 떠나기 어렵습니다. |
| **네트워크 효과** | 사용자가 늘어날수록 제품의 가치가 커지는 성질입니다. 거래소·플랫폼의 핵심 해자이지만, **임계점 아래로 떨어지면 같은 논리로 빠르게 무너진다**는 양면성이 있습니다. |
| **규모의 경제** | 생산량이 늘어날수록 제품 하나당 원가가 낮아지는 효과입니다. 고정비 비중이 큰 사업에서 강하게 나타납니다. |
| **가격 결정력** (Pricing Power) | 고객을 크게 잃지 않으면서 가격을 올릴 수 있는 힘입니다. **인플레이션 국면에서 마진을 지켜냈는지**를 보면 실재 여부가 드러납니다 — 원가는 올랐는데 마진이 유지됐다면 가격을 전가한 것입니다. |
| **트리거** | ⚠️ 문서에 따라 뜻이 다릅니다. **밸류에이션 / 적정주가** 문서에서는 밸류에이션 숫자만으로 정하는 가격 레벨을 뜻하고, **투자 판단** 문서에서는 거기에 리스크와 정성적 조건까지 합친 최종 매수·매도 기준을 뜻합니다. 섞어 쓰지 않습니다. |
| **투자 논거** (Thesis) | "이 회사에 왜 투자하는가"를 한 문단으로 정리한 것입니다. **논거가 깨지는 조건(thesis breaker)을 함께 적어둬야** 나중에 판단이 맞았는지 복기할 수 있습니다. |
| **촉매** (Catalyst) | 가려져 있던 가치가 주가에 반영되게 만들 만한 구체적 사건입니다. 신제품 출시, 규제 승인, 대형 수주, 사업부 분사 등이 해당합니다. |
| **10-K** | 미국 상장사의 **연간보고서**입니다. 사업 설명, 리스크 요인, 감사받은 재무제표, MD&A가 모두 들어 있어 **이 저장소에서 가장 신뢰도가 높은 1차 출처**입니다. |
| **10-Q** | **분기보고서**입니다. 10-K보다 간략하고 감사를 받지 않은(검토만 받은) 재무제표가 들어갑니다. |
| **8-K** | **수시보고서**로, 인수·경영진 교체·실적 발표처럼 중요한 사건이 생겼을 때 그때그때 제출합니다. 실적 발표 자료(보도자료·Non-GAAP 조정표)는 대개 8-K의 첨부(Ex-99.1)로 나옵니다. |
| **S-1** | IPO를 위한 최초 등록신고서입니다. 상장 전 재무와 리스크가 **처음으로 공개되는 문서**입니다. |
| **위임장** (Proxy Statement, DEF 14A) | 주주총회 전에 공시하는 문서로, 경영진 보상 내역과 지분 구조 등 **거버넌스 정보의 공식 출처**입니다. |
| **13F** | 운용자산 1억 달러 이상인 기관이 제출하는 분기말 보유 종목 공시입니다. ⚠️ **분기 종료 후 45일까지 제출하면 되므로 이미 과거 정보**이며, 그 사이 다 팔았을 수도 있습니다. |
| **Form 4** | 내부자(임원·이사·10% 이상 주주)의 매매 신고로, **2영업일 안에** 제출됩니다. 13F보다 훨씬 신선한 정보입니다. |
| **MD&A** (경영진 논의 및 분석) | 10-K·10-Q 안에서 경영진이 실적이 왜 그렇게 변했는지 직접 설명하는 절입니다. **숫자만으로는 안 보이는 맥락**이 여기에 있습니다. |
| **어닝콜** (Earnings Call) | 실적 발표 직후 경영진이 애널리스트를 상대로 진행하는 설명회입니다. 질의응답에서 가이던스의 전제나 우려 사항이 드러나는 경우가 많습니다. |
| **어닝서프라이즈** | 실제 실적이 컨센서스를 얼마나 웃돌거나 밑돌았는지입니다. 주가 반응은 절대 실적보다 이 차이에 반응하는 경향이 있습니다. |
| **차등의결권** (Dual-class) | 의결권이 다른 여러 종류의 주식을 함께 발행하는 구조입니다. 창업자가 지분율보다 훨씬 큰 의결권을 갖게 되는 경우가 많아 **소액주주가 경영진을 견제하기 어렵다**는 점에서 거버넌스 리스크로 봅니다. |
| **기관 지분율** | 펀드·연기금 등 기관 투자자가 보유한 지분 비율입니다. 높으면 정보가 충분히 반영돼 있다는 뜻이기도 하고, 기관의 대량 매도에 취약하다는 뜻이기도 합니다. |
| **내부자 지분율** | 임원·이사 등 내부자가 보유한 지분 비율입니다. 적당히 높으면 주주와 이해관계가 일치한다는 긍정 신호이지만, **지나치게 높으면 견제가 불가능**해져 소액주주 권리가 약해집니다. |
| **자본 배분** (Capital Allocation) | 벌어들인 현금을 재투자·인수·배당·자사주매입·부채상환 중 어디에 쓸지 결정하는 경영진의 선택입니다. 장기 수익률을 가르는 **가장 중요한 경영 능력**으로 봅니다. |
| **경영진 보상 구조** | 보상이 어떤 지표에 연동되는지(매출 성장·EPS·TSR 등)입니다. **어떤 지표를 걸어두느냐가 경영진의 행동을 만들기 때문에**(예: EPS에 연동되면 자사주매입 유인이 커짐) 위임장에서 확인할 가치가 있습니다. |
| **행동주의 투자자** (Activist) | 지분을 확보한 뒤 이사회 교체·사업부 분사·주주환원 확대 등을 공개적으로 요구하는 투자자입니다. |

## 8. 리스크 · 회계 품질 { #risk }

> 📖 예시로 풀어 쓴 설명: [리스크 · 회계 품질](./concepts/risk-and-quality.md)

| 용어 | 뜻 |
|------|-----|
| **체계적 위험 vs 비체계적 위험** | 체계적 위험은 시장 전체에 작용해 **분산으로 없앨 수 없는** 위험(금리·경기·전쟁)이고, 비체계적 위험은 개별 기업에만 해당하는 위험(리콜·소송·경영진 이탈)입니다. **분산투자로 줄일 수 있는 것은 후자뿐**이라는 점이 이 구분의 핵심입니다. |
| **분산투자** | 서로 잘 같이 움직이지 않는 자산에 나눠 담아 전체 변동성을 줄이는 것입니다. **같은 섹터 종목을 여러 개 담는 것은 분산 효과가 제한적**입니다 — 같은 충격에 함께 움직이기 때문입니다. |
| **변동성** (표준편차) | 수익률이 얼마나 출렁이는지를 나타냅니다. 위험의 대용치로 널리 쓰이지만 **"손실 가능성"과 정확히 같은 개념은 아닙니다** — 위로 크게 오르는 것도 변동성으로 계산되기 때문입니다. |
| **최대낙폭** (MDD) | 고점 대비 가장 크게 떨어졌던 폭입니다. 실제로 견뎌야 하는 고통의 크기를 변동성보다 직관적으로 보여줍니다. |
| **샤프 비율** | 위험 1단위당 얻은 초과수익입니다. 수익률만 비교하면 위험을 크게 진 쪽이 유리해 보이므로, 위험으로 나눠 공정하게 비교하려는 지표입니다. |
| **소르티노 비율** | 샤프 비율에서 **하락 변동성만**을 위험으로 세는 버전입니다. 위로 튀는 것까지 위험으로 계산하는 샤프의 한계를 보완합니다. |
| **VaR** (Value at Risk) | 일정 확률 범위 안에서 예상되는 최대 손실액입니다. **꼬리 위험(그 확률 밖의 극단 상황)을 과소평가**한다는 비판이 있습니다. |
| **집중 위험** | 매출이 특정 고객·제품·지역에 쏠려 있는 상태입니다. 10-K는 매출의 10% 이상을 차지하는 고객을 공시하도록 돼 있어 거기서 확인할 수 있습니다. |
| **키맨 리스크** | 창업자나 핵심 인물 한 사람에게 사업이 지나치게 의존하는 상태입니다. 차등의결권과 겹치면 영향이 훨씬 커집니다. |
| **규제 / 정책 리스크** | 인허가, 독점금지 조사, 수출통제, 세제 변화처럼 **외부 규칙이 바뀌면서 생기는 위험**입니다. 금융·디지털자산·방산에서 특히 큽니다. |
| **환위험** | 환율이 변해 해외 매출·자산의 원화(또는 달러) 환산액이 흔들리는 위험입니다. 해외 매출 비중이 큰 회사일수록 큽니다. |
| **금리위험** | 금리가 변해 이자 부담과 밸류에이션이 함께 흔들리는 위험입니다. 변동금리 차입이 많거나 먼 미래 현금흐름 비중이 큰 회사에서 큽니다. |
| **신용위험** | 거래 상대가 돈을 갚지 못할 위험입니다. 매출채권이 큰 회사, 금융회사에서 핵심 위험입니다. |
| **유동성 위험** | 필요할 때 자산을 제값에 팔지 못할 위험입니다. 소형주와 비상장 자산에서 큽니다. |
| **희석 위험** | 유상증자·전환사채·SBC로 주식수가 늘어나 **기존 주주의 몫이 줄어드는** 위험입니다. 희석주식수 추이로 확인합니다. |
| **이익의 질** (Earnings Quality) | 장부상 이익이 실제 현금과 얼마나 일치하는지입니다. **CFO가 순이익을 몇 년째 계속 밑돌면** 이익이 현금으로 뒷받침되지 않는다는 뜻이라 우선 의심 대상이 됩니다. |
| **발생액** (Accruals) | `순이익 − 영업활동현금흐름`. 이 값이 크고 계속 양수라면 이익이 **회계적 추정에 많이 기대고 있다**는 신호입니다. |
| **매출채권·재고 급증** | 매출 증가율을 크게 웃도는 매출채권·재고 증가입니다. 밀어내기 판매나 수요 둔화의 조기 신호일 수 있으므로 DSO·DIO로 확인합니다(4. 수익성 · 효율성 · 안정성 심화 참고). |
| **채널 스터핑** | 유통망에 물건을 밀어 넣어 매출을 앞당겨 인식하는 관행입니다. **다음 분기 매출을 당겨쓴 것**이라 반드시 반작용이 따라옵니다. |
| **잦은 일회성 비용** | "일회성"이라며 조정하는 비용이 매년 반복된다면 그건 사실상 경상 비용입니다. **Non-GAAP 조정 항목의 3~5년 추이**를 나열해 보면 드러납니다. |
| **회계정책 변경** | 추정 방식이나 회계 정책을 바꾸는 것입니다. 정당한 이유가 있을 수 있지만, 변경 직후 실적이 좋아졌다면 그 효과를 걷어내고 봐야 합니다. |
| **재작성** (Restatement) | 과거에 발표한 재무제표가 틀렸다며 다시 발표하는 것입니다. **심각한 신호로 취급**합니다 — 그 회사가 낸 다른 숫자도 믿기 어려워지기 때문입니다. |
| **감사의견** | 적정 / 한정 / 부적정 / 의견거절 네 가지입니다. **적정이 아니면 그 자체로 중대한 경고**입니다. |
| **계속기업 불확실성** (Going Concern) | 감사인이 "이 회사가 1년 안에 존속할 수 있을지 의문"이라고 명시적으로 표시한 것입니다. |
| **내부통제 중요한 취약점** (Material Weakness) | 재무보고 내부통제에 중대한 결함이 있다는 공시입니다. 숫자 자체의 신뢰도를 떨어뜨립니다. |
| **특수관계자 거래** | 경영진·대주주·관계사와 하는 거래입니다. 조건이 시장 가격에 비해 공정한지 주석에서 확인할 필요가 있습니다. |
| **우발부채** | 아직 확정되지 않았지만 현실화되면 부담이 되는 채무입니다. 진행 중인 소송, 보증, 세무 분쟁 등이 해당하며 **본표가 아니라 주석에** 있습니다. |
| **Altman Z-Score** | 여러 재무비율을 결합해 부도 가능성을 점수화한 모형입니다. **제조업 데이터로 만들어져 금융·소프트웨어에는 잘 맞지 않습니다.** |
| **Piotroski F-Score** | 수익성·레버리지·효율성 9개 항목을 0 또는 1로 채점해 합산한 점수(0~9)로, 재무 상태가 개선되고 있는지를 봅니다. |
| **Beneish M-Score** | 회계 조작 가능성을 추정하는 모형입니다. 어디까지나 **의심 대상을 걸러내는 선별 도구이지 판정 도구가 아닙니다.** |
| **공매도 리포트** | 공매도 투자자가 공개하는 부정적 분석입니다. 주가 하락에 이해관계가 걸려 있으므로 **주장과 증거를 분리해서** 검증합니다 — 증거가 사실이면 이해관계와 무관하게 유효합니다. |
| **생존 편향** | 실패해서 사라진 사례가 표본에서 빠지는 바람에 과거 성과가 실제보다 좋아 보이는 착시입니다. |
| **확증 편향** | 자기 논거를 지지하는 정보만 찾아보는 경향입니다. **Bull Case와 Bear Case를 반드시 둘 다 쓰게 하는 규칙**이 이 편향에 대한 장치입니다. |

## 9. 거시경제 { #macro }

> 📖 예시로 풀어 쓴 설명: [거시경제](./concepts/macroeconomics.md)
>
> ⚠️ 아래 지표들의 **현재 수준은 여기 적지 않습니다.** 계속 바뀌므로 항상 원출처(FRED, BLS, 연준, 미 재무부)에서 확인하세요. 여기서는 "그 지표가 무엇이고 주가에 어떤 경로로 닿는가"만 다룹니다.

| 용어 | 뜻 |
|------|-----|
| **GDP** (국내총생산) | 한 나라에서 일정 기간 생산된 최종 재화·서비스의 총가치입니다. **명목 GDP**는 그해 가격 그대로, **실질 GDP**는 물가 상승분을 제거한 기준입니다. 경제 규모와 성장 속도를 재는 가장 기본적인 척도입니다. |
| **경기순환** | 확장 → 정점 → 수축 → 저점을 반복하는 흐름입니다. 업종마다 이 국면에 대한 민감도가 달라서, 경기가 좋을 때 크게 오르는 경기민감주와 상대적으로 덜 흔들리는 경기방어주로 나뉩니다. |
| **경기침체** (Recession) | 통상 "실질 GDP가 2개 분기 연속 마이너스"를 기술적 침체라고 부릅니다. 다만 **미국의 공식 판정은 NBER이 고용·소득·생산을 종합해 사후에** 내리므로, 침체 판정이 나올 때는 이미 한참 지난 뒤인 경우가 많습니다. |
| **인플레이션 vs 디플레이션** | 물가가 지속적으로 오르는 것과 내리는 것입니다. 완만한 인플레이션은 정상이지만, 디플레이션은 소비를 미루게 만들어 경제를 더 위축시키기 때문에 중앙은행이 더 두려워합니다. |
| **디스인플레이션** | 물가가 **여전히 오르고는 있지만 오르는 속도가 느려지는** 상태입니다. 물가가 내려가는 디플레이션과 전혀 다른 개념인데 자주 혼동됩니다. |
| **CPI** (소비자물가지수) | 소비자가 사는 물건·서비스 묶음의 가격 변화를 측정한 지수입니다. 가장 널리 인용되는 물가 지표입니다. |
| **PCE** (개인소비지출 물가지수) | **연준이 정책 판단에 주로 참고하는 물가 지표**입니다. 가격이 오른 물건 대신 다른 것을 사는 소비 대체 효과를 반영하기 때문에 **통상 CPI보다 낮게 나오는 경향**이 있습니다. 어느 지표를 인용하는지에 따라 "물가가 몇 %"가 달라집니다. |
| **근원 지표** (Core) | CPI나 PCE에서 **변동성이 큰 식품과 에너지를 뺀** 버전입니다. 유가 급등락 같은 일시적 요인에 흔들리지 않아 **기저의 물가 추세**를 더 안정적으로 보여주기 때문에 정책 판단에서 더 중시됩니다. |
| **스태그플레이션** | 성장은 정체되는데 물가는 오르는 상태입니다. **금리를 올리면 성장이 더 꺾이고 내리면 물가가 더 오르므로** 정책 대응이 가장 까다로운 국면입니다. |
| **기준금리** (연방기금금리) | 미국 중앙은행이 목표 범위를 정하는 초단기 금리입니다. **모든 자산 가격의 출발점**이며, DCF의 무위험이자율을 통해 밸류에이션에 직접 닿습니다. |
| **연준** (Fed, 연방준비제도) | 미국의 중앙은행입니다. 물가 안정과 최대 고용이라는 두 가지 임무를 동시에 지고 있어, 둘이 상충할 때 어느 쪽에 무게를 두는지가 시장의 관심사가 됩니다. |
| **FOMC** (연방공개시장위원회) | 연준에서 실제로 통화정책을 결정하는 위원회로, 연 8회 회의를 엽니다. |
| **점도표** (Dot Plot) | FOMC 위원 각자가 예상하는 향후 금리 수준을 점으로 찍어 놓은 분포도입니다. **이미 내려진 결정보다 이 전망이 바뀌는 것이 시장을 더 크게 움직이는** 경우가 많습니다. |
| **QE** (양적완화) | 중앙은행이 국채·채권을 사들여 시중에 돈을 푸는 정책입니다. 기준금리를 더 내릴 여지가 없을 때 쓰는 추가 수단입니다. |
| **QT** (양적긴축) | 반대로 보유 자산을 줄여 시중의 돈을 회수하는 정책입니다. |
| **테이퍼링** | 자산 매입 규모를 점진적으로 줄여가는 것입니다. **완화의 축소일 뿐 긴축 그 자체는 아니라는 점**에서 QT와 다릅니다. |
| **국채수익률** (Treasury Yield) | 미국 국채에 투자했을 때 얻는 수익률입니다. **2년물은 앞으로의 정책금리 기대**를, **10년물은 장기 성장·물가 기대**를 반영합니다. 10년물은 DCF 무위험이자율의 표준 근거로 쓰입니다. |
| **수익률곡선** (Yield Curve) | 만기별 국채 수익률을 이은 곡선입니다. 정상적으로는 돈을 오래 빌려줄수록 더 받아야 하므로 우상향합니다. |
| **장단기 금리차 역전** | 장기물 수익률이 단기물보다 낮아지는 현상입니다. 역사적으로 침체의 선행 신호로 주목받아 왔지만, **신호와 실제 침체 사이의 시차가 길고 예외도 있어** 단독 근거로 쓰기는 어렵습니다. |
| **실질금리** | `명목금리 − 기대인플레이션`. **자산 가격에 실제로 작용하는 것은 명목금리가 아니라 실질금리**입니다 — 명목금리가 높아도 물가가 그만큼 오르면 실질 부담은 그대로이기 때문입니다. |
| **신용스프레드** | `회사채 수익률 − 같은 만기 국채 수익률`. 벌어지면 시장이 기업의 부도 위험을 더 크게 보고 있다는 뜻이라, **위험선호 심리의 온도계** 역할을 합니다. |
| **실업률** | 일할 의사가 있는 사람 중 일자리를 못 구한 비율입니다. 연준의 두 임무 중 하나라 금리 경로 전망에 직접 영향을 줍니다. |
| **비농업고용** (NFP) | 매월 발표되는 농업 외 부문의 신규 고용자 수입니다. 실업률과 함께 고용 상황을 판단하는 핵심 지표로, 발표일에 시장이 크게 움직입니다. |
| **JOLTS** (구인·이직 보고서) | 빈 일자리 수와 자발적 이직률을 보여줍니다. 빈 일자리가 많고 자발적 이직이 활발하면 노동시장이 뜨겁다는 뜻이라 임금 상승 압력으로 이어집니다. |
| **PMI / ISM** (구매관리자지수) | 기업 구매담당자를 대상으로 한 설문 기반 지표로, **50을 넘으면 확장, 밑돌면 위축**으로 읽습니다. 실제 통계보다 빨리 나오는 선행지표입니다. |
| **소비자심리지수** | 가계가 체감하는 경기와 앞으로의 전망을 설문으로 측정한 지표입니다. |
| **소매판매** | 실제로 지출된 소비 금액입니다. **미국 GDP의 약 3분의 2가 소비**라 비중이 큽니다. 심리는 나쁜데 소매판매는 견조한 식으로 둘이 어긋나는 경우가 있어 함께 봅니다. |
| **환율** | 통화 간 교환 비율입니다. 달러가 강해지면 해외에서 번 돈을 달러로 바꿀 때 금액이 줄어들어, **해외 매출 비중이 큰 미국 기업의 실적을 직접 깎습니다**(3. 표기 규칙의 "상수통화 기준" 참고). |
| **달러인덱스** (DXY) | 주요 통화 묶음 대비 달러의 가치를 지수화한 것입니다. 달러의 전반적인 강약을 한 숫자로 볼 때 씁니다. |
| **무역수지** | 상품·서비스의 수출액에서 수입액을 뺀 값입니다. |
| **경상수지** | 무역수지에 해외 투자 소득과 이전 거래까지 더한, 더 넓은 대외 거래 수지입니다. |
| **관세** | 수입품에 매기는 세금입니다. 원가를 직접 올리므로, 그 비용을 가격에 전가할 수 있는 회사와 그렇지 못한 회사의 마진이 갈립니다. |
| **수출규제** | 특정 기술·품목을 특정 국가에 팔지 못하게 하는 제한입니다. 해당 시장 매출이 통째로 사라질 수 있어 반도체·방산에서 큰 리스크입니다. |
| **재정정책 vs 통화정책** | 재정정책은 **정부**가 지출과 세금을 조절하는 것이고, 통화정책은 **중앙은행**이 금리와 유동성을 조절하는 것입니다. 방산·인프라처럼 정부 예산에 매출이 걸린 업종은 재정정책의 영향을 직접 받습니다. |
| **원자재 가격** (유가 등) | 에너지·금속 등의 가격입니다. 기업의 원가 구조에 직접 들어가는 동시에, **인플레이션 경로를 통해 금리에도 영향**을 주므로 두 방향으로 작용합니다. |
| **M2** (통화량) | 현금과 예금 등 시중에 풀린 돈의 총량입니다. 유동성 환경이 팽창 중인지 수축 중인지 보는 지표입니다. |
| **소프트랜딩 vs 하드랜딩** | 금리를 올려 물가를 잡으면서도 침체는 피하는 시나리오(소프트랜딩)와, 침체를 동반하고 마는 시나리오(하드랜딩)입니다. |
| **필립스 곡선** | 실업률이 낮으면 임금과 물가가 오른다는 경험적 역관계입니다. 최근에는 잘 들어맞지 않는 국면이 잦아 **참고 틀 정도로만** 씁니다. |
| **금리가 주가에 닿는 두 경로** | ① **할인율 경로**: 금리↑ → 요구수익률↑ → 미래 현금흐름의 현재가치↓. 먼 미래의 이익이 가치의 대부분인 성장주가 더 크게 하락합니다. ② **실적 경로**: 금리↑ → 소비·투자 위축 → 매출·이익↓, 그리고 차입이 많은 기업은 이자 부담까지 늘어납니다. **두 경로는 동시에 작동**하므로 금리가 오를 때 성장주와 부채 많은 기업이 함께 맞습니다. |

## 10. 시장 구조 · 거래 { #market }

> 📖 예시로 풀어 쓴 설명: [시장 구조 · 거래](./concepts/market-structure.md)

| 용어 | 뜻 |
|------|-----|
| **시가총액** | `주가 × 발행주식수`. 회사의 시장 가격 전체입니다. 통상 대형(100억 달러 이상)·중형·소형·마이크로로 나눠 부르며, **규모에 따라 유동성과 변동성이 크게 다릅니다.** |
| **유통주식수** (Float) | 실제로 시장에서 거래될 수 있는 주식수로, 내부자와 전략적 투자자가 묶어둔 물량을 뺀 것입니다. **Float이 작으면 적은 거래량에도 주가가 크게 흔들립니다.** |
| **유동성** (Liquidity) | 원하는 가격에 원하는 만큼 사고팔 수 있는 정도입니다. 유동성이 낮으면 팔고 싶을 때 제값을 못 받습니다. |
| **호가 스프레드** | 사겠다는 최고 가격과 팔겠다는 최저 가격의 간격입니다. **스프레드가 넓으면 사고파는 것만으로 비용이 발생**하므로, 소형주에서는 이 비용이 무시할 수 없습니다. |
| **지수** (Index) | S&P 500·나스닥 100·러셀 2000처럼 시장을 대표하도록 묶은 종목 집합입니다. 성과를 재는 기준(벤치마크)이자, 패시브 자금이 실제로 사들이는 대상입니다. |
| **패시브 운용** | 종목을 고르지 않고 지수를 그대로 따라가는 운용 방식입니다. **지수에 편입되거나 편출되면 패시브 자금이 기계적으로 사고팔기 때문에**, 실적과 무관한 주가 변동이 생깁니다. |
| **ETF** (상장지수펀드) | 펀드를 주식처럼 거래소에서 사고팔 수 있게 만든 상품입니다. 대부분 지수를 추종합니다. |
| **IPO** (기업공개) | **신주를 발행해 자금을 조달하면서** 상장하는 것입니다. 회사에 돈이 들어오는 대신 기존 주주 지분은 희석됩니다. |
| **직상장** (Direct Listing) | 신주를 발행하지 않고 **기존 주식만 거래소에 올리는** 방식입니다. 회사에 새로 들어오는 돈은 없고 희석도 없습니다. |
| **SPAC** | 이미 상장된 껍데기 회사와 합병해 우회 상장하는 방식입니다. IPO보다 빠르지만 **실적 전망 공시 요건이 느슨해** 상장 후 전망이 크게 어긋나는 사례가 많았습니다. |
| **락업** (Lock-up) | 상장 후 일정 기간 기존 주주가 주식을 팔지 못하게 하는 약정입니다. **해제일 전후로 대량 매물이 나올 수 있어**, 상장 초기 기업은 해제 시점을 확인합니다. |
| **유상증자** | 신주를 발행해 자금을 조달하는 것입니다. 기존 주주 지분이 희석되므로 **조달한 돈을 어디에 쓰는지**가 판단의 핵심입니다. |
| **ATM 발행** (At-the-Market) | 시장가로 조금씩 나눠 신주를 발행하는 방식입니다. 한 번에 크게 발행하지 않아 주가 충격은 작지만, **조용히 지속적으로 희석**된다는 점에서 주식수 추이를 봐야 합니다. |
| **전환사채** (CB) | 나중에 정해진 조건으로 주식으로 바꿀 수 있는 채권입니다. 지금은 부채지만 앞으로 주식이 될 수 있어 **희석주식수 계산에 영향**을 줍니다. |
| **자사주 소각** | 사들인 자기주식을 없애 발행주식수를 실제로 줄이는 것입니다. **소각하지 않고 보유만 하면** 나중에 인수 대가나 임직원 보상으로 다시 풀릴 수 있어 희석 방지 효과가 확정되지 않습니다. |
| **배당기준일** (Record Date) | 배당을 받을 주주를 확정하는 날입니다. 이날 주주명부에 올라 있어야 배당을 받습니다. |
| **배당락일** (Ex-Dividend Date) | 이날 이후에 사면 이번 배당을 받지 못하는 날로, 이론상 배당금만큼 주가가 조정됩니다. ⚠️ **미국은 2024-05-28 결제주기가 T+1로 바뀐 이후 배당락일과 배당기준일이 같은 날**입니다(T+2 시절의 "기준일 하루 전"이 아닙니다). |
| **배당지급일** (Payment Date) | 배당금이 실제로 계좌에 들어오는 날입니다. 기준일로부터 몇 주 뒤인 경우가 많습니다. |
| **주식분할 vs 역분할** | 1주를 여러 주로 나누는 것과, 여러 주를 1주로 합치는 것입니다. **기업 가치는 전혀 변하지 않으며**, 과거 데이터는 소급조정해야 합니다(3. 표기 규칙의 "주식분할 소급조정" 참고). 역분할은 상장 유지 요건(최저 주가)을 맞추려는 목적인 경우가 많아 맥락을 확인합니다. |
| **공매도** (Short Selling) | 주식을 빌려서 먼저 판 뒤, 나중에 되사서 갚는 거래입니다. 주가가 내려야 이익이 납니다. |
| **대차잔고** | 공매도를 위해 빌려간 주식이 아직 갚아지지 않고 남아 있는 물량입니다. 많을수록 하락에 베팅한 자금이 크다는 뜻입니다. |
| **숏스퀴즈** | 주가가 오를 때 공매도 투자자들이 손실을 줄이려 앞다퉈 되사면서 **상승이 더 증폭되는** 현상입니다. 대차잔고가 클수록 잘 일어납니다. |
| **옵션** (콜 / 풋) | 정해진 가격에 **살 권리**(콜)와 **팔 권리**(풋)입니다. 개별 종목의 옵션 거래가 과열되면, 옵션을 판 쪽이 위험을 상쇄하려 기초 주식을 사고팔면서 **주식 자체의 변동성이 함께 커지기도** 합니다. |
| **시간외 거래** | 정규장이 열리지 않은 시간의 거래입니다. **실적 발표가 대개 장 마감 후에 나오므로** 주가 반응이 여기서 먼저 나타납니다. |
| **서킷브레이커** (거래 일시중단) | 지수나 개별 종목이 급격히 변동할 때 거래를 잠시 멈추는 제도입니다. 공포 매도가 연쇄적으로 번지는 것을 끊으려는 장치입니다. |
| **블록딜** | 대량 지분을 장외에서 한 번에 넘기는 거래입니다. 통상 시장가보다 **할인된 가격에 이뤄져** 단기 주가에 부담을 줍니다. |
| **실적 시즌** | 분기 실적 발표가 몰리는 기간입니다. 개별 기업 뉴스가 쏟아지면서 종목별 변동성이 커집니다. |
| **블랙아웃** | 실적 발표 직전, 회사가 투자자와의 소통을 자제하는 기간입니다. 이 기간에는 자사주매입도 통상 제한됩니다. |
| **벤치마크** | 성과를 재는 기준 지수입니다. 어떤 지수를 기준으로 잡느냐에 따라 같은 성과가 좋아 보이기도 나빠 보이기도 합니다. |
| **알파** (초과수익) | 벤치마크 수익률을 넘어선 부분입니다. 시장 전체가 올라서 번 것이 아니라 **종목 선택으로 더 번 몫**을 가리킵니다. |
| **베타** (시장민감도) | 6.3 할인율 구성요소의 베타와 같은 개념으로, 거래 관점에서는 "시장이 흔들릴 때 이 종목이 얼마나 더 흔들리는가"로 읽습니다. |
