# 주식 리서치 노트

**실제 투자 판단**을 위해 작성하고 계속 업데이트하는 개인 투자 리서치 아카이브입니다.
회사를 조사해 "이 회사에 투자할 만한가?"를 스스로 정리하고, 그 판단으로 실제 투자합니다.

커버리지는 **미국 상장 기업(NYSE/NASDAQ, USD 표시) 위주**입니다.

## 📁 둘러보기

**`sectors/` 아래에 산업/섹터별로, 그 아래에 회사별로** 문서가 정리되어 있습니다 — 왼쪽 메뉴에서 관심 있는 섹터를 골라 들어가면 됩니다.

- 회사 문서는 **개요 → 연혁 → 경영진 → 재무 원자료 → 재무 해석 → 밸류에이션 → 투자 결론 → 뉴스 로그 → 기술적 차트(일봉·주봉)** 순으로 구성됩니다.
- `meta/macro/`에는 환율·금리·채권·주가지수·금속·에너지·디지털자산 등 여러 회사에 공통으로 걸리는 거시지표 참고 차트가 있습니다.
- `meta/glossary.md`·`meta/concepts/`에서 이 사이트가 쓰는 재무·밸류에이션 용어를 찾아볼 수 있습니다.
