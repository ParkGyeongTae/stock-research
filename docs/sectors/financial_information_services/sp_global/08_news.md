# 최근 뉴스 / 이슈

> 2025년 하반기부터 정보 서비스 섹터 전체가 **AI 대체 우려와 성장 둔화 전망으로 디레이팅**되는 흐름이 이어졌고, S&P Global 주가는 그 한가운데 있었다. 회사 자체는 OSTTRA 매각·Mobility 분사로 사업 단순화를 마무리하고 자사주매입 목표를 $7B 이상으로 올리는 중이다.

::: info 이 문서의 성격
발생 순으로 쌓는 **시점성 로그**다(최신이 위). 여기서는 투자 결론을 내리지 않는다 — 판단에 영향을 주는 항목은 [밸류에이션 / 적정주가](./06_valuation.md)·[투자 판단](./07_investment.md)을 직접 갱신하고, 여기에는 반영했다는 표시만 남긴다.
:::
