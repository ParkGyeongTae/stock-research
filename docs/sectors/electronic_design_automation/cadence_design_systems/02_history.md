# 역사 / 주요 이벤트

> 1988년 합병으로 출발해 2008년 유동성 위기를 넘긴 뒤, 2021년 이후 **연속 인수로 EDA 밖 영역을 붙여 온 회사**다. 지금의 재무제표 모양(무형자산 급증, 5개년 만의 순부채 전환)은 대부분 아래 두 번의 인수 국면이 만든 것이다.

---

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| **1988.06** | SDA Systems와 ECAD의 합병으로 Cadence Design Systems 출범. 같은 해 나스닥 상장 — 이후 EDA 3사 구도의 한 축이 된다. ([회사 연혁](https://www.cadence.com/en_US/home/company.html)) |
| **2008.10~2009** | 금융위기와 매출인식 회계기준 변경이 겹쳐 **분기 대규모 손실·CEO 사임·구조조정**. Synopsys와의 격차가 이 시기에 벌어졌고, 회사는 이후 라이선스를 다년 반복매출 구조로 재편했다. ([Reuters, 2008-10-15](https://www.reuters.com/article/idUSN15448462)) |
| **2021.12** | **Anirudh Devgan 사장 → CEO 취임**(Lip-Bu Tan은 이사회 의장으로 이동). 이후 "Intelligent System Design" 전략 아래 EDA 밖 인수가 본격화된다. ([Business Wire, 2021-08-17](https://www.businesswire.com/news/home/20210817005418/en/)) |
| **2024.05 / 2025.08** | **BETA CAE 인수(약 $1.24B)**로 구조·유체 해석을 확보하고, **Arm Artisan 파운데이션 IP 사업 인수**로 IP 포트폴리오를 넓혔다. IP·SD&A가 매출의 3분의 1에 가까워진 출발점이며, 자기자본과 인수 무형자산이 이때부터 크게 늘었다. |
| **2026.02** | **Hexagon Design & Engineering 인수 완료(총 대가 $3,101.0M — 현금 $2.1B + 보통주 3.2백만 주, 취득일 공정가치 $902.2M)**. 구조해석·음향·다물체동역학을 확보해 SD&A를 확대한 대신, **FY2023~FY2025 3년 내내 순현금이던 자본구조가 2026 Q2에 순부채 +$1,210.9M으로 전환**됐다. ([10-Q 2026-06-30](https://www.sec.gov/Archives/edgar/data/813672/000081367226000092/cdns-20260630.htm) 주석 3) |
