# 역사 / 주요 이벤트

> 2012년 개인 간 비트코인 송금 서비스로 출발해 2021년 나스닥 직상장으로 "월가가 인정한 크립토 기업"이 됐고, 2022~2023년 크립토 겨울과 SEC 제소를 거친 뒤 2025년 SEC 소송 취하·S&P500 편입으로 규제·주류금융 편입이라는 두 개의 큰 벽을 동시에 넘었다.

> ⚠️ 이 문서는 **회사 관점의 사건**만 다룬다. CEO 개인의 커리어·경영 스타일은 [CEO / 경영진](./03_ceo.md)에 기록하고, 여기서는 CEO 교체가 회사에 미친 영향이 있을 때만 간단히 언급한다(Coinbase는 창업자 Brian Armstrong이 현재까지 CEO를 유지 중이라 해당 사항 없음).

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 2012.06 | Brian Armstrong(전 Airbnb 엔지니어)과 Fred Ehrsam(전 Goldman Sachs 트레이더)이 공동 창업. Y Combinator 2012년 여름 배치 프로그램 참여[^yc] |
| 2012.10 | 은행 계좌 연동을 통한 비트코인 매매 서비스 정식 출시 |
| 2013.05 | Series A $5M 유치 (Union Square Ventures 주도)[^funding] |
| 2013.12 | Series B $25M 유치 (Andreessen Horowitz, Union Square Ventures, Ribbit Capital)[^funding] |
| 2015.01 | 기관·전문 트레이더 대상 "Coinbase Exchange" 출시 및 $75M 투자 유치(DFJ, NYSE, USAA 등 참여 — 뉴욕증권거래소가 전략적 투자자로 참여한 상징적 사건)[^funding] |
| 2016.05 | Coinbase Exchange를 GDAX(Global Digital Asset Exchange)로 리브랜딩 |
| 2018.05 | GDAX를 **Coinbase Pro**로 재차 리브랜딩, 기관 대상 **Coinbase Prime** 플랫폼 출시 |
| 2018.09 | Circle·Bitmain과 공동 설립한 Centre 컨소시엄을 통해 **USDC** 스테이블코인 출시[^usdc] |
| 2019.05 | 비상장 상태에서 6:1 액면분할 실시(상장 이전이라 상장 후 주가 이력에는 영향 없음)[^split] |
| 2020.05 | "리모트 퍼스트(remote-first)" 조직 전환 선언 — 특정 도시를 본사로 규정하지 않는 정책 채택[^remote] |
| **2021.04.14** | **나스닥 직상장(direct listing).** 뉴욕증권거래소 준거가격(reference price) $250/주로 설정, 상장 첫날 종가 $328.28/주 기록 — 전통 IPO가 아닌 직상장 방식을 택한 첫 대형 크립토 기업[^listing] |
| 2022.06 | 크립토 겨울(약세장) 여파로 전체 인력의 약 18%(약 1,100명) 감원[^layoff2022] |
| 2023.01 | 추가 950명(약 20%) 감원 — 2022~2023년 누적 인력 축소[^layoff2023] |
| 2023.02 | 이더리움 L2 블록체인 **Base**(Optimism OP Stack 기반) 출시 |
| 2023 (중) | Circle이 Centre 컨소시엄 잔여 지분 50%를 주식 $210M 규모로 인수하며 컨소시엄 해산. Coinbase는 Circle의 소수 지분을 보유하는 구조로 전환하고, USDC 준비자산 이자수익을 Circle과 배분하는 계약을 체결(잔여수익의 각 50%)[^circle] |
| 2023.06 | SEC가 미등록 브로커·거래소·청산기관 운영 혐의로 Coinbase를 제소[^secsuit] |
| **2025.02.27** | **SEC가 Coinbase에 대한 민사 소송을 취하** — 벌금·사업모델 변경 조건 없이 종결. 같은 주 Consensys·Robinhood·Gemini·Uniswap·OpenSea 등에 대한 소송도 함께 취하되며 SEC의 크립토 정책 기조 전환을 상징[^secdrop] |
| 2025.05.08 | 파생상품 거래소 **Deribit**를 현금 $700M + 자사주 약 1,100만 주(총 약 $2.9B) 규모로 인수 발표 — 2025년 8월 인수 완료[^deribit] |
| 2025.05.11~15 | 외주 고객지원 업체(TaskUs) 소속 상담원 매수를 통한 내부자 유출로 고객 약 69,461명의 개인정보(주소·SSN 일부·계좌 마스킹 정보·신분증 사진)가 유출된 사실을 공표. 공격자는 $20M 갈취를 시도했으나 회사는 지불을 거부하고 대신 제보자에게 $20M 포상금을 내걸었다 — 복구비용은 $180~400M로 추산[^breach] |
| **2025.05.19** | **S&P500 지수 편입** — Capital One의 Discover Financial 인수로 발생한 공석을 대체하며, 크립토 네이티브 기업 최초로 S&P500에 편입. 편입 발표 직후 주가 하루 만에 약 24% 급등[^sp500] |
| 2025.06 | 지분관계사 Circle Internet Group이 뉴욕증권거래소(NYSE)에 상장 — 상장 첫날 주가 168% 급등[^circleipo] |
| 2026.05.05 | "AI-네이티브" 조직 전환을 명분으로 전체 인력의 약 14%(약 700명) 감원 발표. 관리 계층을 CEO 직속 5단계로 단순화하고 조직을 소규모 "AI 파운더 팀" 단위로 재편 — 2분기 중 $50~60M 규모의 구조조정 비용(대부분 현금 퇴직위로금) 반영[^layoff2026] |
