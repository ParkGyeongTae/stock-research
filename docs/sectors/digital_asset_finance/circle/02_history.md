# 역사 / 주요 이벤트

> 소비자 결제 앱으로 출발해 거래소(Poloniex) 인수·매각을 거친 뒤, USDC 발행이라는 단일 사업으로 범위를 좁혀 상장까지 온 회사다. 지금의 재무구조를 만든 것은 아래 다섯 사건이며, 그중 둘(SVB 디페그·Centre 해체)이 오늘의 매출·비용 구조를 그대로 결정했다.

---

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 2013.10 | **창업** — Jeremy Allaire와 Sean Neville이 보스턴에서 Circle Internet Financial 설립. 초기 사업은 비트코인 기반 소비자 송금·결제 앱이었고, 2015.09 뉴욕주 **BitLicense를 업계 최초로 취득**하며 "규제 순응"을 정체성으로 삼았다 — 이 노선이 이후 GENIUS Act·OCC 인가로 이어진다 |
| 2018.09 | **USDC 출시** — Coinbase와 공동 설립한 컨소시엄 Centre를 통해 달러 연동 스테이블코인 USDC를 발행. 이 시점부터 회사의 사업 정체성이 소비자 앱에서 **발행사**로 바뀌었고, Coinbase와의 유통 제휴라는 구조가 시작됐다 |
| 2023.03 | **SVB 사태 — USDC 디페그 위기** — 준비자산 중 약 33억 달러가 파산한 Silicon Valley Bank에 예치돼 있던 사실이 알려지며 USDC 가격이 1달러 아래로 이탈, 대규모 상환이 발생했다. 예금 전액 보호로 사흘 만에 페그를 회복했지만 **존폐가 걸렸던 유일한 사건**이며, 이후 준비자산을 BlackRock 운용 국채 펀드 중심으로 재편하는 계기가 됐다 |
| 2023.08 | **Centre 해체 — USDC 완전 소유권 확보** — Circle이 USDC의 발행·거버넌스 권한을 단독으로 가져오고, 그 대가로 Coinbase가 Circle 지분을 취득하며 **준비자산 이자수익을 배분받는 계약 구조**가 확정됐다. 오늘날 매출의 58.8%가 배분·거래비용으로 빠져나가는 손익 구조(개요 1. 사업 모델 — 어떻게 돈을 버는가)가 이 계약에서 나온다 |
| 2025.06 | **NYSE 상장** (2025-06-05, 공모가 $31) — 우선주가 Class A로 1:1 전환되고 Class B(1주 5표, 의결권 30% 상한)가 신설되는 자본구조 재편이 동시에 일어났다. 상장 시 RSU 유동성 조건이 충족되며 **일회성 주식보상비용이 그해에만 $566.2M** 인식돼 FY2025 GAAP 영업이익이 적자로 뒤집혔고(핵심 지표 A.1), 전환사채가 전액 상환·전환되며 이자부 차입금이 사실상 0이 됐다 |
