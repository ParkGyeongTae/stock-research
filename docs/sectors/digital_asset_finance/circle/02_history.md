# 역사 / 주요 이벤트

> 리테일 결제 앱으로 출발해 거래소 인수·매각을 거쳐 "USDC 발행사"로 사업을 좁힌 뒤, 2023년 Coinbase와의 지분관계 재편과 2025년 IPO·GENIUS Act를 계기로 규제 정합성을 핵심 경쟁력으로 내세우는 회사로 자리잡았다.

> ⚠️ 모든 항목은 웹검색으로 확인한 사실만 기록. 추측이나 출처 불명 내용은 작성 금지.
>
> ⚠️ 이 문서는 **회사 관점의 사건**만 다룬다. Jeremy Allaire 개인의 커리어는 [`03_ceo.md`](./03_ceo.md)에 별도로 기록했다.

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 2013.08 | Jeremy Allaire와 Sean Neville이 보스턴에서 Circle Internet Financial 설립. 초기에는 비트코인 기반 소비자 송금·결제 앱(Circle Pay)으로 출발 |
| 2015 | 뉴욕주 금융서비스국(NYDFS)으로부터 **최초의 BitLicense** 취득 |
| 2016 | 영국 금융감독청(FCA)으로부터 **최초의 가상통화업자 인가** 취득 |
| 2018.02 | 당시 최대 규모 암호화폐 거래소 중 하나였던 **Poloniex를 약 4억 달러에 인수** — 소비자 결제에서 거래소 사업으로 확장 시도 |
| 2018.09 | Coinbase와 함께 **CENTRE Consortium**을 결성하고 달러 연동 스테이블코인 **USDC 출시** |
| 2019.10 | Poloniex를 인수 약 18개월 만에 **약 1.56억 달러 손실을 보고 매각** — 거래소 사업에서 철수하고 USDC·스테이블코인 인프라 사업에 집중하는 전략적 전환점 |
| 2019 (하반기) | 공동창업자 Sean Neville이 공동CEO직에서 물러남(이사회에는 잔류) — 이후 Jeremy Allaire 단독 CEO 체제로 전환 |
| 2021.07 | SPAC(기업인수목적회사) **Concord Acquisition Corp와의 합병을 통한 상장 계획 발표**(기업가치 약 45억 달러 평가) |
| 2022 | 시장·규제 환경 변화를 이유로 **SPAC 합병 무산** |
| 2023.08 | Circle과 Coinbase가 **CENTRE Consortium 해산**에 합의. Circle이 USDC 거버넌스·스마트컨트랙트 키 관리를 전담하는 대신, Coinbase는 Circle의 소수 지분을 취득하고 플랫폼별 USDC 보유 잔고 비중에 따라 준비자산 이자수익을 배분받는 계약 체결(현재까지 이어지는 배분비용 구조의 시작점). 동시에 USDC 지원 블록체인이 6개 추가되어 총 15개로 확대 |
| 2025.01 | Heath Tarbert(전 CFTC 위원장, 전 Citadel Securities 최고법률책임자)가 **President(사장)로 합류** |
| 2025.04 | 나스닥이 아닌 **NYSE 상장을 위한 Form S-1 제출** |
| 2025.06.05 | **NYSE 상장(IPO)** — 공모가 주당 $31, 3,400만 주 발행(총 조달액 11억 달러 이상). 첫날 종가 $83.23(공모가 대비 +168%) |
| 2025.06.23 | 상장 후 첫 랠리에서 **주가 사상 최고가 $298.99** 기록 |
| 2025.06.30 | 미국 통화감독청(OCC)에 **신탁은행 설립(National Trust Charter) 신청** |
| 2025.07.18 | 미국 최초의 연방 스테이블코인 규제법 **GENIUS Act 발효**(트럼프 대통령 서명) — Circle 등 주요 암호화폐 기업 CEO들이 서명식에 참석 |
| 2025.12 | OCC로부터 신탁은행 설립 **조건부 승인** 획득 |
| 2026.01 | 경쟁사 Tether가 미국 연방 규제를 받는 스테이블코인 **USAT 출시** — 미국 기관 시장에서 USDC와의 직접 경쟁 재개 |
| 2026.06.30 | Stripe·Visa·Mastercard·Google·BlackRock·Coinbase 등 140여개 기업이 참여하는 경쟁 스테이블코인 컨소시엄 **Open USD(OUSD) 출범 발표**(Circle·Tether는 불참). 같은 시기 FTSE Russell 성장주 지수에서 Circle이 제외되며 지수 추종 자금의 기계적 매도가 겹쳐 **주가가 사상 최고가 대비 약 70% 급락** |
| 2026.07.10 | OCC로부터 **신탁은행 설립 최종 승인** 획득 — 설립 법인명 First National Digital Currency Bank, N.A.(사업명 Circle National Trust). 예수금 수신·대출은 불가하며 고객자산 커스터디·향후 준비자산 관리 기능이 목적 |
| 2026.08.05 | 2026년 2분기 실적 발표 — Arc 토큰 프리세일(2.42억 달러)을 반영해 연간 Other Revenue 가이던스를 기존 대비 2배 이상인 3.10~3.30억 달러로 상향, 자체 레이어1 블록체인 **Arc의 퍼블릭 메인넷을 2026-09-16 출시 예정**이라 발표하며 BlackRock·DTCC·Mastercard·Visa 등을 창립 검증인(founding validator)으로 공개 |
