# 최근 뉴스 / 이슈

> 2026년 6월 경쟁 컨소시엄(OUSD) 출범으로 급락한 뒤, OCC 신탁은행 최종 인가 → IBM 특허 인수 → Arc 메인넷 일정 확정으로 이어지는 신사업 모멘텀에 기대어 7월 말부터 약 45% 반등한 흐름이다. 본업(준비자산 이자수익)이 아니라 **신사업 기대가 주가를 움직이고 있다**는 점이 이 로그의 공통점이다.

::: info 이 문서의 성격
발생 순으로 쌓는 **시점성 로그**다(최신이 위). 여기서는 투자 결론을 내리지 않는다 — 판단에 영향을 주는 항목은 [밸류에이션 / 적정주가](./06_valuation.md)·[투자 판단](./07_investment.md)을 직접 갱신하고, 여기에는 반영했다는 표시만 남긴다.

:::
