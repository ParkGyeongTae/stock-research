# 역사 / 주요 이벤트

> 방화벽 하드웨어 단일 제품 스타트업에서, 17건 이상의 인수합병을 통해 클라우드 보안·SOC·(2026년부터) 아이덴티티 보안까지 아우르는 플랫폼 기업으로 확장해온 20년.

> ⚠️ 항목별 출처는 하단 "참고 자료" 참고. 인수 금액은 발표 시점 기준(딜 종결 시 조정될 수 있음).

---

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 2005 | Nir Zuk(전 Check Point·NetScreen, 최초의 스테이트풀 인스펙션 방화벽·최초의 침입방지시스템 개발자)가 창업 |
| 2007 | 첫 차세대 방화벽(NGFW) 제품 출하 |
| 2011 | Gartner Magic Quadrant "네트워크 방화벽" 부문 리더로 처음 선정(이후 다년 연속 유지) |
| **2012.07** | **NYSE 상장(IPO)** — $260M 조달, 2012년 4번째로 큰 테크 IPO |
| 2014 | Fortinet·McAfee·NortonLifeLock와 함께 위협 인텔리전스 공유 비영리 조직 Cyber Threat Alliance 공동 설립 |
| **2018.03** | Evident.io 인수($300M) — 클라우드 보안 태세 관리(CSPM), 이후 Prisma Cloud의 핵심 축 |
| **2018.06** | **Mark McLaughlin → Nikesh Arora로 CEO 교체**(회사에 미친 영향은 아래 요약, 개인 이력은 [`03_ceo.md`](./03_ceo.md)) |
| 2018.10 | RedLock 인수($173M) — 클라우드 위협 탐지·컴플라이언스 |
| 2019.02 | Demisto 인수($560M) — SOAR, 이후 Cortex XSOAR의 핵심 축 |
| 2019.05 | Twistlock 인수($410M) — 컨테이너 보안, Prisma Cloud 확장 |
| 2020 | CloudGenix 인수($420M) — SD-WAN, SASE(Prisma SASE) 구성 요소 |
| 2020.11 | Expanse 인수 발표($800M) — 공격표면관리(ASM) |
| 2021.10 | 상장 시장을 NYSE에서 **Nasdaq으로 이전** |
| 2022.09 | **3:1 주식분할** |
| 2022.11 | Cider Security 인수($300M) — 소프트웨어 공급망 보안 |
| 2023.11 | Talon Cyber Security 인수($625M) — 엔터프라이즈 브라우저 보안 |
| **2024.12.16** | **2:1 주식분할** — 이 저장소의 모든 과거 주가·EPS·BPS는 이 분할을 소급 반영([`04_metrics.md`](./04_metrics.md) 참고) |
| 2025.08 | **CyberArk(아이덴티티 보안, PAM 시장 1위) 인수 계약 발표** — 총 대가 약 $25B(현금+주식) |
| **2026.02.11** | **CyberArk·Chronosphere 인수 종결** — 현금 $2.3B + 신주 약 112M주 발행. 창사 이래 최대 규모 M&A로, 네트워크·클라우드·SOC에 이어 아이덴티티 보안까지 플랫폼을 확장([`08_news.md`](./08_news.md) 상세) |

2018년 이후 누계로는 약 17건, 총 $5.5B 이상을 M&A에 투입해 Prisma(클라우드 보안)·Cortex(SOC) 제품군을 사실상 인수를 통해 조립해왔다 — CyberArk 인수는 이 전략의 연장선이자 지금까지 중 압도적으로 큰 베팅이다.
