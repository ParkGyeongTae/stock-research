# 최근 뉴스 / 이슈

> 2026년의 뉴스 흐름은 셋으로 갈린다 — **①매출·회비 지표의 지속적 가속**(FY2026 연간 +10.2%로 마감), **②관세를 둘러싼 법적 대응과 가격 정책**, **③9월 24일로 예정된 FY2026 4분기 실적발표**. 실적 악재성 뉴스는 이 기간에 없었다.

::: info 이 문서의 성격
발생 순으로 쌓는 **시점성 로그**다(최신이 위). 여기서는 투자 결론을 내리지 않는다 — 판단에 영향을 주는 항목은 [밸류에이션 / 적정주가](./06_valuation.md)·[투자 판단](./07_investment.md)을 직접 갱신하고, 여기에는 반영했다는 표시만 남긴다.

:::
