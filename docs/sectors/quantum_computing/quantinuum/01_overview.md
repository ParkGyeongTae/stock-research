## 1. 한 줄 요약

Quantinuum은 Honeywell이 20년 가까이 사내에서 키운 트랩드 이온 하드웨어 조직(Honeywell Quantum Solutions)과 영국의 양자 소프트웨어 기업 Cambridge Quantum이 2021년 합병해 만들어졌다. QCCD(quantum charge-coupled device) 아키텍처를 기반으로 **논리 큐비트 정확도(logical fidelity)에서 업계 최상위권**을 주장하며, 2030년 완전 결함허용 양자컴퓨팅 달성을 목표로 Helios(현재) → Sol(2027) → Apollo(2029) 로드맵을 제시하고 있다. 2026-06-04 주당 $60에 Class A 2,800만 주를 공모해 $1.68B을 조달하며 Nasdaq에 상장했으나, 상장 3개월 만에 주가는 $48.00으로 공모가 대비 -20%다.

## 3. 산업 / 시장 내 위치

Quantinuum은 **트랩드 이온** 방식으로, 같은 방식의 [IonQ](../ionq/01_overview.md)와 직접 경쟁한다. 두 회사는 큐비트 정확도에서 서로 업계 최상위를 주장해왔고, 실제로 IonQ 문서에서도 Quantinuum은 오랫동안 "비상장 최대 경쟁자"로 기록돼 왔다 — 2026-06 상장으로 이제 두 회사를 같은 잣대로 비교할 수 있게 됐다.

매출 규모로는 IonQ가 크게 앞선다. FY2025 기준 IonQ $130.0M vs Quantinuum $30.9M이고, FY2026 가이던스는 IonQ $280~290M vs Quantinuum $28~32M으로 격차가 **10배 가까이 벌어진다.** 다만 이 격차의 상당 부분은 IonQ가 연쇄 M&A로 네트워킹·보안·센싱·파운드리 매출을 편입한 결과이고, 순수 양자컴퓨팅 매출만 비교하면 차이가 더 작을 수 있다(두 회사 모두 세그먼트 매출을 공시하지 않아 확인 불가).

기술 로드맵에서는 Quantinuum이 더 구체적이다. QCCD 아키텍처 위에 Helios(현재, 98큐비트 — Oracle Cloud Infrastructure 배치) → Sol(2027, 트랩 칩 제작 완료·검증 중) → Apollo(2029, 물리 큐비트 수천 개·논리 큐비트 수백 개)로 이어지는 일정과 **2030년 완전 결함허용 달성** 목표를 제시했고, Helios에서 "near five-nines" 논리 정확도를 시연했다고 밝혔다. [D-Wave](../d_wave_quantum/01_overview.md)가 어닐링 상용 매출을 내는 대신 게이트 모델에서 후발인 것과 대비하면, Quantinuum은 **범용 게이트 모델의 기술 선두를 주장하되 상용 매출은 아직 작은** 포지션이다.

가장 특이한 구조적 요소는 **지배구조**다. Honeywell과 Cambridge Quantum Holdings가 상장 후에도 지분의 약 82%를 보유하고, Honeywell 단독으로 의결권의 약 49.1%를 쥔다. Class A(공모 유통분)와 Class B(창업 주주)로 나뉜 Up-C 구조라 재무제표 해석이 다른 회사와 크게 다르다 — 자세한 함정은 [핵심 지표](./04_metrics.md) 상단 경고를 반드시 먼저 읽을 것.
