# 역사 / 주요 이벤트

> 1999년 창업 → 2011년 세계 최초 상용 양자컴퓨터 판매 → 2022년 SPAC 상장 → 2026년 게이트 모델 인수와 미 정부 지분 투자. 20년 넘게 어닐링 단일 노선을 지켜오다 2026년 처음으로 두 번째 기술 축을 샀고, 같은 해 미국 정부를 주주로 받았다.

::: warning 읽기 전 주의
모든 항목은 웹검색으로 확인한 사실만 기록. 인수 관련 금액·날짜는 발표일과 종결일이 다른 경우가 많아 구분해서 표기했다.

이 문서는 **회사 관점의 사건**만 다룬다. CEO 개인의 커리어는 [CEO / 경영진](./03_ceo.md) 참고.
