# 역사 / 주요 이벤트

> 1999년 창업 → 2011년 세계 최초 상용 양자컴퓨터 판매 → 2022년 SPAC 상장 → 2026년 게이트 모델 인수. 20년 넘게 어닐링 단일 노선을 지켜오다 2026년 처음으로 두 번째 기술 축을 샀다.

## 연혁

| 연도 | 내용 |
|------|------|
| 1999 | 캐나다 브리티시컬럼비아에서 D-Wave Systems 창업 — 양자 어닐링 상용화를 목표로 출발 |
| 2011 | **세계 최초의 상용 양자컴퓨터 D-Wave One(128큐비트) 판매** — Lockheed Martin이 첫 고객 |

| **2020-01** | **Alan Baratz가 D-Wave Systems CEO 취임** (그 전까지 사내에서 소프트웨어·애플리케이션·R&D를 이끌던 인물) |
| 2022-02-08 | DPCM Capital(SPAC)과의 합병 발표 — 합병 후 기업가치 약 $1.6B로 제시 |
| **2022-08** | **NYSE 상장(티커: QBTS)** — SPAC 합병 종결로 D-Wave Quantum Inc. 출범 |
| 2023 | 매출 $8.8M에 그치고 자기자본이 **마이너스(-$24M)**로 떨어짐 — 상장 이후 가장 어려운 국면([핵심 지표](./04_metrics.md) A.3) |
| 2025-03 | Advantage2 시스템 일반 공급 개시 |
| 2025 Q1 | **독일 Jülich 슈퍼컴퓨팅센터에 Advantage2 시스템 판매** — 분기 매출 $15.0M(전년 동기 $2.5M)으로 회사 역사상 최대 분기 매출 기록 |
| 2025 | 대규모 자본조달로 연말 현금·유가증권 $884.5M 확보(전년 $178.0M 대비 +397%) |
| **2026-01-06** | **Quantum Circuits Inc. 인수 합의 발표** — 총 대가 약 $550M(주식 $300M + 현금 $250M). Yale 스핀오프, 오류정정 초전도 게이트 모델 |
| 2026-01-20 | Quantum Circuits 인수 종결 — 어닐링·게이트 두 축 체제로 전환 |
| 2026-06-01 | NYSE에서 인베스터 데이 개최 |
| 2026-06-04 | 2026년 정기주총 — Alan Baratz·Sharon Holt 이사 재선임. 주총 후 **Sharon Holt가 이사회 의장 선임**(CEO-의장 분리 구조 유지) |
| 2026-08-06 | 2026 Q2 실적 발표 — 매출 $3.1M(전년과 동일 수준), 상반기 수주 $35.5M(YoY +1,120%), RPO $40.7M(+668%) |
