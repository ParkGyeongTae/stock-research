- **직책**: President and Chief Executive Officer, 이사 겸임
- **취임일**: 2021-01-01 (재임 6년째)
- **출생년도 / 국적**: 1967년 / 독일
- **학력**: 경영학 학사(독일) 및 MBA — 상세 학교는 **확인 필요**
- **전임 CEO**: Ajay Banga (2010~2020). 교체는 실적 문제가 아닌 **계획된 승계**였고, 방가는 이후 이사회 의장을 거쳐 2023년 세계은행 총재로 자리를 옮겼다

## 2. 경영 스타일 / 전략 방향

미바흐 체제의 자본배분은 **"카드 거래 건당 수수료 밖에서 매출을 만든다"**는 한 문장으로 정리된다. 재임 중 집행한 세 건의 인수가 그 방향을 그대로 보여준다 — **Recorded Future($26.5억, 2024-12)**로 위협 인텔리전스를, **BVNK($18억, 2026-08)**로 스테이블코인 정산 인프라를 사들였고, 그 이전 Vocalink(2017)가 계좌 간 이체 기반을 마련했다. 세 건 모두 **결제망을 위협하는 영역을 사서 안으로 들이는** 성격이라는 공통점이 있다.

성과는 매출 구성에 드러난다. 부가서비스 비중이 FY2023 36.9% → FY2025 **40.6%**로 올랐고 성장률은 결제망(+12%)의 두 배(+23%)다. **동종사 [Visa](../visa/03_ceo.md)와 전략의 방향은 같지만 수단이 다르다** — Visa는 자체 망 위에 파트너를 얹어 스테이블코인 정산 $200억 런레이트를 만든 반면, Mastercard는 $18억을 들여 인프라를 소유했다. 자본 투입은 크지만 통제력은 높은 선택이며, **어느 쪽이 유리했는지는 아직 판정할 수 없다.**

주주환원은 공격적이다. 연 $9~12B 자사주매입으로 희석주식수를 매년 2.0~2.6% 줄이고 있고, FY2026에는 상반기에만 $8.9B을 집행해 연간 $15B(E) 수준이 예상된다([핵심 지표](./04_metrics.md) A.4). 그 결과 **자기자본이 $5,611M까지 줄어 ROE·PBR·부채비율이 정상 해석되지 않는 상태**가 됐다 — 재무위험은 아니지만(이자보상배율 26배) 환원 여력이 차입에 의존하는 국면으로 넘어가고 있다(순부채 $8,434M → $13,352M).

## 3. 성과 / 논란 / 시장 평가

- **성과**: 취임일(2021-01-01) 부근 주가 $350 수준에서 2026-09-15 $573.27로 약 **+64%**다(배당 제외). 재임 기간 실적은 순매출이 FY2023 $25.1B → TTM $35.1B으로 40% 늘었고 **조정 EPS는 $12.26 → $18.78로 53% 늘었다**([핵심 지표](./04_metrics.md) A.1). 영업이익률도 55.8% → 최근 분기 **60.2%**로 개선됐다. 다만 이 성과의 상당 부분은 팬데믹 이후 국경간 거래 회복이라는 순풍과 겹쳐 있어 개인 기여분을 분리하기 어렵다.
- **논란 / 리스크**: 개인 관련 소송·스캔들은 확인되지 않는다. 회사 차원의 쟁점은 **미국 인터체인지 집단소송 $38B 합의**(2026-06 예비승인, 항소 예고)와 **국경간 성장률의 3년 연속 둔화**(+24% → +12%)다. 후자는 가장 마진 높은 매출원의 감속이라 [투자 판단](./07_investment.md)에서 별도로 다룬다.
- **시장 평가**: CEO 개인에 대한 부정적 평가는 확인된 출처에서 찾지 못했다. 다만 **2024년 말 회사가 3개년 가이던스를 하향**(순매출 CAGR을 high-teens → low-double-digit, EPS 성장을 low-20s → mid-teens)한 바 있어, 성장 기대 자체가 한 단계 낮아진 상태에서 재임 중이라는 점은 감안해야 한다.

## 4. 보상 · 지분 구조

| 항목 | 값 | 기준 |
|------|-----|------|
| 총보상 (Total Compensation) | **확인 필요**[^p1] | 2026 위임장(DEF 14A, 2026-04-27 제출) 요약보상표에 FY2025 값이 있으나 이번 조사에서 본문 확보에 실패했다. 언론 집계 기준 최근 연도 총보상은 **약 $30M 수준**으로 보도됐다 |
| CEO 개인 지분율 (%) | 1% 미만 | 위임장 수익적 소유 표 |
| 내부자(임원·이사) 지분율 (%) | 1% 미만 | |
| 기관 투자자 지분율 (%) | 약 75~80% (Class A 기준) | 뱅가드·블랙록 등 패시브 운용사 중심 |
| 주요 대주주 (5% 이상 보유) | Vanguard, BlackRock | 전략적 대주주가 아니라 패시브 운용사다. 다만 아래 재단 지분 참고 |
| 차등의결권 구조 (dual-class) | **있음 — Class A(공개) / Class B(비상장)** | Class B는 **거래소에 상장되지 않으며** 이사 선임 의결권이 제한된다. 발행주식 894백만 주 중 Class B는 약 7백만 주로 **1% 미만**이라 실질 영향은 미미하다 |

> **차등의결권이 있지만 실질적으로는 단일 클래스에 가깝다.** Class B는 전체 주식의 1% 미만이고 과거 회원은행 보유분의 잔재다 — **동종사 [Visa](../visa/03_ceo.md)가 Class A/B-1/B-2/B-3/C + 우선주의 다섯 종류를 두고 시가총액·EPS 계산 기준이 갈리는 것과 대조된다.** 그래서 Mastercard의 주당 지표는 별도 환산 없이 읽을 수 있고, **두 회사의 PER을 비교할 때 기준을 맞춰야 하는 쪽은 Visa다.**
>
> 한편 **지배구조상 특기할 점은 Mastercard Foundation**이다. 2006년 상장 당시 설립돼 Class A 지분을 상당 규모 보유해온 자선재단으로, 의결권은 제한적으로 행사하되 장기 보유자로 남아 있다 — 정확한 현재 지분율은 **확인 필요**.

[^p1]: 이 저장소는 확인하지 못한 수치를 확정치처럼 적지 않는다. 언론 집계치는 연도 기준이 엇갈려(2024년분과 2025년분이 혼재) 그대로 인용하지 않았다.
