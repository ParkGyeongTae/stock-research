# CEO / 경영진

> McKinsey·JPMorgan Chase 소비자금융 CEO를 거쳐 2013년부터 10년간 Visa President로 재직한 뒤 2023년 CEO에 오른 내부 승진 케이스 — 급격한 전략 전환보다 기존 확장 전략(가치사슬 확장·신흥 레일 대응)의 연속성이 강점이자, 새로운 방향성 제시가 부족하다는 평가를 동시에 받는다.

> ⚠️ 모든 항목은 웹검색으로 확인한 사실만 기록. 출처는 각 절에 표기.

- **이름**: Ryan McInerney
- **직책**: Chief Executive Officer (Chairman은 겸임하지 않음 — Al Kelly가 Executive Chairman으로 재직 중)
- **취임일**: 2023-02-01 (2026-08 기준 재임 약 3년 6개월)
- **출생년도 / 국적**: 공개된 출생연도 확인 안 됨(1997년 대학 졸업 기준 1970년대 중반 출생 추정) / 미국 국적으로 추정, 확인 필요
- **학력**: University of Notre Dame 재무학 학사(1997년 졸업)
- **전임 CEO**: Alfred F. Kelly, Jr.(2016~2023 CEO, 이후 Executive Chairman으로 전환 — 은퇴가 아니라 이사회 의장직 유지)

## 2. 경영 스타일 / 전략 방향

10년간 President로서 이미 Visa의 사업 전반(발급·매입·가치부가서비스)에 깊이 관여했던 인물이라, CEO 취임 후에도 급격한 전략 전환보다는 **기존 확장 노선의 가속**에 가깝다는 평가가 많다. 취임 후 실적발표 코멘터리에서 일관되게 강조하는 축은:

- **"Visa as a Service" — 카드 레일을 넘어선 인프라 사업자로의 확장**: Visa Direct(실시간 자금이동), Cybersource(가맹점 결제 게이트웨이), 최근에는 스테이블코인 정산·AI 에이전트 커머스(Trusted Agent Protocol)까지, 카드 네트워크의 핵심 자산(발급사·가맹점 접점, 리스크 관리 노하우)을 다른 결제 레일에도 파는 방향.
- **신흥 위협을 흡수하는 전략**: 실시간 계좌이체(A2A)·스테이블코인처럼 카드 네트워크를 우회할 수 있는 기술을, 경쟁자로 두기보다 Visa 인프라 위에 얹어 수수료를 받는 모델로 편입시키려는 시도(예: USDC 정산 지원, Visa Direct 스테이블코인 페이아웃).
- **가치부가서비스(Value-Added Services) 비중 확대**: Data processing·Other revenue의 고성장([핵심 지표](./04_metrics.md) A.1)이 이 전략의 실적 반영으로 해석된다.

## 3. 주요 성과 / 논란

- **성과**: 재임 기간(FY2023 Q2~현재) 매출은 FY2023 $326억 → FY2025 $400억으로 성장했고, 주가는 취임 시점(2023-02, 대략 $220대) 대비 2026-08 현재 $364.15로 상승. 다만 이 기간 상승이 CEO 개인의 전략 전환 효과인지, 업계 전반의 구조적 성장(카드 전환 지속)에 따른 것인지는 명확히 분리하기 어렵다.
- **논란 / 리스크**: 재임 중 Interchange MDL 소송의 화해금 재계상이 FY2025 실적(영업이익률 급락)에 직접 타격을 줬다([핵심 지표](./04_metrics.md) A.1, [최근 뉴스 / 이슈](./08_news.md) 참고) — CEO 개인 스캔들은 확인된 바 없으나, Visa 자체가 오랫동안 반독점·수수료 관련 소송에 노출되어 있다는 구조적 리스크는 재임 기간 내내 이어지고 있다.

## 5. 시장 / 투자자 평가

McInerney 취임 이후 시장은 대체로 "안정적 연속성"으로 평가하는 편이다 — Visa 주가가 재임 기간 동안 견조하게 상승했고([기술적 분석 — 일봉·1년](./09_technical_daily.md) 참고), 애널리스트 컨센서스도 우호적(평균 목표주가가 현재가 상회, [밸류에이션 / 적정주가](./06_valuation.md) 참고)이다. 다만 10년간 President로서 이미 회사 전략에 깊이 관여했던 인물이라 "새로운 비전 제시자"라기보다 "기존 전략의 관리자"에 가깝다는 평가가 나오며, 스테이블코인·AI 에이전트 커머스 같은 신사업이 실제 매출에 기여하는 시점·규모는 아직 검증 초기 단계다.

## 6. 지분 구조 / 거버넌스

> ⚠️ Visa는 일반적인 "창업자 초과의결권" 형태의 차등의결권 구조가 **아니다**. 4개 보통주 클래스(A/B-1/B-2/B-3/C, 세부적으로는 Class A·B계열·C 3종)는 2007년 지주회사 재편과 2016년 Visa Europe 인수 과정에서 **소송 손실 흡수(loss-absorbing)** 목적으로 설계된 Visa 고유의 구조다 — 일반적인 "창업자 대 일반주주" 구도의 거버넌스 리스크와는 성격이 다르다.

| 항목 | 값 | 기준일 |
|------|-----|--------|
| 기관 투자자 지분율 (%) | 약 75~78%(출처마다 74.8%~91.7%까지 편차, 집계 방법론 차이로 추정 — 범위로 기록) | 2026-08 시점 집계 |
| 내부자(임원·이사) 지분율 (%) (4. 보상 / 지분의 CEO 개인 지분 포함 합계) | 1% 미만(약 0.08%로 보고하는 출처도 있음) | 2026-08 시점 집계 |
| 주요 대주주 (5% 이상 보유) | Vanguard Group(약 8.3%), BlackRock(약 7.1%), State Street(약 4.3%, 개별로는 5% 미만이나 3사 합산 상위) | 2026-08 시점 집계(3자 집계 사이트, 1차 공시인 13F 직접 대조는 하지 않음 — 확인 필요) |
| 차등의결권 구조 (dual-class) | 있음(단, 창업자형 아님) — **Class A**: 1주 1표 일반 의결권, 뉴욕증권거래소 상장. **Class B-1/B-2/B-3**: 원칙적으로 무의결권(핵심 결제사업 매각 등 특정 사안에서만 Class A와 함께 투표), 회원은행(주로 미국 은행) 보유, 시장 매도 시 자동으로 Class A 전환. **Class C**: 무의결권, 비상장, 최근 발행분 기준 Class A 전환비율 4.0배 | 2026-08 기준(Visa Investor Relations "Class B/C Stock Info") |

> Class B/C 주식이 존재하는 이유: 2007년 지주회사 재편 당시, 상장 이전 회원은행들의 반독점(interchange) 소송 리스크를 일반 Class A 주주(신규 투자자)에게 전가하지 않기 위해 회원은행 지분을 Class B/C로 분리하고, 소송 화해금이 발생하면 이 클래스들의 Class A 전환비율을 낮춰(사실상 가치를 깎아) 손실을 흡수하도록 설계했다. 2016년 Visa Europe 인수 때도 같은 논리로 우선주(Series B/C preferred)를 발행했다([역사 / 주요 이벤트](./02_history.md) 참고). **일반 투자자가 보유하는 Class A 주식의 의결권·경제적 가치에는 영향이 없다**는 점에서 창업자형 차등의결권과는 리스크 성격이 다르지만, 소송 진행 상황에 따라 전환비율·충당금이 변동해 실적 변동성의 한 원인이 된다([핵심 지표](./04_metrics.md) A.1 각주, [최근 뉴스 / 이슈](./08_news.md) 참고)는 점은 계속 추적할 가치가 있다.
