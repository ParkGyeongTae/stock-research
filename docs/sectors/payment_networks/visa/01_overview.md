# Visa (V)

> 전 세계 카드 결제의 절반 이상이 지나가는 결제망(VisaNet)을 운영하며, 자기 돈을 빌려주지 않고 **거래가 지나갈 때마다 수수료만 받는** 구조로 순매출 대비 FCF 마진 47%를 내는 회사다. 성장은 여전히 두 자릿수지만, 인터체인지 소송 화해 이행과 고객 인센티브(리베이트) 부담 확대가 그 수익성을 갉아먹는지 지켜봐야 한다.

- **회사명**: Visa Inc.
- **티커 / 상장 시장**: V / NYSE
- **설립 / 본사**: 1958년 BankAmericard로 출발, 2007년 Visa Inc.로 통합 설립 / 미국 캘리포니아주 샌프란시스코
- **CEO**: Ryan McInerney (2023년 2월 취임)
- **홈페이지**: <https://www.visa.com>
- **섹터 / 산업**: 금융 인프라 / 결제 네트워크(payment networks)
- **시가총액**: 약 **$712.9B** (2026-09-15 종가 $375.62 × 희석 Class A 환산 주식수 18.98억 주 기준)[^mktcap]
- **회계연도(FY) 마감월**: **9월 30일** (FY2026 = 2025.10~2026.09) — 다른 문서는 이 값을 인용만 한다

[^mktcap]: Visa는 Class A(공개) 외에 Class B-1/B-2/B-3(미국 금융기관)·Class C(미국 외 금융기관)·우선주가 있어, 시가총액은 회사가 EPS 산정에 쓰는 **희석 Class A 환산 주식수**(FY2026 Q3 가중평균 18.98억 주)에 종가를 곱해 근사했다. Class A 발행주식수만 곱하는 집계 사이트는 약 $686B으로 제시하므로([stockanalysis](https://stockanalysis.com/stocks/v/statistics/), 2026-09-16) 어느 기준인지 밝히지 않으면 값이 갈린다.

::: info FY2026은 2026-09-30 종료 예정이다
이 문서를 쓴 시점(2026-09-16)에 Visa의 FY2026은 **아직 진행 중이며 Q3(2026-06-30)까지 공시**됐다. 그래서 [핵심 지표](./04_metrics.md)의 "올해" 열은 추정치가 아니라 **최근 12개월 실적(TTM, 2025.07~2026.06)**이고, [밸류에이션](./06_valuation.md)의 FY2026 EPS만 컨센서스 기반 추정치(E)다. FY2026 확정 실적은 **2026년 10월 발표** 예정이다.

## 1. 사업 모델 — 어떻게 돈을 버는가

Visa는 카드를 발급하지도, 여신을 제공하지도 않는다(신용위험은 발급 은행이 진다). 대신 **발급사 ↔ 매입사 ↔ 가맹점을 잇는 네트워크 사용료**를 받는다. 매출은 네 갈래로 잡히고, 여기서 은행·대형 가맹점에 되돌려주는 **고객 인센티브(client incentives)를 차감한 것이 순매출(net revenue)**이다 — 이 차감 항목이 총매출의 28%에 달해 사실상의 실효 할인율로 작동한다([핵심 지표](./04_metrics.md) C절).

| 사업 부문 | 설명 | 매출 비중 | 기준 시점 |
|-----------|------|-----------|-----------|
| Data processing revenue | VisaNet이 승인·정산·결제를 처리한 **건당** 과금 | 35.9% | FY2025 (총매출 기준) |
| Service revenue | 발급사가 Visa 브랜드·네트워크를 쓰는 대가. **전분기 결제금액**을 기준으로 인식 | 31.5% | FY2025 |
| International transaction revenue | 발급국과 가맹점 소재국이 다른 거래의 환전·해외거래 수수료. 마진이 가장 높다 | 25.4% | FY2025 |
| Other revenue | 컨설팅·데이터 분석·마케팅 등 부가서비스(value-added services) 및 라이선스 | 7.3% | FY2025 |
| (차감) Client incentives | 발급사·매입사·대형 가맹점에 지급하는 리베이트 | **−28.3%** | FY2025 |
| **합계 = 순매출 $40.0B** | | 100% (순매출 기준) | FY2025 |

출처: [FY2025 10-K](https://www.sec.gov/Archives/edgar/data/1403161/000140316125000089/v-20250930.htm) MD&A — Service $17,539M / Data processing $19,993M / International transaction $14,166M / Other $4,053M / Client incentives $(15,751)M, 총매출 $55,751M.

- **지역 구성**: 순매출의 **미국 39% · 해외 61%**(FY2025). 미국 비중은 FY2023 43% → FY2024 41% → FY2025 39%로 계속 낮아지는 중이며, 해외 순매출 증가율(+15%)이 미국(+6%)의 두 배를 넘는다.
- **부가서비스**: FY2025 value-added services 매출 **$10.9B**(+24% YoY, FY2024 $8.8B·FY2023 $7.2B). 결제 건수 성장과 별개의 성장 축이며 Other revenue와 Data processing revenue에 나뉘어 계상된다. 동종사 [Mastercard](../mastercard/01_overview.md)는 같은 성격의 사업이 매출의 40.6%를 차지하며 별도 부문으로 공시하는데, **Visa는 부문으로 분리하지 않아 비중을 직접 비교할 수 없다.**
- **새 축 — 스테이블코인**: 2026-09-08 회사 발표로 **스테이블코인 정산이 연환산 $200억 런레이트를 넘어섰고**(전년 대비 15배 이상), 160개 넘는 스테이블코인 연동 카드 프로그램이 Visa 망에서 운영되며 그 프로그램들의 결제금액은 전년 대비 약 200% 늘었다. 순매출 $44B 규모에 비하면 여전히 작지만, **1년 전의 "옵션가치"에서 측정 가능한 사업으로 넘어가는 중**이다([최근 뉴스 / 이슈](./08_news.md) 참고).

## 2. 산업 / 시장 내 위치

카드 결제망은 사실상 **Visa·Mastercard 복점**이고, Visa가 그중 큰 쪽이다. Nilson Report(2025-06, 2024 캘린더 기준) 집계로 Visa의 총결제금액은 $13.4조로 Mastercard($8.0조)의 1.7배, American Express($1.75조)의 7.7배다. 발급 카드 수도 Visa 48.1억 장 vs Mastercard 31.5억 장이다.[^nilson]

[^nilson]: [FY2025 10-K](https://www.sec.gov/Archives/edgar/data/1403161/000140316125000089/v-20250930.htm) Item 1의 경쟁사 비교표(원자료: The Nilson Report issue 1288, 2025-06). Visa/Mastercard는 소비자·소상공인·법인 신용·직불·선불 전체, Amex·Discover·JCB는 신용카드 기준이라 정의가 완전히 같지는 않다.

**복점 안에서의 상대 위치는 규모와 성장률이 갈린다.** Visa가 결제금액에서 1.7배 크지만, FY2025 순매출 증가율은 Visa +11.3% vs [Mastercard](../mastercard/01_overview.md) +16.4%로 **2위 사업자가 더 빨리 크고 있다.** 이 차이의 상당 부분은 Mastercard의 부가서비스 비중(40.6%)이 Visa보다 높고 그 부문이 +23%로 크기 때문이다 — 즉 두 회사의 성장률 격차는 결제망 점유율 다툼이 아니라 **매출 믹스 차이**에서 나온다.

- **해자의 성격**: 발급사가 많을수록 가맹점이 받고, 가맹점이 많을수록 소비자가 쓰는 **양면 네트워크 효과**다. 신규 진입자가 같은 규모의 수용처를 확보하는 데 드는 비용이 진입장벽 그 자체다(자세한 것은 [투자 판단](./07_investment.md) 2. 경쟁 해자).
- **경쟁의 실제 축**은 서로가 아니라 **카드망을 우회하는 경로**다. 브라질 Pix·인도 UPI 같은 국가 주도 실시간 계좌이체(A2A), 스테이블코인·온체인 결제, 그리고 미국 인터체인지 소송 화해에 따른 라우팅 확대가 그것이다. 이 셋은 Visa와 Mastercard에 같은 방향으로 작용하므로 **한 회사만 보는 것보다 복점 전체의 문제로 읽는 편이 정확하다.**
