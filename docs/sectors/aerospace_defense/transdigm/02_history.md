# 역사 / 주요 이벤트

> 1993년 항공우주 부품 4개 사업을 차입매수(LBO)로 사들이며 출발한 회사가, **"독점적 애프터마켓 부품 사업을 인수해 가격을 올리고 원가를 줄인다"**는 단 하나의 공식을 30년 넘게 반복해 매출 $88억 규모로 키운 과정이다. 사업의 성격도, 자본구조의 성격도 창업 당시의 LBO에서 거의 바뀌지 않았다.

---

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 1993.09 | **회사 설립** — W. Nicholas Howley와 Douglas Peacock이 사모펀드 Kelso & Company와 함께 IMO Industries의 항공우주 4개 사업(Adel Fasteners·Aero Products Component Services·Controlex·Wiggins Connectors)을 약 $56M에 차입매수. 지금의 사업 모델이 이 첫 거래에서 그대로 시작됐다 |
| 2003 | 사모펀드 Warburg Pincus가 회사를 인수 — 상장 전 두 번째 사모펀드 소유 국면 |
| 2006.03 | **NYSE 상장** — 2006-03-20 IPO, 티커 `TDG` |
| 2019.03 | **Esterline Technologies 인수 완료** ($122.50/주, 부채 인수 포함 총 약 **$4.0B**) — 회사 역사상 최대 규모 인수. 항전·센서·특수 소재로 제품군을 크게 넓혔다 |
| 2019.05 | **미 국방부 감찰관(DoD IG) 초과이익 보고서와 하원 청문회** — 검토 대상 부품 47종 중 46종에서 $16.1M의 초과이익을 얻었다는 지적. 청문회 후 회사는 $16.1M을 전액 환불했다 |
| 2021.01~02 | Cobham Aero Connectivity 인수 (약 $945M) — 항공 통신·안테나 |
| 2021.12 | **DoD IG 후속 보고서** — 부품 106종 중 105종에서 추가로 약 $21M의 초과이익. 개별 부품 초과이익률이 68%~3,850% 범위로 지적됐다 |
| 2023.05 | Calspan 인수 완료 (약 $725M) — 천음속 풍동 등 항공우주 시험·기술개발 서비스 |
| 2024.07 | Raptor Scientific 인수 (약 $646M) — 항공우주·방산용 시험·계측 솔루션 |
| 2025.05 | **CEO 교체 발표** — Kevin Stein의 은퇴와 당시 Co-COO Mike Lisman의 후임 지명을 공시 |
| 2025.08 | **$50억 신규 부채 조달과 주당 $90.00 특별배당** — 2025-08-19 채권·term loan으로 $5.0B을 조달하고, 2025-08-20 이사회가 특별배당을 선언해 9월 12일 지급. 배당등가금 포함 총 지급액 약 **$5.2B** |
| 2025.10 | **Mike Lisman이 President & CEO 취임**(10-01자). Kevin Stein은 2025-09-30자로 은퇴하고 이사회에는 잔류, 2026-03-31까지 자문 역할 |
| 2025.10 | Simmonds Precision Products 인수 완료 — RTX로부터 연료·근접 센싱, 구조 건전성 모니터링 사업 인수 |
| 2026.04 | **Jet Parts Engineering·Victor Sierra 인수 완료** (현금 약 **$2.2B**) — 둘 다 **OEM 대체 부품(PMA)·수리 사업**이다. 자사 순정 부품의 가격 결정력을 위협해온 바로 그 시장의 사업자를 사들인 거래라는 점에서 성격이 다르다 |
| 2026.07 | Prince & Izant 인수 계약 체결 (현금 약 **$1.07B**, 세제 혜택 포함) — 브레이징 합금·특수 금속 부품. 2026-08-04 기준 FY2026 가이던스에는 이 거래 기여분이 포함돼 있지 않다 |
| 2026.08 | FY2026 가이던스 상향 — 매출 $10,470~10,550M으로, 회사 역사상 처음 연 매출 $100억을 넘길 전망 |

!!! note "연혁을 관통하는 두 가지"
    **1. 인수는 이 회사의 부수 활동이 아니라 성장 그 자체다.** 위 표에서 인수 항목을 빼면 회사의 궤적이 거의 남지 않는다. 회사 스스로 주주 커뮤니케이션에서 목표를 **"독점적이고 애프터마켓 비중이 큰 항공우주 사업을 인수·보유·운영해 사모펀드 수준(private equity-like)의 수익률을 낸다"**고 표현한다.

    **2. 규제·정치 리스크는 사라진 적이 없다.** 2019년과 2021년 두 차례의 DoD 감찰관 보고서는 회사의 가격 결정 방식 자체를 문제 삼았고, 사업 모델이 바뀌지 않는 한 같은 성격의 조사가 재발할 수 있다. 방산 매출 비중을 고려할 때 이 리스크는 상시적이다 — 상세는 [투자 판단](./07_investment.md) 참고.

    **3. 최근 인수의 방향이 달라졌다는 점은 주목할 만하다.** 2026년 4월 인수한 Jet Parts Engineering·Victor Sierra는 **PMA(승인 대체부품) 사업자**다. 지금까지 이 회사의 해자를 갉아먹는 쪽에 있던 사업을 직접 사들인 것으로, 방어적 인수인지 새로운 성장축인지는 아직 실적으로 확인되지 않았다.
