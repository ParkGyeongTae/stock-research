# 최근 뉴스 / 이슈

> FY2026 들어 **인수와 자사주매입이 동시에 빨라지는 흐름**이다 — 39주 만에 인수 $2.2B·자사주매입 $1.8B을 집행하고 추가로 $1.07B 인수를 계약했으며, 실적 가이던스는 두 차례 상향됐다. 그 사이 CEO도 교체됐다.

!!! note "이 문서의 성격"
    발생 순으로 쌓는 **시점성 로그**다(최신이 위). 여기서는 투자 결론을 내리지 않는다 — 판단에 영향을 주는 항목은 [밸류에이션 / 적정주가](./06_valuation.md)·[투자 판단](./07_investment.md)을 직접 갱신하고, 여기에는 반영했다는 표시만 남긴다.
