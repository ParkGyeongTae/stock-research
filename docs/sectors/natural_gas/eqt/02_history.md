# 역사 / 주요 이벤트

> 1888년 피츠버그의 지역 가스회사로 출발해, 대형 M&A와 스핀오프를 반복하며 "분사→재통합"을 거쳐 지금은 북미 유일의 대형 수직계열화 천연가스 기업이 됐다.

!!! note "이 문서의 범위"
    회사 관점의 전환점만 기록한다. CEO 개인의 커리어·경영 스타일·보상은 [CEO / 경영진](./03_ceo.md)에, 최근 1년 이내의 시점성 이슈는 [최근 뉴스 / 이슈](./08_news.md)에 있다.

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 1888 | Equitable Gas Company로 피츠버그에서 설립 |
| 2009.02 | 사명을 Equitable Resources, Inc.에서 **EQT Corporation**으로 변경 |
| 2017.06 | Rice Energy 인수 발표 — 주식+현금 혼합 대가, 총 약 **$6.7B**(EV 기준으로는 부채 포함 약 $8.2B로 보도) |
| 2017.11 | Rice Energy 인수 완료 — 애팔래치아 최대 천연가스 생산사로 등극, Rice 가문(Toby Rice 등)이 EQT 이사회·경영진에 합류 |
| 2018.11 | **Equitrans Midstream을 분사(spin-off)** — 미드스트림(수집·수송) 사업을 별도 상장사(ETRN)로 분리, EQT 주주에게 지분 80.1% 안분 배정. 분사 후 EQT는 순수 업스트림(E&P) 기업으로 전환 |
| 2019.07 | **Toby Z. Rice가 CEO 취임** — Rice 가문 주도의 위임장 대결(proxy contest)로 기존 경영진 교체. 자세한 내용은 CEO / 경영진 참고 |
| 2024.03 | Equitrans Midstream **재인수** 합병계약 발표 — 전량 주식교환(Equitrans 1주당 EQT 0.3504주), 초기 기업가치 약 $35B 이상 |
| 2024.07 | Equitrans Midstream 인수 완료 — **"북미 유일의 대형 수직계열화 천연가스 기업"**으로 재편, 당초 일정보다 조기 종결(약 $150M 비용 절감). 발행주식수가 이 거래의 주식 대가 지급으로 급증(FY2023 419.9백만 주 → FY2024 596.9백만 주) |
| 2025.07 | Olympus Energy·Hyperion Midstream·Bow & Arrow Land 자산 인수 완료 — 약 90,000 순 에이커, 순생산량 약 500 MMcf/d, 대가는 EQT 보통주 25,229,166주(약 $1,471M) |
| 2026.05~06 | Moody's·Fitch 신용등급 상향 — Fitch가 투자등급 **BBB**로 상향, Moody's는 전망을 Positive로 조정(순부채 감소·FCF 개선 근거) |
