# 역사 / 주요 이벤트

> 100년 넘게 이어온 파이프라인 건설·운영 회사가, 2000년대 초 통신사업 도박으로 파산 직전까지 몰렸다가 순수 천연가스 인프라 회사로 재편해 지금의 대형 미드스트림 사업자로 자리잡기까지의 여정.

!!! note "이 문서의 범위"
    공식 연혁(williams.com)·SEC 공시·언론 보도로 확인한 **회사 관점의 사건**만 기록한다. CEO 개인의 커리어·경영 스타일은 [CEO / 경영진](./03_ceo.md), 현재의 사업부문 구조와 부문별 비중은 [개요](./01_overview.md)에 있다.

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 1908 | Miller Williams·David Williams 형제가 아칸소주 포트스미스(Fort Smith)에서 건설회사로 창업, 이후 장거리 파이프라인 건설로 사업 확장 |
| 1918 | 본사를 오클라호마주 털사(Tulsa)로 이전 — 현재까지 본사 소재지 |
| 1957 | 장외시장(OTC)에서 주식 공개 |
| 1966 | 파이프라인 자산을 레버리지 바이아웃으로 인수하며 "건설업체"에서 "파이프라인 운영사"로 전환 |
| 1983 | Northwest Energy Company 인수로 주간(interstate) 천연가스 파이프라인 시스템(Northwest Pipeline) 확보 |
| **1995** | **Transco Energy Company를 약 $3B에 인수** — 16,000마일 규모 파이프라인이 편입되며 미국 동부 해안까지 사업권을 확장, 미국 최대 주간 천연가스 수송업체 중 하나로 자리잡음(현재도 Transco는 Transmission, Power & Gulf 부문의 핵심 자산) |
| 1998 | MAPCO와 합병 |
| 1999~2001 | **Williams Communications Group(WCG)**을 통해 광섬유 통신망 사업에 본격 진출 — 닷컴 버블 당시 대규모 자본을 투입 |
| **2002.04** | 닷컴 버블 붕괴로 WCG가 파산(Chapter 11)하며 Williams에서 분리·비연결 처리됨 — WCG 보증·부채 노출로 Williams 자체도 유동성 위기에 직면 |
| **2002.08** | Warren Buffett의 Berkshire Hathaway 및 Lehman Brothers로부터 연 30% 금리의 $900M 대출을 포함해 총 $3.4B 규모의 긴급 자금을 조달, 자체 파산을 회피 — 이 시기 신용등급이 투자등급 밖으로 추락하고 주가가 폭락 |
| 2001 | Barrett Resources 인수(업스트림 자산 확대, 이후 순차적으로 정리) |
| 2003 | 통신·비핵심 자산 매각 등 재무구조 재건 프로그램 진행 — 업계에서 "턴어라운드 사례"로 평가받음 |
| 2007 | 신용등급 투자등급(investment-grade) 재획득 |
| 2009 | 마르셀러스·유티카 셰일 가스전 수집·처리 사업 확대 |
| 2014 | Access Midstream Partners 지배지분 인수, 걸프만 Gulf Star 시스템 가동 개시 |
| **2015.09~2016.06** | **Energy Transfer Equity(ETE, 현 Energy Transfer)가 Williams를 약 $33B에 인수하기로 합의**했으나, 유가 급락과 세무 의견서 문제 등으로 2016년 6월 합병이 파기됨 — Williams가 계약상 위약금(termination fee) $410M을 요구하며 델라웨어 법원에 소송 제기 |
| **2018.08** | **Williams Partners L.P.(WPZ)의 남은 공개시장 지분(약 2.56억 유닛) 전량을 주식교환($10.5B 규모, 유닛당 Williams 보통주 1.494주)으로 인수**하며 MLP(상장 파트너십) 구조를 해소하고 단일 C-corp(WMB) 구조로 단순화 |
| 2021 | Sequent Energy Management 인수(가스 마케팅 역량 강화) |
| 2022.09 | 델라웨어 형평법법원이 Williams 승소 판결(위약금+이자+비용 총 $602M) — Energy Transfer가 항소 |
| **2023.10** | 델라웨어 대법원이 원심을 확정, Williams 승소 최종 확정(위약금 $410M + 계약 이율 이자 등) |
| 2023.11 | Energy Transfer로부터 $627M 최종 수령 — 변호사 비용 등을 제한 세후 순이익 **$534M**을 FY2023 GAAP 손익계산서에 "Net gain from Energy Transfer litigation judgment"로 인식(핵심 지표 A.1. 실적 지표 각주 참고) |
| 2023.02 | MountainWest Pipeline Holding Company 인수($1.024B) |
| 2023.11 | DJ 분지(Denver-Julesburg Basin) 가스 수집·처리 자산 인수($544M) |
| 2024.01 | Hartree Partners 계열사로부터 걸프코스트 가스 저장 자산 포트폴리오 인수($1.844B) |
| 2024.08 | Discovery 합작사(JV) 지분 연결 편입($151M) |
| 2024.09(3분기) | Aux Sable 지분 매각, Discovery 관련 자산 재측정 이익 인식 |
| 2024.11 | Crowheart 자산 인수($249M) |
| 2025.01 | Rimrock 가스 수집·처리 시스템 인수($319M, DJ 분지 확장) |
| 2025.03 | Cogentrix Energy 지분 투자($153M, 발전 자산) |
| 2025.06 | Saber Midstream 인수($43M) |
| 2025년 상반기 | Haynesville 업스트림(E&P) 자산을 Woodside Energy에 매각하고 전략적 파트너십 체결 — 업스트림 비중을 줄이고 미드스트림·전력 인프라에 집중 |
| **2025.07.01** | **Chad Zamarin이 President & CEO로 취임**, 14년 재임한 Alan Armstrong은 Executive Chairman으로 이동(2026.03 이사회에서 완전 퇴임) — CEO / 경영진 참고 |
| 2026.02 | 2026 Analyst Day에서 FY2025 실적(Adjusted EBITDA $7.75B, 5개년 CAGR 9%) 발표 및 2026년 가이던스(Adjusted EBITDA 중간값 $8.2B) 제시 |
| **2026.08** | **Momentum Midstream을 최대 $5.5B에 인수하기로 합의**(헤인즈빌~걸프코스트 LNG·전력 수요 연결 강화) 및 **Blackstone과 Power Innovation 합작 조인트벤처 최종화**($5.34B 저비용 자본 조달) — 최근 뉴스 / 이슈 참고 |
