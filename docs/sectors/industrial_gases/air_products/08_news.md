# 최근 뉴스 / 이슈

> 2026년의 뉴스 흐름은 하나로 모인다 — 전임 경영진이 벌인 청정수소 메가프로젝트를 접고(6월 $2.9B 손상), 남은 것은 파트너에게 위험을 넘기고(7월 Yara 오프테이크), 성장 파이프라인을 반도체로 갈아끼우는(전자용 수주 $1.5B+) 과정이다. 시장은 이 전환을 긍정적으로 받아들여 가이던스 상향 때마다 주가가 올랐다.

::: info 이 문서의 성격
발생 순으로 쌓는 **시점성 로그**다(최신이 위). 여기서는 투자 결론을 내리지 않는다 — 판단에 영향을 주는 항목은 [밸류에이션 / 적정주가](./06_valuation.md)·[투자 판단](./07_investment.md)을 직접 갱신하고, 여기에는 반영했다는 표시만 남긴다.

:::
