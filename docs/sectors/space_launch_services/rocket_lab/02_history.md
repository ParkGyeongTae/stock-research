# Rocket Lab — 역사 / 주요 이벤트

> 뉴질랜드의 소형 로켓 스타트업이 연이은 부품·위성 제조사 인수로 수직계열화를 완성해가며, 이제는 위성통신 사업자 Iridium 인수로 발사-제조-통신을 아우르는 우주기업으로 도약을 시도하는 20년.

> ⚠️ 모든 항목은 웹검색으로 확인한 사실만 기록. CEO 개인 이력은 [`03_ceo.md`](./03_ceo.md)에 있다.

---

## 연혁

| 연도 | 내용 |
|------|------|
| 2006 | Peter Beck이 뉴질랜드에서 **Rocket Lab 창업** |
| 2009 | Ātea-1 발사 — 남반구 최초의 민간 개발 로켓으로 우주 도달 |
| 2013 | 본사를 미국 캘리포니아로 이전(이후 2020년 롱비치로 재이전) |
| 2017.05 | Electron 첫 발사("It's a Test") — 지상 통신장비 설정 오류로 궤도 진입 실패 |
| 2018.01 | **Electron 첫 궤도 진입 성공("Still Testing")** — 뉴질랜드 마히아 반도 발사장에서 발사, 위성 3기 배치 |
| 2020.04 | Sinclair Interplanetary 인수 — 위성 부품(반응휠 등) 제조사, Space Systems 수직계열화의 시작 |
| 2021.08 | **Vector Acquisition Corp과 SPAC 합병으로 나스닥 상장(RKLB)** |
| 2021.10 | ASI(Advanced Solutions Inc.) 인수 — 우주 소프트웨어 기업 |
| 2021.12 | Planetary Systems Corporation 인수 — 위성 분리 시스템 제조사 |
| 2022.01 | SolAero Holdings 인수 완료(약 8,000만 달러) — 우주용 태양전지판 제조사 |
| 2025.03 | Neutron, 미 우주군 **NSSL(National Security Space Launch) Phase 3 Lane 1** 프로그램(최대 56억 달러 규모)에 온램프 |
| 2025.03 | Mynaric AG(레이저 광통신 단말 제조사) 인수 의향 발표 |
| 2025.05 | Geost(위성 페이로드·센서 제조사) 인수 발표(2.75억 달러) — 2025.08 인수 완료 |
| 2026.04.14 | **Mynaric AG 인수 완료**(총 대가 약 1.553억 달러, 현금+주식 227만 주) |
| 2026.05.27 | 주가 사상 최고치 $150.23 기록 |
| 2026.06.29 | **Iridium Communications 인수 계약 발표** — 80억 달러(EV), 주당 $27 상당 현금+주식(콜라 구조), 종결 목표 2027년 중반 |
| 2026.08.10 | Q2 2026 실적 발표 — 매출 2.341억 달러(사상 최대, YoY +62%), 백로그 23.6억 달러(사상 최대) |
| 2026.08.12 | Iridium 인수 관련 HSR(반독점) 대기기간 만료 — 인수 절차 진전(주주총회·FCC 승인 등은 진행 중) |
| 2026.08.14 | 5월 사상 최고가 대비 주가 약 45% 하락한 상태(약 $82) — Iridium 인수 희석 우려·섹터 조정 등이 배경으로 거론(`08_news.md` 참고) |
