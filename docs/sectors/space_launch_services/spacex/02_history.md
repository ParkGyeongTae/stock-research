# SpaceX — 역사 / 주요 이벤트

> 로켓 3회 연속 실패로 파산 직전까지 몰렸던 스타트업이 재사용 로켓·위성 인터넷·(최근엔) AI 인프라까지 아우르는 사상 최대 규모 IPO 기업으로 성장하기까지의 24년.

> ⚠️ 모든 항목은 웹검색으로 확인한 사실만 기록. 정확한 일자를 확인하지 못한 일부 항목은 연/월까지만 표기했다.
>
> ⚠️ 이 문서는 **회사 관점의 사건**만 다룬다. Elon Musk 개인의 커리어·경영 스타일은 [`03_ceo.md`](./03_ceo.md)에 있다.

## 연혁

| 연도 | 내용 |
|------|------|
| 2002 | **Elon Musk가 Space Exploration Technologies Corp.(SpaceX) 창업.** 화성 이주 비용을 낮춘다는 목표로 발사체 자체 개발 시작 |
| 2006.03 | Falcon 1 첫 발사 시도, 실패 |
| 2006~2008 | Falcon 1 3회 연속 발사 실패. 자금 고갈로 **파산 직전**까지 몰림 |
| 2008.09 | **Falcon 1 4차 발사 성공** — 민간 액체연료 로켓 최초로 궤도 진입. 이 성공이 없었다면 회사가 존속하지 못했을 것이라는 평가가 지배적 |
| 2008.12 | NASA와 국제우주정거장(ISS) 화물 수송 계약(COTS) 체결 — 이후 매출의 핵심 축이 되는 정부 계약 관계의 시작 |
| 2010.12 | Dragon 우주선 COTS Demo Flight 1 — **민간 기업 최초로 우주선을 궤도에서 회수** |
| 2012.05 | Dragon, 민간 우주선 최초로 ISS 도킹 |
| 2015.12 | **Falcon 9 1단 로켓 지상 착륙 최초 성공** — 재사용 로켓 시대 개막, 발사 비용 절감의 기술적 토대 확보 |
| 2018.02 | Falcon Heavy 첫 발사 성공 (테슬라 로드스터를 화성 궤도로 발사하며 화제) |
| 2019.05 | **Starlink 위성 첫 발사** — 이후 자체 위성 인터넷 사업의 시작점 |
| 2020.05 | **Crew Dragon Demo-2** — 민간 기업 최초로 유인 우주선을 궤도에 올림. NASA 유인 우주 프로그램(Commercial Crew Program)의 정식 파트너로 자리매김 |
| 2021.04 | NASA, Artemis III 달 착륙선(Human Landing System)으로 **Starship 선정** |
| 2021.09 | Inspiration4 — Crew Dragon을 이용한 **최초의 전원 민간인 궤도 비행** |
| 2022 | Starlink 서비스 국가 약 40개국으로 확대 |
| 2023.04 | Starship 최초 궤도급 시험비행 (발사 직후 실패, 이후 반복 시험비행 지속) |
| 2023 | 연간 발사 96회, 매출 103.87억 달러(FY2023, S-1 공시 기준) |
| 2024 | 연간 발사 134회. **FY2024 순이익 7.91억 달러로 유일한 흑자 연도** 기록(매출 140.15억 달러) |
| 2025 | 연간 발사 165회(사상 최다). Starlink 구독자 900만 명 돌파. 12월 내부자 텐더오퍼에서 기업가치 약 8,000억 달러 평가 |
| 2026.02.02 | **xAI를 올스톡으로 합병.** 결합 밸류에이션 약 1.25조 달러(SpaceX 1조 달러 + xAI 2,500억 달러) — 사업부가 Space·Connectivity(Starlink)·AI 3개로 재편 |
| 2026.05.20 | SEC에 **S-1(IPO 공모서류) 제출** — 비상장 기간 처음으로 공식 재무제표 공개(FY2025 매출 186.74억 달러, 순손실 49.37억 달러) |
| 2026.06.12 | **나스닥 상장(SPCX).** 공모가 $135, 상장 첫날 종가 $160.95(+19%) — 사상 최대 규모 IPO |
| 2026.08.04 | 상장 후 첫 분기 실적 발표(Q2 2026) — 매출 78억 달러(YoY +92%), 순손실 5.41억 달러로 전년동기(-10억 달러) 대비 축소. AI 인프라 CapEx 급증(분기 183.7억 달러, 이 중 AI 158.3억 달러)이 시장의 주목을 받음 |
| 2026.08 | 내부자 락업(lock-up) 해제로 약 9.115억 주(시가 약 1,000억 달러 상당) 매도 가능 물량 발생. Starship Flight 13, 재진입 후 기체 보존에 성공하는 등 개발 진전 |
