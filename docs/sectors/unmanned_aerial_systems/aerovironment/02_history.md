# 역사 / 주요 이벤트

> 인력(人力) 비행·태양광 고고도 무인기를 만들던 항공 연구기업이 2000년대 이후 미군 소형 정찰·자폭 드론 표준 공급사로, 그리고 2025년 BlueHalo 인수를 계기로 우주·사이버·지향성 에너지까지 아우르는 종합 방산기술기업으로 세 차례 크게 정체성을 바꿔온 회사다.

> ⚠️ 모든 항목은 웹검색으로 확인한 사실만 기록. CEO 개인의 커리어·경영 스타일은 [`03_ceo.md`](./03_ceo.md)에 있고, 여기서는 회사 관점의 사건만 다룬다.

## 연혁

| 연도 | 내용 |
|------|------|
| 1971 | Paul B. MacCready Jr.가 캘리포니아에서 AeroVironment 창업. |
| 1977 | 인력(人力) 비행기 **Gossamer Condor**로 Kremer Prize 수상 — 조종 가능한 인력비행 최초 달성, 창업자의 항공공학적 명성을 확립한 사건. |
| 1979 | **Gossamer Albatross**로 인력비행 최초 도버해협 횡단. |
| 1980 | 태양광 동력 비행기 **Solar Challenger**로 태양광 유인비행 기록 수립 — 이후 NASA 고고도 태양광 무인기(Pathfinder·Centurion·**Helios**) 개발로 이어지는 기술 기반이 됨. |
| 1980~90년대 | 태양광 고고도 장기체공(HALE) 무인기 연구와 병행해 소형 전술 무인기(Pointer 등) 개발 착수 — 이후 군용 무인체계 사업의 출발점. |
| 2003 | NASA 고고도 태양광 무인기 **Helios** 프로토타입이 시험비행 중 추락. |
| 2002~2000년대 중반 | **RQ-11 Raven** 개발·양산 — 이라크·아프가니스탄전에서 미군 최다 운용 소형 정찰 무인기로 자리잡음(2010년까지 누적 23만 회 이상 출격). |
| **2007-01-23** | **NASDAQ 상장(IPO)** — 공모가 주당 $17, 공모 규모 약 $114M. |
| 2011 | 자폭 드론(loitering munition) **Switchblade** 시리즈 도입 — 이후 회사의 핵심 성장동력이 됨. |
| 2011 | Wahid Nawabi, Efficient Energy Systems(EES, 전력관리·EV충전) 사업부 SVP 겸 GM으로 입사 — 이후 CEO 이력은 [`03_ceo.md`](./03_ceo.md) 참고. |
| 2016-05 | Wahid Nawabi, Timothy E. Conver의 뒤를 이어 CEO 취임(사장직은 같은 해 1월부터). |
| **2018-06** | 전력관리·EV충전 사업부 **Efficient Energy Systems(EES)를 Webasto에 약 $35M에 매각** — 순수 무인체계(UAS) 기업으로 사업 초점을 좁힌 전환점. |
| 2021-02 | **Arcturus UAV** 인수(중형 무인기 플랫폼) 및 Progeny Systems의 **Intelligent Systems Group(ISG)** 자산 인수(수중·자율 시스템). |
| 2021-05 | 독일 **Telerob GmbH**(폭발물처리(EOD) 로봇) 인수 — 지상 무인체계(UGV)로 포트폴리오 확장. |
| **2021-06** | 본사를 캘리포니아 시미밸리(Simi Valley)에서 **버지니아 알링턴(Arlington)**으로 이전 — 주요 고객(국방부)과의 근접성 확보 목적. 시미밸리 등 기존 사업장은 유지. |
| 2021-09 | Wahid Nawabi, 이사회 의장(Chairman) 겸임 시작. |
| 2022-02 | 러시아의 우크라이나 침공 직후, 정찰 무인기(Quantix Recon) 등을 우크라이나에 최초 지원 — 이후 소모성 정밀타격 드론 수요 급증의 최대 수혜 기업 중 하나로 부상하는 계기. |
| 2022-08 | **Planck Aerosystems** 자산 인수(무인기 자율 이착륙·항모 운용 기술). |
| **2023-05~06** | 미 국방부 프로그램 낙찰 실패 통보(2023년 5월) 여파로 **MUAS 보고단위 영업권 손상 $156.0M** 인식, MUAS COCO(자사 운영) 사이트 전면 폐쇄에 따른 가속상각 $34.1M 추가 — FY2023 GAAP 대규모 순손실(약 $(176.2)M)의 직접 원인. 상세 수치는 [`04_metrics.md`](./04_metrics.md) A.1 참고. |
| 2023-09 | **Tomahawk Robotics** 인수(무인체계 통합 제어 소프트웨어). |
| 2025-05 | Q4 FY2025 실적에서 UGV(무인지상차량) 관련 영업권 손상 $18.4M 추가 인식. |
| **2025-05-01** | **BlueHalo 인수 완료** — 약 $41억 규모 전액 주식교환 거래. 우주 시스템·사이버보안·전자전·지향성 에너지(레이저 무기) 역량을 더해 "차세대 방산 기술기업"으로 사업 재편, 조직을 **Autonomous Systems(AxS)** / **Space, Cyber and Directed Energy(SCDE)** 2개 부문으로 개편. 인수대가로 보통주 약 1,740만 주 신규발행(비현금, 공정가치 약 $2.78B). |
| 2025-07 | 보통주 유상증자(약 405만 주, 순조달액 약 $968.5M) 및 **0% 표면금리 2030년 만기 전환사채(원금 약 $650M, 순조달액 $726.9M)** 발행 — 조달자금으로 기존 텀론 $700.2M·리볼버 차입 $265.1M 상환. |
| 2026-01 | 미 우주군(Space Force) **SCAR 프로그램**(BADGER 위상배열 안테나) 작업중지 명령 수령 — Space 보고단위 현금흐름 전망 하향 조정의 트리거. |
| **2026-03-10** | FY2026 3분기 실적 발표 — Space 보고단위 영업권 손상 $151.3M 최초 인식(이후 재작성으로 확대, 아래 참고), SCAR 프로그램 계약 해지 및 재입찰(recompete) 필요 공시. |
| 2026-03 | **Empirical Systems Aerospace(ESAero)** 인수(약 $200M) — 항공 엔지니어링·제조 서비스 역량 추가. |
| **2026-06-22** | FY2026 3분기(2026-01-31 종료) **10-Q/A 재작성 제출** — Space 보고단위 영업권 손상 계산에서 인수 이연법인세 자산·부채 배분 오류 발견, 손상액 $89.4M 추가(누적 $240.7M)로 정정, 내부통제 중요한 취약점(material weakness) 공시. |
| 2026 상반기 | 위 재작성 관련 다수의 증권집단소송(securities class action) 제기(리드 플레인티프 신청 마감 2026-07-27) — 상세는 [`08_news.md`](./08_news.md). |
| 2026-06-29 | FY2026 4분기·연간 실적 발표 — 매출 $1,976.8M(YoY +141%), BlueHalo 인수 이후 첫 완전 회계연도 실적. |
