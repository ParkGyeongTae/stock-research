# Kratos Defense & Security Solutions — 역사 / 주요 이벤트

> 무선통신 인프라 회사(WFI)로 출발해 2004년 국방부 대상 사업으로 전략을 틀고 2007년 사명을 바꾼 뒤, 인수합병으로 마이크로파 전자부품·위성통신·표적 드론 역량을 축적해왔다. 2018년 비핵심 사업 매각으로 방산 기술기업 정체성을 굳힌 이후, 2019년 XQ-58 Valkyrie 첫 비행을 기점으로 저비용 소모성 전투 무인기 분야의 대표주자로 부상했고, 2026년에는 대규모 유상증자로 위성통신 M&A(Orbit·Nomad)와 생산능력 확충을 동시에 밀어붙이고 있다.

> ⚠️ 모든 항목은 웹검색으로 확인한 사실만 기록. 추측이나 출처 불명 내용은 작성 금지.
>
> ⚠️ 이 문서는 **회사 관점의 사건**만 다룬다. Eric DeMarco 개인의 커리어는 [`03_ceo.md`](./03_ceo.md)에 별도로 기록했다.

## 연혁

| 연도 | 내용 |
|------|------|
| 1994.12 | Massih Tayebi·Masood Tayebi 형제가 캘리포니아 샌디에이고에서 **Wireless Facilities, Inc.(WFI)** 창업 — 무선통신 인프라 엔지니어링·설치·유지보수 서비스 제공 |
| 1999.11 | 나스닥 상장(IPO), 티커 "WFII" |
| 2003.11 | Eric DeMarco가 President & COO로 입사 |
| 2004.04 | DeMarco, CEO 취임 — 이후 사업 전략을 연방정부(특히 국방부) 대상으로 전환하기 시작 |
| 2004~2009 | High Technology Solutions(HTS)·Madison Research(MRD)·Haverstick Consulting·SYS Technologies·Digital Fusion(DFI) 등 연방정부 서비스 기업을 잇달아 인수하며 방산 사업 확대 |
| 2007.09 | 사명을 **Kratos Defense & Security Solutions, Inc.**로 변경 — 상업용 무선통신 사업을 정리하고 국방부 대상 사업자로 재편 |
| 2011.02~08 | 마이크로파 기반 전자부품·레이더·전자전 시스템 업체 **Herley Industries를 약 2.7억 달러에 인수** |
| 2011.07.27 | **Integral Systems와 합병** — 위성 데이터 처리·지상국(ground systems) 역량 확보, 약 800명 인력·14개 거점 편입 |
| 2012.05~07 | 무인 표적기(aerial target) 제조사 **Composite Engineering, Inc.(새크라멘토 소재)를 약 1.55억 달러에 인수** — Kratos 무인체계 사업의 토대 |
| 2018.02~06 | 비핵심 사업이던 **Public Safety & Security(PSS) 사업부를 Securitas Electronic Security에 매각**(순현금 유입 약 7,000만 달러) — 무인기·위성통신·미사일방어·훈련체계·마이크로파 전자부품 중심 "고기술 방산기업"으로 전략 재확인 |
| 2019.02 | 터보젯 엔진 업체 **Florida Turbine Technologies 인수** |
| 2019.03.05 | 유마 사격장(애리조나)에서 **XQ-58A Valkyrie 첫 비행** — 미 공군 저비용 소모성 타격 시연(LCASD) 프로그램용 스텔스 무인전투기 |
| 2020.02.24 | 디트로이트 소재 터보젯 제조사 **Technical Directions, Inc.(TDI) 인수** |
| 2020.03 | 극초음속 시험체 **Gray Wolf 순항미사일 고고도 비행시험** 실시 |
| 2024.04 | 미 공군 **CCA(Collaborative Combat Aircraft) Increment 1** 프로그램 시제 단계에 General Atomics·Anduril이 선정 — Kratos는 자체 무인전투기(XQ-58 등) 포트폴리오를 보유했음에도 이 1차 선정에서는 제외됨(`07_investment.md` 리스크 참고) |
| 2025.11.05 | 이스라엘 위성통신 시스템 업체 **Orbit Technologies Ltd 인수 계약**(약 3.563억 달러) 발표 |
| 2026.01.08 | 미 해병대가 Northrop Grumman·Kratos 컨소시엄을 **XQ-58 Valkyrie 기반 무인 윙맨 드론 사업자로 선정** |
| 2026.02.10 | 미 전쟁부(Department of War) 산하 "Drone Dominance" 프로그램의 **1단계 Gauntlet에 참여 기업으로 선정**(4단계에 걸쳐 총 11억 달러 규모, 약 35만 대 조달 목표) |
| 2026.02.11 | 이동형 통신 지휘소 제조사 **Nomad Global Communication Solutions 인수** 완료 |
| 2026.02.26~03.02 | **공모증자**(14,285,714주 + 초과배정옵션 2,142,857주, 공모가 주당 $84.00, 순조달액 약 13.484억 달러) 완료 — Orbit·Nomad 인수 재원, 생산능력 확충, 재무건전성 강화에 사용 |
| 2026.03.02 | **Orbit Technologies 인수 완료**(현금 약 3.527억 달러) — Kratos 마이크로파 전자부품(Microwave Electronics) 사업부에 편입 |
| 2026 (예정) | 오클라호마주 브리스토(Bristow)에 신규 제트엔진 생산시설 가동 예정 |
