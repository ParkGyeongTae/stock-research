# 역사 / 주요 이벤트

> 회사의 방향을 바꾼 전환점만 남긴다. 최근 1년 안팎의 뉴스는 [최근 뉴스 / 이슈](./08_news.md)에 있다.

이 회사의 역사는 **합병으로 만들어진 회사가 어떻게 단일 프로그램(F-35)에 집중하게 됐는가**로 요약된다. 1990년대 냉전 종식 후 미 국방예산이 줄면서 방산업계가 강제 통폐합되던 국면에서 태어났고, 2001년 JSF 수주 이후 30년치 매출을 한 기종에 묶었다.

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 1912.08 | **Glenn L. Martin Company** 설립 (캘리포니아). 현 사명의 "Martin" 계보 |
| 1926.12 | **Lockheed Aircraft Company** 설립 (Allan Loughead 등). "Lockheed" 계보 |
| 1943 | Clarence "Kelly" Johnson 주도로 **Skunk Works**(고등개발계획국) 설립. U-2·SR-71·F-117·F-22로 이어지는 기밀 개발 조직의 기원이며, 현재 Aeronautics 부문 기밀 프로그램의 뿌리 |
| 1971.08 | 미 의회가 **록히드 긴급대출보증법** 통과. L-1011 여객기와 롤스로이스 엔진 파산 여파로 사실상 도산 직전이었고, 정부 보증으로 생존 — **회사 존립이 정치적 결정에 달렸던 사건** |
| 1976.02 | **록히드 뇌물 스캔들** — 일본·서독·이탈리아 등 항공기 판매 로비 뇌물이 미 상원 청문회에서 폭로. 미국의 [해외부패방지법(FCPA, 1977)](https://www.justice.gov/criminal/criminal-fraud/foreign-corrupt-practices-act) 제정의 직접적 계기가 됐다 |
| **1995.03** | **Lockheed Corporation + Martin Marietta 합병**($100억 규모) → **Lockheed Martin Corporation** 출범. 당시 세계 최대 방산업체가 됐다[^merge] |
| 1996.04 | Loral의 방산전자 사업 인수($9.1B 규모). 현 RMS 부문의 전자·C4ISR 기반 |
| **2001.10** | **합동타격전투기(JSF) 계약 수주** — 보잉 X-32를 제치고 F-35 프라임 선정. 역사상 최대 규모 방산 프로그램이며, 25년이 지난 현재까지 **Aeronautics 부문(매출의 40%)을 떠받치는 축** |
| **2015.11** | **Sikorsky Aircraft 인수**($90억, United Technologies로부터). 회전익기 사업 진입 — 현 RMS 부문. FY2025 손실충당이 난 CMHP·TUHP가 이 인수로 들어온 프로그램이다[^sik] |
| 2016.08 | IS&GS(정보시스템·글로벌솔루션) 부문을 Leidos에 분리매각. IT 서비스에서 손을 떼고 플랫폼·무기체계에 집중하는 방향 전환 |
| **2020.06** | **Jim Taiclet 사장 겸 CEO 취임** (2021.03 회장 겸임). American Tower CEO 출신 — "21st Century Security" 전략의 시작([CEO / 경영진](./03_ceo.md)) |
| **2022.02** | **Aerojet Rocketdyne 인수($44억) 무산** — 미 FTC가 반독점을 이유로 제동. 로켓 모터 수직계열화가 막히면서 대형 M&A가 자본배분 선택지에서 사실상 빠졌다 |
| 2023.07 | **F-35 TR-3 인도 중단** — Technology Refresh 3 소프트웨어 지연으로 미 정부가 신규 인도 수령을 거부. 인도 지연분이 재고로 쌓이며 현금흐름이 눌렸다 |
| 2024.07 | TR-3 축소(truncated) 버전으로 **인도 재개**. 중단 기간 만 1년 |
| **2025.07** | **2025 2분기 세전 $1,681M 손실충당** (기밀 항공 $950M · CMHP $570M · TUHP $95M · 고정자산 상각 $66M). 당일 주가 **−10.8%**($460.53 → $410.74) — 5년 내 두 번째로 큰 하락일 |
| 2026.01 | 2025년 **F-35 191대 인도**(연간 최다), 누적 1,300대 돌파. TR-3 지연으로 쌓였던 재고 해소 |
| **2026.06** | **미사일방어청(MDA) THAAD 요격체 증산 계약 수주 — 7년 $350억.** 이 한 건으로 MFC 부문 수주잔고가 한 분기에 $46.6B → $87.9B(+88.6%)로 뛰었다 |
| 2026 (월 확인 필요) | **Golden Dome 우주기반 요격체(SBI) 프로토타입 개발사로 미 우주군에 선정.** 성능 시연은 2028년 예정 |

[^merge]: 합병일은 1995년 3월 15일. 출처: [회사 역사 페이지 "A Merger of Equals"](https://www.lockheedmartin.com/en-us/news/features/history/merger.html).
[^sik]: CMHP(Canadian Maritime Helicopter Program, 캐나다 해상헬기)와 TUHP(Turkish Utility Helicopter Program, 터키 다목적헬기)는 둘 다 Sikorsky 계열의 **국제 고정가 프로그램**이다. 인수 10년 뒤에 손실충당으로 돌아왔다는 점에서, 이 인수의 원가 위험이 아직 정리되지 않았다는 신호로 읽을 수 있다.

**이 연혁에서 읽어야 할 것 하나** — 1971년 대출보증, 2001년 JSF 수주, 2022년 FTC 제동, 2026년 THAAD·Golden Dome까지 **회사의 변곡점이 거의 전부 미 정부의 결정**이었다. 기술이나 시장 경쟁보다 **조달 정책·예산·규제가 이 회사의 실적을 결정한다**는 것이 이 사업의 구조적 성격이고, [투자 판단](./07_investment.md)의 리스크가 대부분 여기서 나온다.
