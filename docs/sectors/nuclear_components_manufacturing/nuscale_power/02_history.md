# NuScale Power — 역사 / 주요 이벤트

> 오리건주립대 기술이전 스타트업 → 2020년 세계 최초 SMR 설계인증 → 2022년 SPAC 상장 → 2023년 첫 플래그십 프로젝트(UAMPS CFPP) 좌초 → 2024년 ENTRA1 파트너십으로 사업모델 전면 전환 → 2025년 대규모 일회성 비용·집단소송으로 이어지는, "규제 인증에서는 앞섰지만 상업화는 계속 늦어지는" 궤적의 회사.

> ⚠️ 모든 항목은 웹검색·1차 공시로 확인한 사실만 기록. 추측이나 출처 불명 내용은 작성 금지.
>
> ⚠️ 이 문서는 **회사 관점의 사건**만 다룬다. CEO 개인의 커리어·경영 스타일은 [`03_ceo.md`](./03_ceo.md)에 기록한다.

## 연혁

| 시점 (연도.월) | 내용 |
|----------------|------|
| 2007 | 오리건주립대(OSU) 기술이전으로 Paul G. Lorenzini·José Reyes가 공동 설립 |
| 2011 | Fluor Corporation이 초기 대규모 투자자로 참여, 이후 누적 약 $570M 투자하며 최대주주로 성장 |
| 2014 | DOE 자금지원 프로그램(SMR Licensing Technical Support 등)에 선정되며 설계인증 절차 본격화 |
| **2020.08** | 미 NRC로부터 **세계 최초 SMR 설계인증(Design Certification)** 획득(50MWe NPM 모델) — NuScale의 핵심 규제 우위가 확립된 시점 |
| **2022.05.02** | 스팩(SPAC) **Spring Valley Acquisition Corp**와의 합병 완료, NYSE에 **SMR** 티커로 상장 |
| 2022~2023 | 유타주 지자체연합 UAMPS와 협력해 아이다호국립연구소(INL) 부지에 77MWe×6기(462MW) **Carbon Free Power Project(CFPP)** 추진 — DOE로부터 최대 $1.355B 비용분담 지원 약정 |
| **2023.11.08** | 원가 초과로 목표 전력단가($58/MWh)를 넘어서고 UAMPS 회원 유틸리티들의 구독 이탈이 이어지며 **UAMPS와 CFPP 프로젝트 상호 종료 합의** — NuScale의 첫 플래그십 상업 프로젝트가 착공 전 좌초된 사건. DOE는 이 프로젝트에 약정한 $1.355B 중 $232.8M만 실제 지급한 상태였다 |
| 2024 | 루마니아 국영 원전사업자 SN Nuclearelectrica의 자회사 RoPower Nuclear와 **Technology License Agreement(TLA)** 체결 — 유럽 첫 상업화 시도 |
| **2024년 중** | 전략적 파트너 **ENTRA1 Energy**와 **Partnership Milestone Agreement(PMA)** 체결 — 이후 NuScale은 발전소 고객과 직접 계약하지 않고 ENTRA1을 통해서만 프로젝트를 확보하는 구조로 사업모델을 전환(자세한 계약 구조는 [`01_overview.md`](./01_overview.md) §2 참고). Fluor가 지분 매각(monetization)을 본격적으로 시작한 시점도 이 무렵과 겹친다 |
| 2025.05(FEED 완료 시점 부근) | Fluor의 RoPower FEED(기본설계) Phase 2 용역 완료 |
| **2025년 3분기(2025-11-06 실적발표)** | ENTRA1과 TVA(테네시밸리전력청) 간 **최대 6GW(NPM 72기) 규모 비구속적 협력 합의**가 체결되며 PMA상 지급 조건이 충족돼, **"Milestone Contribution 1" $507.4M이 일회성 G&A 비용으로 인식** — 분기 순손실이 전년동기 $46M에서 $532M로 급증. 발표 다음 거래일(2025-11-06→11-07) 주가 약 14% 급락 |
| 2025.11 전후 | 조직 슬림화 조치로 **정규직 154명(전체의 28%) 감원**, 2025년 말 기준 정규직 428명으로 축소 |
| **2026.03경 (증권집단소송 커버 기간 2025-05-13~2025-11-06)** | ENTRA1의 원전 개발·시공 경험·역량에 대한 공시가 부실했다는 취지의 **증권 집단소송(securities fraud class action)** 다수 제기(Levi & Korsinsky, Kessler Topaz 등 로펌 주도, 리드플레인티프 마감 2026-04-20) |
| 2026.01분기(1분기) | SN Nuclearelectrica 주주들이 Doicești(옛 석탄화력 부지)에 NPM 6기 RoPower 플랜트를 배치하는 다음 단계 진행을 승인 |
| **2026년 상반기** | 미 NRC로부터 **상향 설계(우레이티드, 77MWe 모델 기반) 추가 설계인증** 획득 — NRC 인증을 받은 원자로 설계 7개 중 2개를 보유한 유일한 SMR 업체가 됨 |
| 2026.05 전후 | Fluor Corporation의 지분 매각이 대체로 일단락됐다는 보도(다만 2026-03-30 위임장 기준 Fluor는 여전히 Class A 12.68%·총 의결권 12.09%를 보유 — 잔여 지분 매각 여부는 [`03_ceo.md`](./03_ceo.md) §6 참고, 확인 필요) |
| 2026.08.05 | 2분기 실적 발표 — 분기 매출 $0.075M(전년동기 대비 −99%)까지 축소, 현금성자산은 유상증자 등으로 약 $1.9B까지 증가. ENTRA1·TVA 간 구속력 있는 전력구매계약(PPA)이 2026년 말까지 체결될 수 있다는 경영진 코멘트 |
