# 역사 / 주요 이벤트

> MIT 동문 두 명이 세운 반도체 테스터 회사에서 출발해, LitePoint·Universal Robots 등 인수를 통해 "테스트 + 로보틱스" 이중 사업 구조를 갖추게 됐고, 2023년 창업자 계열이 아닌 내부 승진 CEO 체제로 전환한 뒤 2025년 AI 반도체 수요 급증의 최대 수혜 기업 중 하나로 부상했다.

> ⚠️ 아래 항목은 웹검색으로 확인한 사실만 기록. CEO 개인의 커리어·경영 스타일은 [CEO / 경영진](./03_ceo.md)에 있고, 여기서는 회사 관점의 사건만 다룬다.

## 연혁

| 연도 | 내용 |
|------|------|
| 1960 | MIT 동문 Alexander V. d'Arbeloff와 Nicholas DeWolf가 공동 창업 |
| 1961 | 첫 제품(로직 제어 go/no-go 다이오드 테스터)을 Raytheon에 판매 |
| 1966 | 최초의 컴퓨터 제어 칩 테스터 J259 출시 |
| **1970** | **뉴욕증권거래소(NYSE) 상장** — 42만 주 공모 |
| 1987 | 최초의 아날로그 VLSI 테스트 시스템 A500 출시 — 아날로그/디지털 혼합신호 테스트 시장 선도 |
| 1999.08 | 2대1 주식분할(액면분할) 실시 — 이 저장소가 다루는 최근 3개년(FY2023~) 구간에는 해당 없음 |
| 2000~2001 | Herco Technologies, Synthane-Taylor 인수 (Teradyne Connection Systems), 이어 회로기판 테스트·검사 기업 GenRad 인수 |
| 2011 | **LitePoint 인수** — 무선(Wireless) 테스트 사업 진출 |
| 2015 | **Universal Robots 인수** — 협동로봇(Cobot) 사업으로 산업 자동화 영역 확장 |
| 2018 | Mobile Industrial Robots(MiR) 인수 — 자율이동로봇(AMR) 사업 추가 |
| **2018.11.27** | 상장 거래소를 **NYSE에서 NASDAQ으로 이전**(티커 TER 유지) |
| 2020 | AutoGuide Mobile Robots 인수 — 로보틱스 포트폴리오 강화 |
| 2022.07.01 | Greg Smith, President 취임(CEO 승진 전 단계) |
| **2023.02.01** | **Greg Smith CEO 취임** — Mark E. Jagiela 후임, 동시에 이사회 합류(Chairman은 겸임하지 않음, [CEO / 경영진](./03_ceo.md) 6. 지분 구조 / 거버넌스 참고) |
| 2023.11 | Technoprobe(프로브카드 공급사) 지분 10% 취득 계약(콜옵션 방식) — 공급망 파트너십 강화 |
| **2024.05.27** | **Device Interface Solutions(DIS) 사업부를 Technoprobe에 $85.0M에 매각**(세전 처분이익 $57.1M) — Semiconductor Test 내 일부 제품군을 핵심 사업 집중을 위해 정리 |
| 2024 (4Q 보고 기준) | 보고 세그먼트를 4개(Semiconductor Test·System Test·Wireless Test·Robotics)에서 3개(Semiconductor Test·Product Test·Robotics)로 재편 |
| 2024 (9개월 누적) | Robotics·Semiconductor Test 중심 인원 87명 감축, 구조조정 비용 $5.3M 인식 |
| **2025.01.31** | Infineon의 자동화 테스트 장비(AET) 기술·개발팀(독일 레겐스부르크) 인수, €17.6M(약 $18.3M) |
| 2025.05.31 | **Quantifi Photonics 인수**(약 $127.2M) — 실리콘 포토닉스(PIC) 테스트 솔루션 확보 |
| 2025 (9개월 누적) | Robotics 부문 중심 약 150명 추가 감축, 구조조정 비용 $18.5M(이 중 Robotics 관련 $13.5M) — 로보틱스 사업의 수익성 재조정 신호 |
| 2026.01.29 | MultiLane과 조인트벤처(MultiLane Test Products, MLTP) 설립 계약 발표 — Teradyne이 약 $157M을 투자해 75% 지분 확보, AI 데이터센터용 고속 인터커넥트 테스트 솔루션 확대 목적 |
| 2026.04.08 | MLTP 조인트벤처 설립 완료(거래 종결) |
| 2026 (2Q) | AI 반도체 수요 급증으로 분기 매출 $1,329M 기록(YoY +104%, 사상 최대), 컴퓨트(AI 가속기·CPU·네트워킹)향 SoC 테스트 매출 전년비 약 600% 성장, AI 관련 매출이 전체의 60% 이상 차지 |
