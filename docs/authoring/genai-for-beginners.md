# 생성형 AI 입문 커리큘럼 — Generative AI for Beginners

이 문서는 GitHub에서 가장 많은 별을 받은 생성형 AI 학습 자료인 Microsoft의 [Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners)가 **무엇을 가르치고, 그중 무엇이 이 저장소를 굴리는 데 실제로 쓸모 있는지**를 정리합니다. 번역이 아니라 커리큘럼 구성을 훑고 고른 것이며, 원문은 링크로 대신합니다.

이 저장소가 따르는 규칙이 아니라 **학습 참고용**입니다.

포크가 62,751개나 되는 것은 이 커리큘럼이 **강의 교재로 널리 복제**되기 때문입니다 — 별 수가 곧 품질이라기보다 "교육용으로 가장 많이 채택된 자료"로 읽는 편이 정확합니다.

## 3. 이 저장소 주인에게 쓸모 있는 레슨

이 저장소는 **애플리케이션을 만들지 않고 문서를 만듭니다.** 그래서 21개 중 실제로 값을 하는 건 절반이 안 됩니다.

**읽을 값이 있는 것**

- **02 · 모델 비교와 선택** — "어려운 추론엔 큰 모델, 단순 작업엔 작은 모델"이라는 판단 기준은 [Claude Code 활용 가이드](./claude-code-guide.md)의 추론 강도 선택과 같은 이야기입니다.
- **03 · 책임 있는 사용** — 환각(hallucination)이 왜 생기고 무엇으로 줄이는지 다룹니다. `AGENTS.md`의 "수치는 확인 후 기입한다"가 왜 그 자리에 있는지에 대한 배경 설명이 됩니다.
- **04 · 05 · 프롬프트** — 기법이 왜 통하는지를 예제와 함께 설명합니다. 도구를 쓰는 실제 작업에서의 프롬프트는 [Claude Code 활용 가이드](./claude-code-guide.md)가 더 구체적입니다.
- **13 · 보안** — 프롬프트 인젝션을 다룹니다. 웹에서 가져온 문서를 그대로 읽히는 작업(공시·뉴스 조사)이 이 저장소의 기본 흐름이라 남의 문제가 아닙니다.
- **15 · RAG** — 지금 이 저장소가 쓰는 방식은 아니지만, **"모델의 기억 대신 원문을 가져와 답하게 한다"**는 발상 자체는 여기서 매일 하는 일입니다(공시를 찾아 인용하고 각주를 다는 것).

**건너뛰어도 되는 것**

- 06~11, 16, 18~21 — 애플리케이션 구축과 모델 배포가 목적이라 여기와 접점이 없습니다.
- 코드 예제 전반 — Azure OpenAI · OpenAI API 키가 필요하고, Microsoft 제품 생태계(Azure, Foundry Models)를 전제로 합니다. **읽는 것만으로 얻는 게 있는 자료지 실습이 필수는 아닙니다.**

## 4. 읽을 때 감안할 것

- **Microsoft 생태계가 기본 전제입니다.** 모델·배포·평가 도구가 Azure 쪽으로 서술되고, 예제는 Azure OpenAI 또는 OpenAI API를 씁니다. 개념을 배우는 데는 무리가 없지만 "이 도구를 써야 한다"로 읽을 필요는 없습니다.
- **번역본은 자동 생성입니다.** 한국어를 포함한 55개 언어가 GitHub Action으로 번역·동기화되므로 최신성은 좋지만 용어가 어색한 곳이 있습니다. 헷갈리면 영어 원문을 봅니다.
- **입문 자료의 한계** — 21개 레슨이 넓게 훑는 구조라, 이미 쓰고 있는 주제(프롬프트·에이전트)는 여기보다 [Claude Code 활용 가이드](./claude-code-guide.md)·[스킬 작성 가이드](./skill-authoring-guide.md)가 깊고 최신입니다. **모르는 영역의 지도를 얻는 용도**로 쓰는 게 맞습니다.
