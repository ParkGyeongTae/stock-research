# 기술적 분석 (주봉 캔들차트 · 5년 지지/저항)

> 최근 5년 주봉 가격 흐름을 지지선·저항선과 함께 정리한 참고 자료. [기술적 분석 — 일봉·1년](./09_technical_daily.md)이 단기 구간을 본다면 이 문서는 여러 사이클에 걸친 구조적 레벨을 본다. **과거 가격 패턴에 대한 객관적 서술이며 매수/매도 신호나 목표가 예측이 아니다** — 적정주가 판단은 [밸류에이션 / 적정주가](./06_valuation.md), 투자 결론은 [투자 판단](./07_investment.md)에 있다.

> ⚠️ 이 문서의 차트·표·방법론 수치는 손으로 만들지 말고 `scripts/gen_technical_chart.py --interval 1wk`로 생성한다. 커맨드·옵션·다크모드 CSS 주의사항·`--emit` 출력을 어디에 붙여넣는지는 전부 `docs/authoring/chart-generation-guide.md` "기술적 분석 차트 생성"이 마스터다.
>
> ⚠️ 상장 후 거래 기간이 2년 미만이거나 유동성이 극히 얕은 종목은 스윙 클러스터가 표본 부족으로 무의미해진다 — 문서를 생략하지 말고 기간을 실제 거래 구간으로 줄여 만든 뒤 표본 부족을 4. 방법론 · 한계에 남긴다.

??? note "이 차트의 데이터 출처와 대조 결과"
    - **출처**: <예: Yahoo Finance 주봉 OHLCV>. 이 차트용으로 따로 수집한 값이라 [핵심 지표](./04_metrics.md)의 원자료 표와는 계보가 다르다(주봉은 핵심 지표가 다루는 범위 밖이다).
    - **대조 결과**: <예: 2026-08-21 종가 $397.87은 밸류에이션 / 적정주가에 인용된 값과 일치>. 어긋나면 어느 쪽이 수정주가(배당·분할 반영)인지부터 확인한다.

## 2. 지지선 / 저항선 요약

각 레벨은 "전후 `<n>`주 내 최고/최저인 스윙 포인트"를 가격 기준 ±`<n>`% 이내로 묶은 클러스터다. 터치 횟수는 그 클러스터에 포함된 스윙 포인트 개수(강도 근사치)이며, 미래 지지/저항을 보장하지 않는다(4. 방법론 · 한계 참고). **기술적 분석 — 일봉·1년의 레벨(전후 5거래일)과는 탐지 창 자체가 달라 값이 다르게 나오는 게 정상이다** — 같은 방법론의 다른 배율로 혼동하지 말 것.

<`--interval 1wk --emit table` 출력을 붙여넣고 비고 열의 `<...>`만 채울 것. 비고의 날짜는 눈대중하지 말고 `--emit dates` 출력을 그대로 옮긴다>

| 레벨 | 가격 | 터치 횟수 | 비고 |
|------|------|-----------|------|
| R3 | $ |  | <어느 시기의 스윙 고점대인지> |
| R2 | $ |  |  |
| R1 | $ |  |  |
| **현재가** | **$`<X>`** (`<YYYY-MM-DD>` 종가) | — | R1과 S1 사이 |
| S1 | $ |  | <현재가에 가장 근접한 지지> |
| S2 | $ |  |  |
| S3 | $ |  |  |
| 참고선 | $ | — | <역대 최고/최저 등 — 왜 근시일 지지/저항으로 보지 않는지> |

> ⚠️ 레벨 개수를 3개로 고정하지 말 것 — 유효한 클러스터가 2개면 2개만 쓴다. 개수를 바꿨거나 `--force-level`로 넣은 레벨이 있으면 사유를 비고와 4. 방법론 · 한계에 남긴다.

## 3. 관측된 특이 구간 — `<YYYY-MM-DD>` <이벤트명>

<가격대가 여러 분기에 걸쳐 구조적으로 재설정된 구간만 — 실적 갭·인수 발표·규제 이슈·거시 국면 전환(금리 인상기 등). **일봉 기준 단기 이벤트는 기술적 분석 — 일봉·1년에 있으니 여기서 중복 서술하지 말 것.** 없으면 이 절을 통째로 삭제>

- <이벤트 시점과 계기. [최근 뉴스 / 이슈](./08_news.md) 로그에 있으면 링크>
- 그 주 종가 기준 전주 대비 **<±X>%**, 이후 몇 주간 레짐이 어떻게 바뀌었는지
- <이 사건 이후 거래 레짐이 어떻게 달라졌는지 — 이전 스윙 레벨을 참고선으로만 처리했다면 그 사유>

---

## 4. 방법론 · 한계

<아래 4줄은 `--interval 1wk --emit facts` 출력을 그대로 붙여넣을 것>

- **데이터**: <출처> 주봉 OHLCV, `<N>`개 주, `<YYYY-MM-DD>`~`<YYYY-MM-DD>`. 수집 시점: `<YYYY-MM-DD>`. <수정주가(배당·분할 반영) 여부 명시>
- **스윙 포인트 탐지**: 각 주의 고가/저가가 전후 `<n>`주(총 <2n+1>주 창) 내 최고/최저값과 같으면 스윙 고점/저점으로 분류. 일봉(전후 5거래일)보다 창이 넓어 단기 노이즈보다 다년 구조적 레벨을 잡는다.
- **클러스터링**: 스윙 포인트를 가격 오름차순으로 정렬한 뒤, 기존 클러스터 중심과 ±`<n>`% 이내면 합산하고 중심을 재계산.
- **생성**: `scripts/gen_technical_chart.py --interval 1wk` (<사용한 옵션 그대로 — 재현용>)
- **한계**: 후행 지표이며 특정 가격의 지지·저항 작동을 보장하지 않는다. 거래량 프로파일·이동평균·추세선 등은 포함하지 않은 단순 모델이고, 윈도우·허용오차 값을 바꾸면 레벨과 터치 횟수가 달라진다(최적화된 값이 아니다).
    - <5년 구간 안에 사업 구조 자체가 바뀌었다면(대규모 M&A·사업부 매각·상장 형태 변경) 과거 레벨이 현재 펀더멘털과 무관해질 수 있다 — 3. 관측된 특이 구간에 남기고 위 표에서 참고선으로만 처리할 것>
    - <해당 기간에 주식분할·대규모 유상증자 등 가격 연속성을 깨는 이벤트가 있었다면 소급 조정 여부를 명시>
